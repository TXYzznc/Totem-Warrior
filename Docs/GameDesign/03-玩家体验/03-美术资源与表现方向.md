## 元素可读性

元素反馈至少同时使用两种通道，例如颜色 + 图标、颜色 + 形状或粒子 + 音效，避免只依赖色相。

层级需要可辨认：

- 弱层：基础提示。
- 标准层：明显增强但不遮挡目标。
- 强层：最高警示，同时保持瞄准和弱点可见。

反应必须与元素常驻状态区别，避免玩家误以为新元素仍留在目标身上。

## 弱点表现

- 玩家弱点是头部，可通过命中反馈强化，不必长期发光。
- 非人型 Enemy 的弱点未来可由 Shader、预制体发光物、材质结构或动画表达。
- 弱点提示方式必须在 Enemy 设计时与攻击节奏共同确定。

## 占位与正式验收

- 最终美术不阻塞玩法闭环和自动 smoke。

- UI 数据或交互 bug 在程序 change 修复；布局、切片、色彩和最终效果偏差回到美术 change。

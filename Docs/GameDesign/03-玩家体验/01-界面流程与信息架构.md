# 界面流程与信息架构

> 状态：功能与字段边界已确认；最终 UI 视觉和排版由独立美术计划负责

## 系统目的

UI 必须让玩家在不理解程序结构的情况下读懂五件事：当前处于哪个阶段、现在能做什么、队伍状态如何、自己的构筑产生了什么效果、下一次构筑应如何根据对手调整。

## 主流程

```text
MainMenu
→ LocalMatchConfirm
→ OpeningBuild
→ CombatHUD
↔ Build2 / Build3 / Build4 / Build5
→ FirstPlayableResult
→ MainMenu
```

主流程不进入 CharacterSelect、StartupSelect 或武器选择。旧 Shop、ThreeChoice、SelfTattoo、TattooEnchant、TattooStudio 和熟练度界面均不属于当前产品流程。

## 主菜单

### 必要入口

- 开始游戏。
- 纹身与元素档案。
- 玩法帮助。
- 设置。
- 制作人员。
- 退出确认。
- 版本与构建信息。

开发构建额外提供：

- match seed 设置或显示。
- 快速模式入口。

当前不显示：

- 账号。
- 好友。
- 商店。
- 排行榜。
- 继续游戏。
- 角色选择。
- 武器选择。

## 本地对局确认

开始游戏后先明确告诉玩家：

- 本局共 6 人。
- 组成 3 支双人队。
- 空位由 Bot 补齐。
- 对局包含五轮和四次缩圈。
- 当前是本地 First Playable，不连接后端。
- 开发模式下显示 seed 和快速模式状态。

确认后才创建 roster、team 和 match seed，进入 OpeningBuild。

## CombatHUD 最低信息

### 战斗状态

- 当前轮次和阶段。
- 当前阶段剩余时间。
- 下一次缩圈或构筑提示。
- 安全区方向、边界和圈外风险。
- 生命、护盾和倒地状态。
- 枪械基本状态、准星和命中反馈。

### 队伍状态

- 队友生命、护盾、倒地、淘汰或撤离状态。
- 救援可用性和距离/范围提示。
- 队伍剩余人数。

### 构筑与元素

- 自身当前纹身摘要。
- 左臂纹身授予的主动技能、可用状态和必要使用反馈。
- 火、冰、雷状态和弱/标准/强层级。
- 主要反应反馈。
- 直接伤害与间接元素伤害的可区分反馈。

### 撤离

- 撤离是否未解锁、已解锁或已失效。
- 合法撤离点位置和范围提示。
- 持续交互进度。
- 中断原因。

## 构筑界面

构筑界面需要同时支持：

- 六个身体部位选择。
- P01/P02 图案选择。
- 火、冰、雷元素选择。
- 当前颜料数量。
- 装备消耗 10、拆除返还 6 的明确反馈。
- 装备、替换、拆除的结果预览。
- 左臂装备后将获得的纹身主动技能预览；拆除或替换时明确提示技能将移除或变化。
- 当前阶段剩余时间。
- Ready/完成状态或明确的自动收口提示。
- 切换到六人情报。
- 向队友请求颜料。

战斗阶段打开同类信息时只能只读，修改控件和业务命令同时禁用。

## 六人情报

建议以三支双人队分组，避免六张同权重卡片造成扫描困难。

### 默认层

- 队伍和玩家身份。
- 存活、淘汰或撤离状态。
- 主要纹身和元素摘要。
- 关键成果摘要。

### 展开层

- 六部位完整构筑。
- 每个纹身的无数值效果文本。
- 基础属性与局内强化拆分。
- 完整精确成果。

界面必须提示“这是本构筑阶段开始前的快照”，避免玩家误以为数据实时更新。

## 颜料请求界面

- 选择火、冰或雷。
- 显示自己和队友当前可见数量。
- 设置请求数量，最大值不超过队友发起时库存。
- 队友看到请求来源、颜色、数量以及同意/拒绝。
- 批准失败时说明“库存已变化”，不能只显示未知错误。
- 阶段结束、请求过期或对局状态变化时安全关闭。

## 倒地、救援、淘汰与观战

### 倒地者

- 倒地生命。
- 20 秒流血倒计时。
- 队友是否正在救援。
- 构筑阶段开始前未救起将淘汰的预警。

### 救援者

- 3 秒救援进度。
- 有效范围。
- 中断原因：离开范围、受控、倒地或主动中止。

### 淘汰者

- 淘汰原因与归因。
- 当前观战队友。
- 队伍是否仍有存活成员。

## Result

结果至少表达：

- 胜利、失败、平局或 `LocalTeamExtracted`。
- match seed 和模式。
- 五轮阶段结果与结束原因。
- 三支队伍最终状态。
- 六人最终构筑。
- 个人精确成果。
- 返回主菜单入口。

返回时要等运行时清理完成，再恢复可交互主菜单。

## 界面层级与时序

- 所有 Form 通过 GF_X UI service 管理。
- 构筑倒计时使用 unscaled time。
- 构筑结束先安全结束请求和弹窗，再切换 HUD，最后恢复战斗模拟。
- 暂停菜单不得推进战斗世界。
- InputModule 是所有界面按键的入口。
- 最终美术未交付时允许占位资源，但不能把占位视觉标为正式验收。

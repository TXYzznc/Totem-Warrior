# 地图资源与撤离

> 状态：地图资源与测试撤离已实现；正式撤离经济暂未设计

## 系统目的

地图资源为战斗轮提供探索和发育目标，撤离为对局提供不依赖“最后一队存活”的成功路径。两者都依赖 OasisCity 中显式配置的合法锚点，确保玩法位置由关卡设计控制且可重复验证。

## OasisCity 权威地图

- 本地对局从 Launch 确认后，先以 additive 方式加载 OasisCity。
- OasisCity 成为活动玩法场景后，运行时才构建地图快照和生成参赛者。
- 旧 `Assets/Resources/PCG`、PCGMap 和空 TotemGame 不再提供运行地图。
- 返回主菜单时恢复 Launch、卸载 OasisCity 并清理运行时对象。

## 三类合法锚点

| 锚点类型 | 用途 | 最低要求 |
|---|---|---|
| PlayerSpawn | 三支队伍出生 | 至少满足三队相邻出生组，场景配置至少六个玩家位置 |
| MapResource | 每轮资源拾取生成 | 数量满足当前刷新配置 |
| Extraction | 解锁后撤离点生成 | 至少 3 个合法点 |

三类锚点拥有独立 ID 空间和用途，不得互相冒充，也不得使用任意 fallback 坐标掩盖场景缺失。

## 地图资源配置

每条 `MapResourcePickupConfig` 至少定义：

- 稳定记录 ID。
- 资源类别和资源 ID。
- 元素。
- 最小数量。
- 最大数量。
- 生成权重。
- 可出现轮次。
- 资源表现键。
- 是否启用。

不同种类拾取物可以使用不同数量区间。同一记录的数量在自己的闭区间内按 seed 确定性随机。

## 当前数量档位

- 小型：4～6。
- 中型：8～12。
- 大型：16～20。

具体记录选择哪个档位由配置决定，不使用一个全局数量覆盖所有资源。

## 资源生成

- 每轮战斗开始时从合法 MapResource 锚点选择位置。
- 类型、数量和位置共同由 match seed、轮次、活动配置和锚点集合决定。
- 相同输入必须产生相同结果。
- 重复锚点、禁用锚点和不可达锚点被拒绝并提供诊断。
- 构筑阶段不能拾取资源。

## 当前资源池

允许：

- 火颜料。
- 冰颜料。
- 雷颜料。
- 配置中明确允许的基础资源。

禁止：

- 旧多武器与武器升级。
- 角色固有技能或技能拾取物；左臂纹身技能只能通过构筑获得。
- P03～P08 体验卡。
- EnemyLoot。
- Boss 核心。
- 高阶撤离资源。

拾取后进入当前参赛者个人库存，不自动分给队友。

## 测试版撤离解锁

First Playable 用人工输入替代未来 Boss 击杀事件：

- 只从 Round4Combat 起接受解锁。
- 组合键为 `Shift + Space`。
- 普通空格仍用于闪避。
- 输入必须来自 InputModule。
- 同一局只能成功解锁一次。
- 更早输入和重复输入被拒绝。
- 解锁服务本身不依赖键盘，未来 Boss 可调用同一 `TryUnlock` 权威入口。

## 撤离点生成

- 解锁后从专用 Extraction 锚点中抽取。
- 默认生成 3 个。
- 使用 match seed 确定性选择。
- 位置可达且不重复。
- 生成后不移动。
- 不使用 PlayerSpawn 或 MapResource 锚点替代。

## 撤离交互

存活且未倒地的本地真人：

1. 进入撤离范围。
2. 持续按住 `F` 3 秒。
3. 期间保持在范围内、不倒地、不受有效伤害。
4. Bot 队友不能处于倒地状态。
5. 完成后整支本地队伍中所有未淘汰成员进入 Extracted。

松开、离开范围、倒地或受到有效伤害时，进度中断并清零。

## First Playable 结算

当前没有后端和真实联机，因此本地队伍撤离成功后：

- MatchFlow 立即停止。
- 结果标记为 `LocalTeamExtracted`。
- 进入现有 Result 流程。
- 不继续模拟其他 Bot 队伍。

未来服务器版本可以让已撤离队离场、其余队伍继续，但不能改变解锁、合法锚点和 3 秒交互合同，除非形成新的设计决策。

## 长期撤离方向

- Boss 被击败后解锁撤离。
- 第五轮缩圈不移动撤离点，但可能让部分点落到圈外。
- 提前撤离降低风险，继续争夺高阶资源提高收益和被淘汰概率。
- 正式战利品保留、掉落和局外经济尚未设计。

# 元素状态与反应

> 状态：First Playable 数值与规则已确认并实现；可读性和平衡待试玩验证

## 系统目的

元素与纹身颜色结合，为同一图案和枪械提供不同的持续压力、控制和团队组合。元素不是一次命中后永久保留的标签，而是会叠层、刷新、衰减并被反应消耗的临时战斗状态。

## 三种元素

- 火。
- 冰。
- 雷。

First Playable 只使用这三种元素，以保持反应关系容易理解并形成稳定的三组合。

## 三层强度

每种元素在目标身上具有三个强度层级：

| 层级 | 含义 |
|---|---|
| 弱 | 初次施加，下一次衰减或反应后消失 |
| 标准 | 再次施加同元素后提升 |
| 强 | 第三次施加达到上限，再次施加只刷新时间 |

同元素施加规则：

1. 无状态时成为弱层。
2. 弱层提升为标准层。
3. 标准层提升为强层。
4. 强层不继续增加，只刷新衰减计时。
5. 每次成功施加同元素都把下一次衰减时间重置为 3 秒。

## 持续时间与衰减

- 每经过 3 秒自然消耗一层。
- 强层衰减为标准层。
- 标准层衰减为弱层。
- 弱层衰减后元素消失。
- 进入构筑阶段时清除全部元素层、来源队列、特性 tick 与衰减计时。
- 元素状态不会冻结并跨构筑阶段继承；下一战斗阶段从无元素附着状态开始。

## 来源记录

每一层元素记录：

- 元素类型。
- 来源参赛者。
- 施加顺序。
- 剩余时间。

同元素多次施加时保留层来源队列，消费遵循 FIFO。这样反应发生时能够知道被消费的旧元素由谁施加，而不是把贡献全部归给最后命中的人。

## 元素自身特性

### 火：持续灼烧

- 每 0.5 秒结算一次。
- 弱/标准/强使用 1/1.25/1.5 的层级系数。
- 用于制造持续生命压力和迫使目标处理战斗窗口。

### 冰：移动减速

- 弱层减速 12%。
- 标准层减速 20%。
- 强层减速 28%。
- 当前数值是早期候选值的两倍，后续仍需验证是否影响射击和撤离公平性。

### 雷：受击放电

- 带雷目标受到有效直接伤害时尝试放电。
- 每 0.5 秒至多触发一次。
- 优先命中距离最近的同阵营次要目标。
- 附近没有合法次要目标时，以正常放电值 50% 的伤害回到目标自身。
- 该效果鼓励被施加雷元素的队伍分散站位，同时为集火提供收益。

## 异元素反应通则

目标已有一种元素时，再施加不同元素：

1. 新元素不留在目标身上，而是用于触发反应。
2. 已有元素消耗一层。
3. 已有弱层被消费后完全消失。
4. 反应组合与施加先后顺序无关。
5. 不设置全局反应冷却。
6. First Playable 中反应是终止节点，不生成新的事件。

## 三种反应

### 火 + 冰：热冲击

- 造成 0.6 倍枪械身体命中伤害。
- 先火后冰与先冰后火结果一致。
- 主要提供明确、直接的组合爆发。

### 火 + 雷：过载

- 对中心目标造成 0.35 倍枪械身体命中伤害。
- 对 3 米内其他合法目标造成 0.25 倍伤害。
- 产生轻击退。
- 主要用于惩罚聚集和改变站位。

### 冰 + 雷：停滞

- 目标在 2 秒内造成的直接伤害降低 20%。
- 主要提供压制窗口和队伍攻防转换。

## 友伤与反应

- 同队元素和反应伤害为 0。
- 射击队友不会施加元素，也不会触发反应。
- 范围反应只对合法敌对目标生效。
- 无效友伤不计成果。

## 反馈要求

玩家至少需要理解：

- 当前元素类型和弱/标准/强层级。
- 下一层衰减即将发生。
- 本次命中施加了元素还是触发了反应。
- 反应类型和主要结果。
- 雷放电目标、火焰 tick 和冰减速的来源。

表现可以使用颜色、图标、Shader、粒子和音效，但不能只依赖颜色，以免层级和反应在混战中不可读。

## 试玩观察项

- 3 秒衰减是否给玩家足够的协作触发窗口。
- 0.5 秒火焰 tick 是否过于频繁或遮蔽直接伤害反馈。
- 冰的 12/20/28% 是否造成失去控制感。
- 雷是否在双人队站位中产生可理解的分散压力。
- 三种反应是否各自改变战斗行为，而不只是不同伤害倍率。

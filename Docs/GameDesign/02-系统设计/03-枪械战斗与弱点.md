# 枪械战斗与弱点

> 状态：单枪械合同、基础数值与射击操控已确认；现有实现待对齐，最终手感仍需试玩调优

## 系统目的

第一版只保留一种枪械，把测试重点放在命中、弱点、纹身事件、元素、队友配合和构筑反制上。多武器会同时引入射程、射速、弹药、动作、数值和资源平衡，容易掩盖纹身系统本身的问题。

## First Playable 武器边界

- 活动武器只有基础步枪 `rifle_patrol_v1`。
- 所有参赛者使用同一武器定义。
- 不启用近战武器、蓄力武器、投射物武器和多武器切换。
- 不启用武器等级、随机词条和弹药耗尽后的近战降级。
- 玩家没有角色自带主动技能；主动技能由左臂纹身授予，属于纹身系统而非枪械系统。
- 最终枪型、手感和数值仍可通过配置调整。

## 首版基础数值基线

| 参数 | 数值 |
|---|---:|
| 玩家最大生命值 | 150 |
| 初始护盾 | 0 |
| 基础步枪身体命中伤害 | 16 |
| 玩家头部弱点倍率 | 1.5 倍 |
| 玩家头部弱点伤害 | 24 |
| 射击间隔 | 0.5 秒 |
| 有效射程 | 30 米 |
| 普通移动速度 | 5 米/秒 |

- 射程内不做伤害衰减。
- First Playable 不实现弹匣容量、换弹和弹药消耗；枪械射击节奏只由射击间隔限制。
- 玩家没有初始基础护盾。纹身或后续正式效果仍可以提供临时护盾。
- 弱点伤害只对基础步枪本次直接伤害应用 `1.5` 倍倍率；所有以“基础伤害”为基数的纹身效果仍以 16 点身体命中伤害计算，不能重复取得弱点倍率。
- 开发测试治疗按钮按最大生命值的 20% 恢复，因此当前基线下每次恢复 30 点生命。

## 射击操控规则

- 基础步枪使用命中扫描。正式开火时立即从当前准星方向执行射线判定，不生成具有飞行时间的实体弹丸。
- 玩家按住鼠标左键可以持续射击；武器按 0.5 秒射击间隔产生合法射击。输入必须经过 InputModule。
- 真人玩家的射线严格沿屏幕准星指向，不使用目标自动选中、角度锥吸附或自动修正到身体/头部。
- First Playable 不加入随机散布。普通移动也不改变射线方向或增加散布。
- First Playable 不加入会改变实际弹道的后坐力；允许使用枪口、镜头、动画和音效表现射击反馈，但表现不得偷偷修改命中结果。
- 场景遮挡物会阻断射线。射击不能穿墙，也不能穿透第一个被命中的玩家继续伤害后方目标。
- 当前实现中的 12 度目标筛选锥不属于正式真人射击规则，后续实现必须移除或停止用于真人命中判定。
- Bot 使用同一武器伤害、射击间隔、射程、遮挡和命中区域规则，但其瞄准强度由独立的反应延迟、转向能力和瞄准误差控制；Bot 不通过真人瞄准辅助规则获得命中。

### 设计理由

第一版需要直接验证弱点瞄准、走位、闪避和纹身构筑。随机散布或宽角度自动吸附会让操作结果无法稳定归因，因此暂不引入。后续若枪感过于平淡，优先测试玩家可学习、可预测的后坐力模式，而不是不可控的随机散布。

### 理论击倒时间参考

以下只计算基础步枪，不计算闪避、护盾、纹身、元素、反应和网络延迟；第一发命中计为时间零点：

| 命中情况 | 所需命中 | 理论时间 |
|---|---:|---:|
| 单人全部身体命中 | 10 次 | 约 4.5 秒 |
| 单人全部弱点命中 | 7 次 | 约 3 秒 |
| 双人同步集火身体 | 5 轮齐射 | 约 2 秒 |
| 双人同步集火弱点 | 4 轮齐射 | 约 1.5 秒 |

该基线的目标是让单人交战保留反应、闪避和构筑介入空间，同时让双人同步集火保持明确威胁。上述时间是平衡参照，不是必须稳定复现的实战结果。

## 有效直接伤害

一次枪械命中要成为“有效直接伤害”，必须依次通过：

1. 命中目标合法。
2. 攻击者与目标不是同队。
3. 目标当前状态允许受到伤害。
4. 护盾或生命实际减少正数。

只有完成以上结算后，普攻相关右臂效果、元素施加和后续反应才有资格进入效果队列。视觉命中但实际伤害为 0，不算有效直接伤害。

### 直接与间接伤害边界

- 基础普攻造成的伤害属于直接伤害。
- 左臂纹身主动技能造成的伤害属于直接伤害。
- 其他部位纹身追加或范围效果造成的伤害属于间接纹身伤害。
- 火焰灼烧、雷元素放电和元素反应造成的伤害属于间接元素伤害。
- 间接伤害可以正常扣除生命、造成倒地或淘汰，并按来源进入成果统计。
- 间接伤害不能再次触发头部、右臂、躯干或其他以直接攻击结果为入口的纹身效果，避免纹身之间形成未设计的递归触发链。

## 身体与弱点

- 所有玩家和 Bot 都提供身体伤害基线。
- 玩家头部是明确弱点。
- 射线命中需要区分身体 collider 和头部 collider。
- 弱点上下文进入优先级 70 的头部事件。
- 普攻相关右臂事件优先级为 60，因此同一次有效弱点命中先结算头部事件，再结算右臂效果。

## 普攻相关右臂触发规则

右臂纹身承载**普攻相关效果**，不与枪械这一武器类别永久绑定。First Playable 当前只有基础步枪，因此本版本由枪械普攻触发；未来即使普攻载体改变，右臂语义仍保持“普攻相关”。

当前普攻右臂按“造成有效直接伤害时触发”，而不是按按下开火、射线命中或产生命中特效触发。

以下情况不触发：

- 命中同队成员。
- 目标处于完全免伤状态。
- 伤害被规则抵消为 0。
- 射击未命中合法伤害区域。
- 目标已经不处于可受击战斗状态。

## 输入边界

- 真人开火、瞄准、闪避、交互、救援、构筑和菜单输入统一经过 InputModule 对应的 `TotemInputService` / `ITotemInputProvider`。
- 业务 MonoBehaviour 不直接读取 `Input` 或 Input System device。
- Bot 通过 AI command provider 产生相同层级的攻击命令，不伪造设备输入。

## 基础闪避

### 首版参数

| 参数 | 数值 |
|---|---:|
| 动画帧数 | 8 帧 |
| 动画帧率 | 12 FPS |
| 动画总时长 | 约 0.67 秒 |
| 基础位移距离 | 4 米 |
| 位移阶段 | 约 0～0.4 秒 |
| 无敌帧 | 第 2～5 帧，约 0.083～0.417 秒 |
| 左腿纹身事件 | 第 6 帧，约 0.417 秒 |
| 基础冷却 | 1.5 秒，从合法闪避开始时计算 |

无敌只占完整闪避动画的 50%。第 1 帧是可受击起手，第 6～8 帧是可受击收尾，因此闪避需要判断时机，并保留可惩罚窗口。

### 方向与合法终点

- 闪避输入必须通过 InputModule。
- 有普通移动输入时，使用摄像机相对的水平移动方向；移除 Y 分量后归一化。
- 没有移动输入时，使用摄像机朝向在水平面的投影。
- 摄像机水平投影无效时，使用角色当前水平朝向兜底。
- 闪避开始后固定本次方向，镜头变化不再改变本次位移。
- 闪避只产生水平位移，不考虑垂直方向向量。
- 开始时预计算 4 米目标点经过地图、碰撞和边界约束后的合法终点。
- 被阻挡时截断到最近合法位置；即使实际位移不足 4 米，仍消耗本次闪避和基础冷却。
- 角色在约 0.4 秒内移动到合法终点。
- 冰元素减速不缩短闪避距离；禁止行动的强控制会阻止闪避开始。
- 闪避及其他强制位移不积攒右腿纹身能量。

### 行动限制

闪避动画期间不能普通移动、开火、激活或触发左臂技能、救援、拾取、撤离交互或再次闪避。第一版不缓存这些输入；镜头仍可转动。

### 动画事件与安全兜底

- 第 2 帧动画事件开启无敌。
- 第 6 帧首先关闭无敌，再触发左腿纹身事件。
- 动画结束事件确认动作结束并恢复普通行动。
- 动画事件携带动作序号与创建时 `PhaseEpoch`；旧动作或旧阶段事件直接失效。
- 战斗状态机必须提供超时兜底。动画事件缺失、动画被替换或混合异常时，最迟在配置的闪避结束时点关闭无敌并结束动作，不能产生永久无敌。
- 每次构筑阶段结束进入下一战斗时，基础闪避冷却刷新为立即可用。

## 弱点表现原则

玩家的弱点是头部，通常可由人体结构自然理解。未来非人型 Enemy 的弱点不一定显而易见，需要额外表现：

- Shader 高亮或受击反馈。
- 在敌人预制体弱点处配置可闪光对象。
- 材质、轮廓、动画或粒子提示。
- 图鉴或遭遇教学。

具体做法属于后续 Enemy/PVE 与美术设计，不进入当前纯 PVP 实现。

## 单枪械验证目标

- 玩家是否能清楚区分身体命中和头部弱点。
- 普攻右臂只在有效伤害后触发是否符合直觉。
- 构筑和元素是否能在同枪械基础上改变战斗决策。
- 高操作玩家是否能通过弱点命中和位置提高非最优构筑上限。
- 武器本体是否过强，以至于纹身和元素没有存在感。

## 后续扩展门槛

新增武器前必须证明它改变的是可读的战斗行为，而不是只增加伤害档位。每新增一种武器都要重新检查弱点、普攻右臂、元素施加、效果队列、Bot 行为、UI 和构筑平衡矩阵。

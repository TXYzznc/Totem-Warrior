## 阅读与实现边界

- 本目录解释玩家规则、设计意图和跨系统关系。
- 本目录是唯一策划标准；精确程序 MUST/SHALL、异常条件和自动测试场景由 `openspec/specs/` 从本目录派生。
- 具体运行代码与配置是实现，不反向自动成为策划规则；发现差异时，以本目录为准修正实现资料。
- OpenSpec 已归档 change 位于 `openspec/changes/archive/2026-08-12-rebuild-six-player-pvpve-first-playable/`。

## 跨系统关键时序

```text
阶段切换请求
→ MatchFlow 确认当前阶段合法
→ 若进入构筑：结算倒地边界
→ 捕获六人情报快照
→ 暂停战斗模拟
→ 打开构筑 UI
→ 倒计时结束并关闭临时弹窗
→ 若需要则执行缩圈
→ 恢复战斗模拟
```

```text
枪械命中
→ 校验目标、队伍和命中部位
→ 护盾/生命应用有效直接伤害
→ 只收集本次合法效果
→ 按优先级和 seed 排序
→ 逐项结算弱点、普攻相关右臂效果、元素与反应
→ 更新倒地/淘汰和本局成果
→ 只产生一次实际生命扣减和一致的表现指令
```

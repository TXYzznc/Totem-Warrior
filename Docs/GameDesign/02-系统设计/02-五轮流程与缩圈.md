# 五轮流程与缩圈

> 状态：阶段规则已确认并实现；具体时长与半径待试玩调优

## 系统目的

五轮流程把一次对局拆为可阅读的决策周期。玩家不能在战斗中随时修正构筑，而是在战斗结果已经产生后进入暂停窗口，观察所有人上一边界的信息，再押注下一轮方案。

## 权威阶段顺序

```text
FrontEnd
→ OpeningBuild（60 秒）
→ Round1Combat
→ Build2（45 秒）
→ Shrink1
→ Round2Combat
→ Build3（45 秒）
→ Shrink2
→ Round3Combat
→ Build4（45 秒）
→ Shrink3
→ Round4Combat
→ Build5（45 秒）
→ Shrink4
→ Round5Combat
→ Result
```

任何服务不得跳过、回退或自行插入阶段。当前纯 PVP 版本的 Round4Combat 和 Round5Combat 不包含 Boss 或 Enemy。

## 构筑阶段

### OpeningBuild

- 持续 60 秒。
- 玩家尚未经历战斗，主要用于理解初始资源、选择首套纹身和确认队友方向。
- 完成后队伍从合法出生锚点生成并进入第一轮战斗。

### Build2～Build5

- 每次持续 45 秒。
- 进入前先处理仍处于倒地状态的玩家。
- 随后冻结全员构筑与本局成果快照。
- 玩家可以装备、替换和拆除纹身，也可向队友请求颜料。
- 倒计时结束时，未关闭的请求和弹窗必须安全收口，不能把修改事务带入战斗阶段。
- 构筑阶段结束时统一刷新所有已装备纹身效果的冷却和左臂纹身主动技能冷却，再进入后续战斗流程。

## 构筑暂停规则

构筑阶段停止：

- 参赛者移动。
- Bot 战斗决策。
- 枪械攻击与伤害应用。
- 元素伤害 tick、持续时间和逐层衰减。
- 地图资源拾取。
- 缩圈和圈外伤害。
- 战斗阶段时钟。

构筑 UI 使用不受世界暂停影响的倒计时。恢复战斗后，元素等状态从进入构筑时的剩余时间继续，而不是重新开始或在暂停期间过期。

## 缩圈规则

- Shrink1～Shrink4 分别发生在 Round2～Round5 开始前。
- 正常模式每次缩圈持续 30 秒。
- 快速测试模式每次缩圈持续 10 秒。
- 目标半径、圈外伤害、持续时间和偏移方式来自 `ZoneShrinkConfig`。
- 缩圈是动态过程，不是瞬间切换。
- 所有地图消费者使用 OasisCity 的权威世界边界和初始中心。

## 空间节奏目标

- Round1～Round3：区域较大，主要支持探索、颜料收集和局部遭遇；PVP 始终合法。
- Round4：当前版本提高相遇概率并开放测试撤离；长期版本在此刷新 Boss。
- Round5：最小活动区域承载最高强度 PVP 和困难撤离。

## 构筑边界与倒地

倒地不能跨入暂停构筑。进入任意 Build 阶段前：

1. 检查所有倒地参赛者。
2. 尚未被救起者立即淘汰。
3. 清理救援进度。
4. 再捕获六人快照。

因此快照展示的是边界结算后的真实存活与淘汰状态。

## 第五轮结果

若比赛未提前结束，Round5Combat 结束时按以下顺序比较：

1. 队伍淘汰数。
2. 玩家伤害。
3. 存活人数。
4. 剩余生命。
5. 所有字段完全一致则为平局。

## 快速模式

快速模式用于自动化和开发验证，不改变阶段顺序、效果合法性和结算规则。它只缩短战斗/缩圈等配置时间。相同 seed 和输入在快速与正常模式下，除时间相关配置外应产生可比较结果。

## 试玩调优项

- 60/45 秒是否给足阅读和修改时间。
- 构筑频率是否打断射击节奏。
- 缩圈过程是否清晰，是否产生无预警圈外伤害。
- 前三轮是否太少相遇或太早团灭。
- Round4/5 在没有 Boss 的当前版本中是否缺少明确目标。

# First Playable 完整流程与测试撤离

> 状态：流程已实现并具有自动化闭环证据

## 版本起点

玩家从 Launch 进入 MainMenu。发布模式展示必要菜单；开发模式额外允许设置或读取 seed、选择快速模式。

## 流程总览

```text
MainMenu
→ 选择开始游戏
→ LocalMatchConfirm
→ 确认 6 人 / 3 队 / Bot 补位 / 五轮 / 四次缩圈
→ 创建 match seed、roster 和 team
→ Additive 加载 OasisCity
→ 构建地图锚点快照
→ OpeningBuild（60 秒）
→ 生成三支队伍
→ Round1Combat
→ Build2（45 秒）
→ Shrink1
→ Round2Combat
→ Build3（45 秒）
→ Shrink2
→ Round3Combat
→ Build4（45 秒）
→ Shrink3
→ Round4Combat
→ 可触发测试撤离解锁
→ Build5（45 秒）
→ Shrink4
→ Round5Combat
→ Result
→ 清理对局并卸载 OasisCity
→ MainMenu
```

任意战斗阶段若只剩一支存活队伍，可以提前进入 Result。本地队伍测试撤离成功也立即进入 Result。

## MainMenu 到对局确认

- 开始游戏不进入角色或武器选择。
- LocalMatchConfirm 明确展示当前版本规则。
- 确认前不创建战斗参赛者，避免取消后残留。
- 确认后生成 seed 和队伍，并开始加载权威场景。

## OasisCity 加载

固定顺序：

1. Launch 保持持久场景。
2. additive 加载 OasisCity。
3. 将 OasisCity 设为活动场景。
4. 读取 PlayerSpawn、MapResource、Extraction 与世界边界。
5. 构建运行时地图快照。
6. 进入构筑/HUD 流程。
7. 在正确时机生成 6 名参赛者。

任何一步失败都应明确中止，而不是回退到旧 PCG 或任意坐标继续。

## OpeningBuild

- 玩家拥有初始可用图案与颜料。
- 可在六部位中选择 P01/P02 和火冰雷。
- 每次装备消耗 10。
- 首次没有上一轮成果，情报以初始状态为主。
- 倒计时使用 unscaled time。
- 完成后从三个独占出生组生成队伍。

## 每轮战斗

战斗阶段允许：

- 移动、瞄准、开火和闪避。
- 敌队互相伤害。
- 纹身和元素效果触发。
- 拾取合法地图资源。
- 倒地、救援和处决。

禁止：

- 修改纹身。
- 绕过请求直接共享颜料。
- 生成 Enemy 或 Boss。

## Build2～Build5

每次进入按以下顺序：

1. 结算未救起倒地者为淘汰。
2. 冻结六人边界快照。
3. 暂停战斗世界。
4. 打开构筑 UI。
5. 玩家查看对手、修改纹身、请求颜料。
6. 倒计时归零时终止未完成事务。
7. 关闭构筑 UI。
8. 执行对应缩圈。
9. 进入下一轮战斗。

## 测试撤离完整流程

### 解锁

```text
进入 Round4Combat 或之后
→ InputModule 检测 Shift + Space
→ 同帧不执行普通空格闪避
→ 撤离服务 TryUnlock 校验阶段与整局一次限制
→ 发布撤离解锁事件
→ 从 Extraction 锚点按 seed 抽取默认 3 点
→ 生成可视撤离点
```

### 交互

```text
本地真人存活且未倒地
→ Bot 队友不处于倒地状态
→ 进入撤离范围
→ 按住 F
→ 连续保持 3 秒
→ 未离开、未松开、未倒地、未受有效伤害
→ 提交整队撤离事务
```

### 结算

- 本地真人标记为 Extracted。
- 同队所有未淘汰成员标记为 Extracted。
- 已淘汰队友保持淘汰。
- MatchFlow 立即停止。
- 结果为 `LocalTeamExtracted`。
- 不继续运行其余 Bot 队。

## 正常第五轮结算

如果没有提前结束或撤离：

- Round5Combat 超时后比较淘汰数、玩家伤害、存活人数、剩余生命。
- 全部相同为平局。
- 保存 seed、模式、阶段时长、队伍、构筑、成果、异常和配置版本。

## 返回主菜单

固定清理：

1. 停止 MatchFlow 和所有战斗模拟。
2. 清理参赛者、Bot、投射/表现运行对象、资源拾取和撤离点。
3. 清理构筑、元素、队伍、成果和地图运行态。
4. 恢复 Launch 为活动场景。
5. 卸载 OasisCity。
6. 打开可交互 MainMenu。

再次开始时只能存在一份 OasisCity 和一套新对局状态。

# 决策记录

> 这里只记录已确认结论及其原因；会话和 OpenSpec 保存过程证据。

## 当前有效决策

| 决策 | 结论 | 原因 |
|---|---|---|
| 对局规模 | 6 人，3 支双人队；不足由 Bot 补齐 | 降低独立游戏在线人数门槛 |
| 联机边界 | First Playable 不做后端；本地队伍撤离后结束对局 | 先快速验证完整结构 |
| 武器边界 | 第一版只实现一种枪械 | 控制生产规模，将差异集中到纹身构筑 |
| 基础战斗数值 | 150 最大生命、0 初始护盾、步枪身体伤害 16、头部 1.5 倍、0.5 秒射击间隔、30 米射程、5 米/秒移速 | 单人交战保留反应空间，同时维持双人集火威胁 |
| 首版弹药边界 | 不做伤害衰减、弹匣、换弹和弹药消耗 | 减少干扰纹身与元素验证的额外变量 |
| 首版射击操控 | 命中扫描、按住连射、准星直射、无真人吸附、无随机散布和弹道后坐力、无穿透 | 让命中结果稳定归因于瞄准、走位和构筑，不被随机性覆盖 |
| Bot 瞄准 | 共用武器结算规则，以独立反应延迟、转向和瞄准误差控制强度 | 避免 Bot 借用真人瞄准辅助并保持难度可调 |
| PVP 限制 | 前三轮不禁止 PVP | 通过较大活动区域自然降低遭遇概率 |
| 构筑窗口 | 仅构筑阶段可修改，战斗期间只读 | 形成观察、预测和应对循环 |
| 构筑情报 | 每次构筑开始公开此前快照与全局成果具体数据 | 支持针对对手进行反制 |
| 图案命名 | 暂用 P01～P08，不按外形擅自命名 | 正式名称尚未设计 |
| First Playable 图案 | 仅 P01/P02；初始可用 | 快速验证图案 × 部位 × 元素框架 |
| 图案目标结构 | P01 为瞄准单体；P02 为目标点范围内全部合法敌人 | 保持单点与范围选择差异 |
| 部位语义 | 头部弱点、右臂普攻、左臂主动技能、躯干受击、左腿闪避、右腿移动蓄能 | 为 12 个效果提供清晰事件入口 |
| 技能来源 | 玩家无角色固有技能；左臂纹身授予主动技能 | 让技能本身成为构筑结果 |
| 冷却 | 每个图案 × 部位独立配置；构筑结束刷新全部纹身冷却 | 支持扩展并保证每轮公平起点 |
| 12 效果 | P01/P02 × 六部位各自拥有不同效果 | 避免只换触发条件的同质构筑 |
| 伤害分类 | 普攻与左臂技能是直接伤害；其他纹身、元素特性与反应是间接伤害 | 阻止纹身递归触发，同时保留伤害和成果归因 |
| 右腿蓄能来源 | 只计算普通移动产生的实际平面位移 | 排除闪避和强制位移刷能量 |
| 倒地与纹身 | 倒地者不触发纹身，也不受纹身效果作用，且不能获得护盾等效果 | 保持倒地处决规则清晰，避免倒地构筑继续运转 |
| 左臂技能输入 | 技能键激活，左键触发，右键取消；正式触发才开始冷却 | 支持单体瞄准和自由选点，取消不惩罚 |
| 构筑边界 | 每个战斗阶段使用 `PhaseEpoch`；切入构筑后旧 Epoch 延迟逻辑失效，并清除临时战斗状态 | 防止迟到动画事件、延迟爆发和异步回调跨轮生效 |
| 基础闪避 | 8 帧/12 FPS、4 米、1.5 秒冷却；第 2～5 帧无敌，第 6 帧触发左腿纹身 | 支持高频闪避，同时保留起手和收尾可惩罚窗口 |
| First Playable 治疗 | 当前不设计正式治疗或轮间恢复；开发模式提供 20% 最大生命、1 秒冷却的本地测试按钮 | 等后续技能和事件统一设计治疗生态，同时保留快速测试手段 |
| 右腿 P01 满能量 | 追加 `0.9×`基础伤害，不移除移动散布惩罚 | 当前没有移动散布机制，避免低收益高成本实现 |
| 元素层级 | 弱、标准、强；反应消耗一层，弱层反应后消失 | 控制状态复杂度并保留组合空间 |
| 反应冷却 | 不设全局反应冷却 | 允许事件队列正常表达组合结果 |
| 事件并发 | 按优先级入队，同优先级稳定随机，依次结算 | 保证结果可解释、可测试且表现清晰 |
| Enemy/PVE | 当前完全不实现，后续重新设计 | 旧方案已失效，避免错误内容继续扩散 |

## 已取消或替代

- 20 人实时对局。
- 战斗中随时修改纹身。
- P02 只寻找一个邻近目标。
- 右臂永久命名为“枪械臂”。
- 左腿闪避后暂存到下一次普攻。
- 全局元素反应冷却。
- First Playable 的 Enemy/PVE/Boss 实现。
- 右腿 P01 的移动散布惩罚移除。

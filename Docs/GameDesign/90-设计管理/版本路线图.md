# 版本路线图

## First Playable：纯 PVP 结构验证

- 6 人、3 支双人队、Bot 补位。
- 单一基础枪械。
- 五轮构筑与战斗、四次缩圈。
- P01/P02 × 六部位的 12 个纹身效果。
- 火、冰、雷三层元素与三种反应。
- 地图资源、倒地救援、情报、颜料请求和测试撤离。
- 不做后端联机，不做 Enemy/PVE/Boss。

当前主要工程目标不是继续修补旧业务层，而是保留 GF_X、Launch、OasisCity、交互物和已确认美术，在新领域合同与新业务数据上分阶段重建 First Playable。旧业务代码、旧业务 DataTable/Catalog、旧 UI 入口和旧规则测试在新链路接管、零引用验证和回归通过后清理。

开发按 [First Playable 开发路线总览](../05-开发计划/第一版开发路线总览.md) 的六个程序里程碑和三个美术验收门推进；具体顺序、依赖、工时和状态以用户维护的《第一版开发任务表.xlsx》为准。

## 后续版本：恢复 PvPvE 主循环

在 First Playable 的 PVP、构筑和元素基础验证后，再独立设计并接入：

- Enemy/PVE 内容与探索压力。
- 第四轮 Boss 多人挑战。
- Boss 贡献强化与击杀者特殊效果。
- Boss 击败后解锁正式撤离点和高阶资源。
- 第五轮高强度 PVP 与高风险撤离。

## 更远期扩展

- P03～P08 及图案体验卡。
- 更多枪械与更丰富构筑，但必须避免超出单开发者与 AI 的生产力边界。
- 元素反应链。
- 差异化颜料消耗。
- 实际联机与后端；只有本地完整结构验证通过后再评估。

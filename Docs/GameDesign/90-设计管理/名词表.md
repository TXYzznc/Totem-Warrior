# 名词表

| 名词 | 当前定义 |
|---|---|
| 参赛者 | 一局中的真人或 Bot，统一参与队伍、战斗、构筑与成果统计。 |
| Bot | 人数不足时补位的人机玩家，不是 Enemy。 |
| Enemy | 后续 PVE 设计中的敌对非玩家单位；当前版本不存在。 |
| P01/P02 | 没有正式名称的图案临时编号。P01 偏单目标；P02 偏目标点范围。 |
| 纹身 | 图案、身体部位与元素颜色组合而成的局内构筑单元。 |
| 纹身主动技能 | 由左臂纹身授予的技能，不是角色固有技能。 |
| 普攻 | 当前由基础步枪射击承担的基础攻击上位概念。 |
| 有效直接伤害 | 通过关系校验并实际减少正数护盾或生命的直接伤害。 |
| 元素层 | 附着在目标身上的火、冰或雷状态，分弱、标准、强三层。 |
| 反应触发者 | 施加后一个异元素并触发反应的参赛者，也是反应击杀归属者。 |
| 反应辅助者 | 提供目标身上先存元素来源的参赛者。 |
| 构筑快照 | 构筑阶段开始前冻结并公开的装备纹身与当前属性信息。 |
| 本局成果 | 从开局累计至当前的伤害、击倒、淘汰、辅助等具体数据。 |
| 合法锚点 | 场景中经过配置、满足对应生成条件的位置。 |
| First Playable | 结构完整、可从主菜单运行至结果页的第一版验证版本，不等于内容完备产品。 |

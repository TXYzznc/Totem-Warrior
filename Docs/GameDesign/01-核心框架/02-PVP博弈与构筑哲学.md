# PVP 博弈与构筑哲学

> 状态：设计原则已确认；具体流派生态待实战验证  
> 文档职责：说明为什么公开构筑、为什么追求三角克制，以及如何避免构筑收敛。

## 问题来源

PVP 构筑最危险的问题不是“某个数值暂时不平衡”，而是所有选择最终都在比较同一个维度。如果图案只提供不同幅度的输出、防御或移速，玩家会迅速找到期望收益最高的一项，其余内容即使视觉不同也会退出实际选择。

本项目希望同时利用两类常见 PVP 深度：

1. **判断深度**：根据对手可能采用的方案进行克制和反克制。
2. **操作深度**：让命中、走位、时机和团队执行改变纸面构筑的实际价值。

## 三角克制原则

“剪刀—石头—布”是设计抽象，不是要求把三套纹身直接命名成三个职业。三角关系的价值在于：

- 任何一个方向都不应在所有对局中占优。
- 玩家能够理解自己为何被克制。
- 预判对手和隐藏下一步意图具有价值。
- 三方关系比五个或更多互相交错元素更容易学习和判断。
- 较低的平局概率有利于推动玩家作出明确选择。

三角关系可以来自效果之间的实际行为，例如持续压力、爆发窗口、位移规避、控制与解除、集火与保护，但不预先把这些行为固化为纹身流派名称。

当前两个基础图案采用第一条明确的收益交换：P01 是单目标高强度，P02 是目标点范围内多目标低强度。该差异是目标结构和单位目标收益的交换，不是给图案附加固定流派标签。

## 公开情报为何必要

完全隐藏构筑时，玩家很难区分“我判断错了”“对手刚好克制我”和“系统暗中给了对手优势”。完全实时公开又会导致无限镜像换装。

因此采用阶段边界快照：

```text
上一战斗阶段结束
→ 结算未救起倒地者
→ 冻结所有玩家当前构筑与整局成果
→ 进入构筑阶段并公开快照
→ 玩家各自修改，但修改不实时公开
→ 下一战斗阶段验证选择
→ 下次构筑才公开这次修改结果
```

这个结构让信息足以支持判断，同时保留一轮的信息延迟、欺骗和预测空间。

## 公开什么，不公开什么

公开：

- 已装备部位、临时图案编号、元素。
- 配置中不含精确数值的效果描述。
- 基础属性与局内强化的拆分显示。
- 从开局累计至边界的精确个人成果。

不公开：

- 图案内部倍率、概率和冷却数值。
- 对手在当前构筑阶段刚做出的修改。
- 隐藏的 Boss 综合贡献算法。
- 尚未实际触发或获得的未来效果。

## 操作修正原则

构筑强度不是一个脱离玩家的绝对值。评估一个效果时至少考虑：

| 维度 | 设计问题 |
|---|---|
| 理论收益 | 完美条件下能产生多少价值？ |
| 触发难度 | 需要弱点命中、距离、时机还是队友配合？ |
| 稳定性 | 普通玩家能否持续兑现？ |
| 反制窗口 | 对手能否通过走位、拆分、集火或构筑应对？ |
| 信息暴露 | 效果是否容易被对手从成果和表现中识别？ |
| 团队价值 | 单人强还是需要双人组合？ |
| 风险 | 失败时损失位置、资源、生命还是构筑机会？ |

高操作构筑可以拥有更高上限，但不能在普通执行下同时拥有最高下限；稳定构筑可以容易兑现，但应给对手明确的识别和应对空间。

## 反唯一最优解检查

每次新增图案或效果前应回答：

1. 它改变的玩家行为是什么，而不只是增加哪个数值？
2. 什么对局状态下玩家会主动选择它？
3. 什么状态下选择它明显不合适？
4. 对手看到无数值描述后能采取什么应对？
5. 它与队友的哪些效果存在组合或冲突？
6. 熟练玩家可以通过什么操作提高上限？
7. 如果它成为最高使用率选择，应该削弱数值还是修复缺失的反制工具？

## 当前版本的限制

First Playable 只有 P01/P02 和火冰雷，尚不足以证明完整流派生态已经成立。当前目标是验证信息与构筑循环是否成立，并收集选择率、成果、胜率、部位分布、元素组合和修改频率，而不是宣称已经实现最终平衡。

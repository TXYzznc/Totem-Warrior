# 长期对局循环

> 状态：宏观节奏已确认；Enemy、Boss、高阶资源和正式撤离细节暂未设计  
> 文档职责：记录完整 PvPvE 产品希望达到的五轮结构，不作为当前 First Playable 的实现清单。

## 长期对局目标

完整版本希望把一局分成“发育—聚集—目标争夺—撤离抉择”四段。前三轮给予探索和构筑空间，第四轮用 Boss 建立暂时共同目标，第五轮让高收益玩家和剩余撤离点集中，形成最强 PVP 压力。

## 完整五轮结构

```text
开局构筑（60 秒）
→ 从合法出生锚点中随机生成，同队生成在一起
→ 第 1 轮战斗

第 2 轮构筑（45 秒）
→ 第 1 次缩圈
→ 第 2 轮战斗

第 3 轮构筑（45 秒）
→ 第 2 次缩圈
→ 第 3 轮战斗

第 4 轮构筑（45 秒）
→ 第 3 次缩圈
→ Boss 在随机合法区域刷新
→ Boss 战
→ Boss 被击败后解锁撤离点
→ 高阶资源刷新

第 5 轮构筑（45 秒）
→ 第 4 次缩圈
→ 最终高强度 PVP 与撤离
```

## 阶段一：前三轮发育

- 前三轮完全不限制 PVP。
- 活动区域较大，队伍并不容易立刻相遇。
- 地图资源、颜料和位置探索构成主要发育内容。
- 偶遇战和主动追击仍然合法，因此发育不是无风险 PVE 保护期。
- 每轮构筑公开信息，让玩家逐步识别领先者、脆弱队伍和可能形成的组合。

## 阶段二：第四轮 Boss 聚集

- 第三次缩圈后在随机合法区域刷新 Boss。
- Boss 数值和能力应适合多名玩家共同挑战。
- 参与人数过少可能导致无法在允许时间内击败 Boss，甚至全员失败。
- 这种失败风险用于约束前三轮无节制淘汰：如果过早减少过多参赛者，幸存者也可能失去撤离机会。
- Boss 不是安全合作副本。不同队伍仍可互相攻击，合作、抢贡献、伏击和保留资源并存。

## Boss 奖励方向

Boss 被击败后：

1. 解锁撤离点。
2. 按玩家对 Boss 的综合贡献提供局内属性强化。
3. 完成最后一击的玩家获得额外特殊效果。
4. 地图刷新高阶奖励资源。

综合贡献可以考虑伤害、控制和其他有效影响，但具体算法不直接向玩家公开。隐藏算法用于避免所有人只追逐单一伤害指标，但其结果反馈必须让玩家感到基本合理。

最后一击特殊效果用于增加围绕击杀归属的博弈，但不能强到让前面所有贡献失去意义。

## 阶段三：撤离窗口

Boss 被击败后到第五轮缩圈前，偏好安全的队伍可以尽快撤离。此时的核心选择是：

- 带着已有成果离开，降低被淘汰风险。
- 留下争夺高阶资源，接受更强 PVP 压力。
- 观察其他队伍是否已经撤离，再改变计划。

## 阶段四：第五轮高强度对抗

- 第四次缩圈进一步压缩可活动区域。
- 已生成的撤离点不再移动。
- 部分撤离点可能落到圈外，从而在实际策略上失效。
- 剩余队伍、资源与可用撤离点集中，PVP 频率和撤离难度明显提高。
- 第五轮应成为主动追求高收益者选择的风险阶段，而不是所有玩家都被迫经历的固定终局。

## 核心动态

```text
前三轮淘汰太多人
→ 第四轮 Boss 参战人数不足
→ 所有人可能无法解锁撤离

多人合作快速击败 Boss
→ 撤离与高阶资源同时开放
→ 临时合作关系迅速转为队伍竞争

部分队伍提前撤离
→ 第五轮人数下降
→ 空间更小、可用撤离点更少
→ 单次遭遇的胜负权重更高
```

## 待独立设计

- Boss 原型、能力组、数值和阶段。
- Boss 刷新区域的合法性与预警。
- 全员失败的精确定义和结果反馈。
- 综合贡献公式及强化池。
- 最后一击特殊效果池。
- 高阶资源类型、数量、归属和局外价值。
- 正式撤离经济与失败损失。
- Enemy/PVE 如何支持前三轮发育而不淹没 PVP 信息。

# 通用 UI 组件素材清单

本目录只保留可跨页面复用的 UI 壳体；普通文字使用 `TMP_Text`，角色、纹身、物品和预览内容由运行时槽位加载。

| 分类 | 素材 | Unity 用法 |
| --- | --- | --- |
| 面板 | `panel_frame.png` | 九宫格面板外框，使用 `Image.Type=Sliced`。 |
| 卡片与列表 | `card_content.png`、`row_list.png` | 可拉伸内容卡与列表行底。 |
| 按钮 | `button_base.png` | 基础按钮壳；normal/focused/pressed 通过 Tint 和 `focus_outline` 表达。 |
| 焦点与选择 | `focus_outline.png`、`selection_frame.png` | 键鼠焦点与选中态描边。 |
| 进度 | `progress_track.png`、`progress_fill.png`、`ring_track.png`、`ring_fill.png` | 线性/圆环进度，填充图使用 Filled 或遮罩。 |
| 状态 | `state_disabled.png`、`state_failure.png`、`state_loading.png`、`state_lock.png`、`state_success.png` | 禁用、失败、加载、锁定、成功等额外语义态。 |
| 箭头 | `arrow_chevron.png` | 导航、展开、比较方向；旋转复用。 |
| 输入提示 | `prompt_base.png` | 输入动作标签的底板，按键文字由 InputModule 在运行时注入。 |

## 生产与验收

- 带描边或纹理的壳体，保留在 `_source/` 的纯绿色背景源图；去绿后的合并图在 `_merged/`。
- 最终素材均为带 alpha 的 PNG，四角透明；详细的九宫格边界、Tint 规则与跨页映射见 `组件规范.md`。
- 同形状的颜色变化不得再导出副本，统一由 `Image.color`、材质参数或局部覆盖层实现。

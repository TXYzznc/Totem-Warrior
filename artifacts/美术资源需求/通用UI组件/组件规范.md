# 通用 UI 组件规范

> 视觉基调：清透机能。暖灰白/浅灰蓝雾面底，喷砂金属细边，青色为主交互，珊瑚红仅用于危险、取消和不可逆操作。UI-002 的颜料失序仅作为该页面的局部叠加，不改变通用组件轮廓。

## 使用边界

- 本目录只存放形状相同、可通过 `Image.color`、九宫格或拉伸复用的壳体。
- 普通文字一律由 TMP_Text 渲染；控制器与键盘按键图标由 InputModule 根据当前绑定提供。
- 角色、纹身图案、物品、武器、头像和材质预览属于运行时数据资源，不放入本目录。
- 所有面板/卡片/按钮边框须九宫格；推荐 `border: 12 px`（512 画布）或等比缩放。

## 目录与资源名

| 分类 | 资源前缀 | Unity 用法 | 状态策略 |
|---|---|---|---|
| 面板 | `panel_` | Image, Sliced | 同形仅 Tint |
| 卡片与列表 | `card_` / `row_` | Image, Sliced | 轮廓不变仅 Tint；锁定加遮罩 |
| 选择与焦点 | `focus_` / `selection_` | Image, Simple | normal 隐藏；focused/selected 显示 |
| 进度 | `progress_` / `ring_` | Image, Filled/Mask | 轨道与填充复用，数值由 TMP_Text |
| 状态 | `state_` | Image, Simple | lock/loading/success/failure |
| 输入提示 | `prompt_` | Image, Sliced | glyph/text 为子节点运行时注入 |

## 状态与颜色

| 状态 | 形状资源 | Unity 处理 |
|---|---|---|
| normal | 基础壳体 | `#D9E2E6` / 低对比边框 |
| focused | `focus_outline` | 青色高对比外描边；控制器可见 |
| pressed | 基础壳体 | 深 8% + 内缩 2 px，不另出图 |
| disabled | 基础壳体 + `state_disabled` | alpha 45%，禁止只靠颜色区分 |
| locked | 基础壳体 + `state_lock` | 锁图标和半透明遮罩 |
| loading | `state_loading` | 旋转或遮罩动画，非文字 |
| success/failure | `state_success` / `state_failure` | 图标+颜色+TMP 文案三重表达 |

## 验收

- 最终 Sprite 必须 RGBA，四角 alpha=0，且含透明像素。
- 有材质的资源必须保留 `#00ff00` 绿幕源、去绿合并图和生成记录；纯色几何资源记录 PIL 参数即可。
- 资源名不得带状态文案、数值或输入键名；这些内容在 Unity 运行时组合。

## 最终通用组件清单（2026-07-27）

全部最终 Sprite 为 RGBA PNG；`_source/` 与 `_merged/` 仅保存可追溯中间产物，不能直接被运行时引用。除明确写为危险色的失败提示外，颜色变化应通过 `Image.color` / 覆盖层完成，不复制同形资源。

|---|---|---|---:|---:|---|
| 面板 | `面板/panel_frame.png` | Image, Sliced；侧栏、详情、弹窗 | 512×512 | 12 | 暖灰白 `#D9E2E6`～`#FFFFFF`；雾蓝 `#C9DCE5`～`#E8F3F5` |

| 焦点框 | `焦点与选择/focus_outline.png` | Image, Simple；controller focused | 512×512 | 不适用 | 青色 `#6FF7ED`～`#BFFFF8`；保留 2 px 描边与角标，不只改色 |

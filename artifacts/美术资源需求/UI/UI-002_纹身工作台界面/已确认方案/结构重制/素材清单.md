# UI-002 纹身工作台（TattooStudioForm）素材清单

## 0. 依据、边界与归属

- **唯一视觉依据**：`../UI-002_颜料失序_纹身工作台_主界面_C_v2.png`。本台账不采用同级的 A/B/C_v3 图，也不因旧交付清单中的历史描述替换该依据。
- **参考画布**：C_v2 为 1672×941；实际 UGUI 采用全局约定的 `Canvas Scaler = Scale With Screen Size`、Reference Resolution `1920×1080`、Match `0.5`。关键交互和文案保持在 title-safe 90% 内。
- **节点分类**：`ui-shell` 是静态可复用壳体；`runtime-slot` 是运行时内容的容器/遮罩；`data-asset` 由业务数据提供；`text` 一律为 TMP_Text。除下文列出的专属部位轮廓图标外，不从 C_v2 整图裁切任何页面 Sprite。
- **运行时内容红线**：角色模型、纹身贴花、颜料物品、样式图案、库存纹身图案，以及 Before/After 的材质预览**全部**为运行时加载内容；它们不是本页面 Sprite，也不应被烘焙进卡片、槽位、面板或状态图。
- **适配**：所有 `runtime-slot` 的 Image/RawImage/RenderTexture 容器均 `preserveAspect=true`；外框背景不启用 preserve aspect，以便适配拉伸。所有可交互项均需 controller 的可见 focused 状态，输入 glyph 和按键名由 InputModule 运行时注入。

## 2. 交互壳体状态台账

下表中的四个基础态为每一个交互壳体的最低实现要求；focused 必须包含不依赖色彩的 2px 轮廓或角标。pressed 使用同一壳体的深 8% / 内缩 2px 表现，disabled 为基础壳体叠加 `state_disabled`（alpha 45%），而不是另出一张文字化状态图。

| 交互壳体 | normal | focused | pressed | disabled | 必需附加态/说明 |
|---|---|---|---|---|---|
| `BodyPartRow` | `ListRow` 基础框 | `FocusOutline` | 基础框内缩 | `state_disabled` | selected 叠 `SelectionFrame`；已无可用内容时仍可聚焦并给出原因 Tooltip |
| `PigmentRow` | `ListRow` 基础框 | `FocusOutline` | 基础框内缩 | `state_disabled` | 颜料数量为 0 时 disabled；数量和名称由 TMP 显示 |
| `StyleCard` | `ContentCard` | `FocusOutline` | 基础框内缩 | `state_disabled` | **必须有 `locked`：`state_lock` + 半透明遮罩 + 解锁条件 TMP 文案**；selected 另叠 `SelectionFrame` |
| `InventoryCard` | `ContentCard` | `FocusOutline` | 基础框内缩 | `state_disabled` | locked/不可装备时叠 `state_lock`；缩略图和数量不烘焙于壳体 |
| `PreviousPage` / `NextPage` | `ButtonShell` | `FocusOutline` | 基础框内缩 | `state_disabled` | 首尾页必须禁用；左右箭头为同一壳体镜像而非两份图 |
| `CharacterPreviewPanel` 的旋转/缩放/重置交互区 | 无显式鼠标框 | 预览边缘焦点框 | 临时拖拽压态 | `state_disabled` | loading 或模型失败时禁用；保留 FocusOutline 使手柄可发现 |
| `InputPrompt`（Rotate/Zoom/Reset/Back） | `prompt_` 底板 | `FocusOutline` | 基础框内缩 | `state_disabled` | glyph、绑定名均为运行时子节点；不能把 `Q/E/R/ESC` 烘焙为图片 |
| `CancelButton` | 危险操作 `ButtonShell` | 高对比焦点框 | 基础框内缩 | `state_disabled` | 取消触发确认时不得直接丢失编辑；使用珊瑚红仅作风险语义 |
| `ConfirmButton` / `BackButton` / `RetryButton` | `ButtonShell` | `FocusOutline` | 基础框内缩 | `state_disabled` | 不在 C_v2 中，但为完整可恢复流程所必需 |
| `ApplyFlowPanel` | 可开始/待命壳体 | 焦点框（可取消时） | 仅可取消操作压态 | `state_disabled` | **必须具备 `loading`、`success`、`failure`**：分别为 `state_loading`、`state_success`、`state_failure`，均同时提供图标、颜色和 TMP 文案；失败状态显示 `RetryButton` |

## 3. 专属与通用组件引用

### 通用组件（只引用，不复制到本页）

来源：`artifacts/美术资源需求/通用UI组件/组件规范.md`。

| 通用资产/组件 | 用途 |
|---|---|
| `PanelFrame`（`panel_`，Sliced，12px border） | 左部位/颜料面板、右样式/材质对比面板、底栏与模态容器；以 Image Tint 做色彩变化 |
| `ContentCard` / `ListRow`（`card_` / `row_`，Sliced） | 样式卡、库存卡、部位行、颜料行的基础壳体 |
| `FocusOutline` / `SelectionFrame` | 所有 focused / selected 交互反馈；焦点不只依赖颜色 |
| `ProgressBar`（`progress_`）及 `state_loading` | 应用流程的轨道、Filled 填充和加载态；百分比为 TMP_Text |
| `InputPrompt`（`prompt_`） | 底部当前设备 glyph 与输入绑定提示 |
| `state_disabled` / `state_lock` / `state_success` / `state_failure` | 禁用、锁定、应用成功、应用失败；不得以文字 Sprite 替代 |

### UI-002 专属组件（本页语义专属）

| 专属组件 | 分类 | 作用与限制 |
|---|---|---|
| `tattoo_bodypart_icon_head/torso/arm/leg` | `ui-shell` | 六个部位行的静态解剖位置轮廓。arm 与 leg 分别由左右行复用，颜色由状态 Tint 控制；不是角色模型或纹身贴花。 |
| `tattoo_compare_arrow` | `ui-shell` | Before/After 的方向关系符号；只表达比较关系，不承载任何材质画面。 |
| `tattoo_workbench_empty_slot` | `ui-shell` | 未装备部位的中性占位壳；不得画入皮革、图案或角色贴花。若通用组件库形成同形 Slot，则迁移为通用引用。 |
| `tattoo_section_divider_diamond` | `ui-shell` | 样式与库存之间的局部结构分隔；无文字、数值或业务图案。若通用库已有等形分隔符则优先引用通用资产。 |

## 4. 效果图未展示、但完整工作台必需的壳体与状态资源

这些内容不改变 C_v2 的主视觉构图；默认按需显示或在叠层中出现。

| 项目 | 分类 | 必要性 |
|---|---|---|
| 角色/贴花/材质预览 loading、empty、error 壳层 | `ui-shell` | 远端内容或 RenderTexture 尚未就绪、加载失败时不能出现空白且无解释的预览区。 |
| 模型不可用的中性轮廓占位 | `ui-shell` | 仅失败降级壳体；不是可装备角色 Sprite。 |
| 样式/库存无结果状态（图标壳 + TMP 描述） | `ui-shell` + `text` | 筛选、未拥有或数据为空时保留可读反馈。 |
| 解锁条件 Tooltip 与锁定态 | `ui-shell` + `text` | 让 locked 样式卡/库存卡给出可行动的原因。 |
| Apply 确认模态、处理中遮罩、成功 Toast、失败 Toast 与重试按钮 | `ui-shell` + `text` | 覆盖不可逆前确认、loading、success、failure 与恢复路径。 |
| 危险取消确认模态与未保存更改提示 | `ui-shell` + `text` | C_v2 的 Cancel 必须可安全退出。 |
| 键盘/手柄焦点恢复、Tooltip、屏幕阅读描述 | `ui-shell` + `text` | 确保切页、锁定、加载或失败后焦点不丢失，且可访问。 |

# UI 资源需求

本目录存放 HUD、纹身工作台、图标、界面组件、提示图、面板背景和交互状态资源。

## 玩法重构后的使用规则

- 现有 `UI-001`～`UI-005` 与 `通用UI组件` 的成品保留为历史参考，不得直接视为当前需求的最终交付。
- 新 UI 仍沿用全局的明亮活性颜料视觉语言，但信息结构必须围绕 6 人双排、分轮构筑和三轮第一阶段验证闭环重新设计。
- 第一阶段只有火、冰、雷三种元素，并需要表达弱／标准／强三层；旧七元素图标体系不再适用。
- 纹身图案暂不命名，以 P01～P08 为临时编号；第一阶段界面只实现 P01/P02，其余图案资源作为后续储备。
- 第一阶段必须覆盖主菜单、常驻 HUD、构筑阶段、六人公开情报、队友颜料请求、倒地／救援／淘汰、三轮结算与开发验证反馈。
- Boss、撤离点、高阶资源、第 4/5 轮及局外熟练度属于后续版本，不得混入第一阶段主流程。

当前需求的具体编号、路径与验收状态以根目录的 `美术资源需求表.xlsx` 为准。

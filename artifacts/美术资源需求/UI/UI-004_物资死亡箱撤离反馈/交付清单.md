## 覆盖内容

每套方案均在同一张全状态视觉稿中覆盖以下六组需求：

1. 物资稀有度：五级状态，同时使用颜色、轮廓缺口或晶化数量区分。
2. 物资属性：全局/持久与可掉落使用两个不同形状徽章，避免语义混淆。
3. 普通物资箱与死亡箱：死亡箱使用断环和个人身份牌语义，不使用血腥表现。
4. 撤离反馈：公开显示进行中 `72%` 与离开范围暂停 `46%` 两种状态；暂停状态含暂停符号和范围环。
5. 晚期事件：使用广播塔、扩散环和阶段时间线表现地图级事件。
6. 高价值补给：使用金色/活性颜料强化的补给箱与侧边提示，不占据中心瞄准区域。

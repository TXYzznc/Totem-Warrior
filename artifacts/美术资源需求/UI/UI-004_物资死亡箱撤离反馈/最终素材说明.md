# UI-004｜LootEvacForm 素材清单与结构台账

> 视觉依据：`UI-004_清透机能_物资死亡箱撤离反馈_全状态_A.png`（1672×941，仅作视觉语言参考）。  
> 结构契约：`openspec/specs/ui-asset-catalog/spec.md`；通用壳体约束：`artifacts/美术资源需求/通用UI组件/组件规范.md`。  
> 本文只定义结构、资源归属与迁移候选；**不移动、不删除、不生成任何 PNG**。

## 1. 落地原则

- `LootEvacForm` 使用全局 Canvas Scaler（1920×1080，Match 0.5）；所有操作提示由 InputModule 在运行时提供当前设备 glyph 与绑定文本。
- 所有普通文字、数值、百分比、玩家名、按钮名和状态文案均为 `TMP_Text`，不得烘焙为贴图。
- 同形状的面板、卡片、焦点框、读条、状态遮罩和输入提示只引用 `通用UI组件` 的壳体，并以 Tint、Sliced 或 Filled 变形；本页只计划持有具备撤离/死亡箱语义的壳体。
- **物资本体、掉落图和身份数据均为运行时加载。** 物品缩略图、物资箱/死亡箱外观、掉落物图标、玩家头像、身份牌图样、名称、数量、稀有度和归属均不得固化进本页 PNG；它们由业务 `data-asset` 给出地址/ID，并挂入对应 `runtime-slot`。
- 所有可交互项均有 controller `focused` 反馈，且 focused 不只依赖颜色；安全区内保留交互和文本。

## 3. 可交互与反馈状态

| 对象 | normal | focused | pressed | disabled | 额外业务反馈 |
| --- | --- | --- | --- | --- | --- |
| 物资槽、死亡箱入口、高价值补给入口 | 基础卡框与语义色弱化显示 | 通用 `FocusOutline`（2px 轮廓/角标）+ 当前设备焦点 | 基础壳体 Tint 降 8%、内容内缩 2px | alpha 45% + `state_disabled`，保留禁用原因文本 | 槽中内容由运行时刷新；空槽显示空态，不生成空物资图 |
| 主操作 / 取消 / 查看详情 | 通用 `InputPrompt` | FocusOutline + glyph 可见 | 内缩 2px | `state_disabled` + 原因 | glyph 和动作名由 InputModule 替换，不能烘焙键位 |
| 撤离流程 | `Extract` 待命态 | 可聚焦的操作提示 | 发起撤离瞬时按压 | 条件不足或冷却中 | `loading`：`state_loading` + 非确定进度；进行中：青色 Filled 读条；离开范围：暂停环与琥珀读条；`success`：`state_success` + 结算文案；`failure`：`state_failure` + 失败原因。成功/失败均为图标+颜色+TMP 三重表达 |
| 物资稀有度 | common/uncommon/rare/epic/legendary | 如可选则叠加 FocusOutline | 同卡片按压规则 | 不可用时叠加 disabled | 稀有度由 `RarityDefinition` 驱动色值、轮廓缺口/晶化数量和标签；使用单一可 Tint 的 `rarity_frame`，不为五档分别烘焙完整卡片 |
| 晚期事件 | 未触发 | 可聚焦事件详情 | 节点按压 | 未解锁/未到阶段 | announced（预告）、active（进行）、escalated（阶段推进/高亮）、resolved（完成/失效）；时间线位置和剩余时间为运行时数据，节点状态以 Tint、填充和通用 state 叠层表现 |
| 物资属性 | 持久 / 可掉落语义徽章 | 如可交互则叠加 FocusOutline | 同卡片按压规则 | 不适用时 disabled | 徽章图形、文案与说明由物资定义提供；持久与可掉落不得共用一个含混图标 |

## 4. 组件归属与引用

| 组件 | 归属 | 分类 | 引用/实现方式 |
| --- | --- | --- | --- |
| PanelFrame、ContentCard / ListRow | 通用 | `ui-shell` | `artifacts/美术资源需求/通用UI组件/`；Sliced、12px 边框，以 Tint 区分区域 |
| FocusOutline / SelectionFrame | 通用 | `ui-shell` | 仅 focused/selected 显示；2px 轮廓或角标确保非色彩依赖 |
| ProgressBar / ProgressRing | 通用 | `ui-shell` | 轨道 Sliced/Simple，填充用 Filled/Mask；数值走 TMP；loading 用 `state_loading` |
| InputPrompt | 通用 | `ui-shell` | glyph 与绑定名是运行时子节点；不做键盘/手柄专用贴图 |
| state_disabled / state_loading / state_success / state_failure | 通用 | `ui-shell` | 按状态叠加，不为每个业务按钮复制整张状态图 |
| 物资稀有度槽、持久/掉落属性区 | UI-004 专属 | `ui-shell` + `runtime-slot` | 仅保留版式壳体；稀有度与物品内容为数据驱动 |
| 死亡箱身份区 | UI-004 专属 | `ui-shell` + `runtime-slot` | 仅保留“死亡箱 + 归属”的结构语义；箱体、头像、身份牌均动态注入 |
| 撤离门锚点、离开范围环、撤离状态区 | UI-004 专属 | `ui-shell` | 只保留撤离空间语义；active/paused/loading/success/failure 使用状态参数与通用 state 叠层 |
| 事件时间线、补给呼出线 | UI-004 专属 | `ui-shell` | 线、节点和呼出框可拉伸；广播塔/补给外观由运行时数据提供 |

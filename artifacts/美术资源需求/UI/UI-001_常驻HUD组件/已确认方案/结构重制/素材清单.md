# UI-001 常驻 HUD｜结构与素材清单

## 依据与边界

- **视觉依据**：`UI-001_清透机能_HUD_全状态_v1.png`（本次以用户确认的 v1 为唯一效果图依据）。
- **运行基准**：1920×1080、Canvas Scaler = Scale With Screen Size、Match = 0.5；关键状态置于 93% action-safe 内，交互与文本置于 90% title-safe 内。
- **结构约束**：同形壳体只引用 `通用UI组件`，页面仅持有语义专属图标；普通文字、数值、按键名称一律使用 `TMP_Text`，不烘焙为 PNG；所有 `runtime-slot` 均 `preserveAspect=true`。
- **本清单不执行任何文件删除、移动或 PNG 生成**；“删除候选”只表示后续清理评审结论。

## 可交互壳体状态

| 交互壳体 | normal | focused | pressed | disabled | 附加状态 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| `ExtractActionButton` | `panel_button` 常规 Tint | 显示 `focus_outline` 的 2px 青色描边与角标 | 基础壳体压暗 8%、内缩 2px | 45% alpha + `state_disabled`，不可只靠变灰 | loading / success / failure | loading 锁定点击；success/failure 均使用图标、颜色和 TMP 文案三重反馈。 |
| `PigmentSwatch` | 色块边框低对比 | `focus_outline` + 当前色块外描边 | 内缩 2px | 45% alpha + `state_disabled` | loading / failure | 色彩仅表示颜料身份；焦点、禁用仍有非色彩线索。 |
| `ExpandCaret`（颜料展开） | 向下形态 | 焦点描边 | 旋转/内缩反馈 | 45% alpha + 禁用遮罩 | loading | 仅控制列表展开，不承载按键名称。 |
| `EventNotice`（可打开详情时） | 常规面板 | `focus_outline` | 内缩 2px | 45% alpha + `state_disabled` | loading | 若事件仅通知则禁用 Raycast，不作为交互项。 |
| `InteractionPrompt` | 常规提示壳 | `focus_outline` | 按绑定触发的短促缩放 | 条件不满足时 `state_disabled` | loading / success / failure | glyph 与绑定文本由 InputModule 在运行时替换。 |

非交互面板（生命、武器、构筑、倒计时与普通事件）不制造虚假 focus；它们只呈现 `data-asset` 与 `TMP_Text`。

## 素材归属与引用

| 用途 | 资源名 / 引用名 | 归属 | Unity 用法 |
| --- | --- | --- | --- |
| 各 HUD 面板底框 | `panel_frame` | 通用 UI 组件 `PanelFrame` | Image / Sliced；Image Tint 区分常规、警示和禁用。 |
| 提取操作壳与颜料色块壳 | `panel_button`、`row_pigment_swatch` | 通用 UI 组件 `ContentCard / ListRow` | Image / Sliced；不按状态复制位图。 |
| 控制器焦点与选中 | `focus_outline`、`selection_frame` | 通用 UI 组件 `FocusOutline / SelectionFrame` | Image / Simple；焦点包含 2px 非色彩描边/角标。 |
| 条段生命、弹药点、部位完整度、事件紧迫度 | `progress_track`、`progress_fill` | 通用 UI 组件 `ProgressBar` | Track = Sliced/Simple，Fill = Filled；数值由 TMP 提供。 |
| 手柄/键鼠操作提示 | `prompt_input` | 通用 UI 组件 `InputPrompt` | Image / Sliced；glyph 与绑定文案不作为静态图片。 |
| 锁定、加载、成功、失败 | `state_disabled`、`state_loading`、`state_success`、`state_failure` | 通用 UI 组件 `state_` | Image / Simple；可与任意壳体叠加。 |
| 生命、信号、撤离、防护语义图标 | `hud_icon_health`、`hud_icon_signal`、`hud_icon_extract`、`hud_icon_shield` | UI-001 专属静态语义素材 | Image / Simple；仅图形，不含文字、数字或状态文案。 |
| 准星、受击方向、颜料展开箭头 | `hud_crosshair`、`hud_damage_direction`、`hud_caret_down` | HUD 补充静态语义素材 | Image / Simple；效果图未展示但战斗 HUD 必需。 |

## 运行时内容与 TMP 文本

| 区域 | 运行时加载内容（`runtime-slot` / `data-asset`） | TMP 文本（`text`） |
| --- | --- | --- |
| 事件通知 | 事件类型图标、事件优先级、持续时间 | 前缀、标题、地点/目标说明 |
| 撤离 | 撤离点、开放性、当前交互资格 | 状态标题、倒计时、操作文案 |
| 构筑摘要 | 当前构筑人体视觉、六部位防护/耐久数据 | 标题、部位名称、耐久值 |
| 生命 | 当前/最大生命、生命段数与治疗状态 | 标题、`当前 / 最大` |
| 武器 | 装备武器预览、当前/备用弹药、射击模式、弹药段 | 当前弹药、备用弹药、射击模式 |
| 颜料 | 当前颜料定义、可用颜料列表、解锁与冷却状态 | 标题；必要时显示颜料名称/冷却 |
| 补充层 | 当前输入设备 glyph 与绑定、准星样式、受击方向、状态效果图标/剩余数据、反馈类型 | 操作名称、效果剩余时间/层数、系统反馈文案 |

## 效果图外但完整 HUD 必需的补充 UI

| 模块 | 必要性 | 资源策略 |
| --- | --- | --- |
| 准星 | 第一人称战斗瞄准的基础反馈 | `hud_crosshair` 静态壳；散布、命中和交互状态由运行时参数驱动。 |
| 情境交互提示 | 开门、拾取、撤离确认等操作必须能以当前设备绑定呈现 | 引用 `prompt_input`，glyph/文案运行时注入。 |
| 受击方向指示 | 不依赖纯颜色传达威胁来源 | `hud_damage_direction` 静态形状，方向和强度运行时驱动。 |
| 状态效果栈 | 中毒、治疗、隐身、冷却等持续状态的可读性 | 引用通用 `row_` / `state_` 壳；图标和计时为动态内容。 |
| 通知/失败反馈 | 网络、交互、撤离与任务操作需有明确结果 | 引用 `state_loading/success/failure` 与 TMP 文案。 |

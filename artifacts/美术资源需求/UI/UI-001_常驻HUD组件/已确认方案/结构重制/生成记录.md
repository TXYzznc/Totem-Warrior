# UI-001 HUD 专属素材生成记录

日期：2026-07-27

## 范围

仅生产 `素材清单.md` 列出的 7 个 UI-001 静态 Sprite：4 个语义专属图标与 3 个 HUD 补充层。通用面板、列表行、焦点、进度、输入提示和 `state_` 遮罩均未复制或生成。

## 带材质图标流程

1. 使用内置图像生成工具生成 `2×2` 严格绿幕网格，背景要求为纯 `#00ff00`，无文字、数字、角色、武器、物资和普通图标内容。
2. 原始图保留为 `_source/HUD_UI001_semantic_icons_imagegen_raw.png`；将连通绿幕标准化为严格 `#00ff00` 后，保留 `_source/HUD_UI001_semantic_icons_strict_00ff00_grid.png`（988228 个严格绿幕像素）。
3. 使用 `remove_chroma_key.py` 自动取样边缘色、软遮罩和去溢色，得到 `_merged/alpha/HUD_UI001_semantic_icons_strict_alpha.png`。
4. 按等大的四个网格单元切出 `health`、`signal`、`extract`、`shield`，不从 HUD mockup 截图裁图。

生成提示（摘要）：近未来清透机能 HUD；深炭黑拉丝材质、青色金属边缘高光、白色语义符号；四个对象为医疗、信号、撤离和防护；严格纯绿背景，禁止文字、数字与额外对象。

## 纯几何补充层

`hud_crosshair`、`hud_damage_direction`、`hud_caret_down` 以 PIL 在 4 倍画布绘制后 LANCZOS 下采样，直接写成透明 RGBA PNG。受击方向图为朝上的静态形状，方向与强度由运行时参数驱动。

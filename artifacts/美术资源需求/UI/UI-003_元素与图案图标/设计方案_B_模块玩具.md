# UI-003 七色元素与八图案图标｜方案 B：模块玩具

> 类型：UI  
> 资源路径：`UI/UI-003_元素与图案图标/`  
> 当前状态：待分配（本文件为制作/寻找资源前的设计与验收 Brief）

## 1. 方案定位

**资源任务**：七种颜料元素与八种图案的完整图标套件；服务 HUD、工作台、掉落物和图鉴。

**范围说明**：按本资源目录的需求范围制作；不额外拆分未列入台账的资源。

**本方案的核心句**：以更饱满、更圆润的模块化体块强化卡通亲和力和远距离识别。

**适用判断**：适合希望用更强轮廓与更低理解门槛吸引玩家的路线；保持同一世界观，不把物体做成幼儿玩具。

## 2. 该资源的具体设计

加粗轮廓与更饱满内形，32×32 下仍可区分；颜色只是辅助，形状必须能独立读出。

### 视觉构成规则

- **形体/信息层级**：更粗的圆角、清楚的分段和略大的功能件；远看必须先读到用途，再读到表面细节。
- **材质与表面**：软触塑料、包胶金属、织物橡胶与轻微磨砂透明件；材质交界通过大色块而不是密集噪点区分。
- **色彩策略**：奶油白、珊瑚橙、湖蓝为常规底色；七种颜料用于大而少的信号面，避免同时出现超过三种强调色。
- **情绪目标**：活泼、可靠、可快速读懂，并保留竞技场的紧凑感。
- **与刺青系统的关系**：刺青、颜料、掉落物与撤离信息必须优先于装饰性亮点；本资源只使用活性颜料来解释功能、风险或交互，不把它当作无意义贴纸。

## 3. 生产与交付

7 个元素与 8 个图案的单色、语义色、禁用、选中、掉落物小尺寸版本及网格规范。

制作时需保留可替换材质、可复用模块或可导出的源文件结构；当前以画面效果为先，但不能把后续统一、替换和优化的余地做死。

## 4. 验收清单

- [ ] 在晴天、明亮街区基线下仍然清楚，不依赖黑暗背景或重后处理。
- [ ] 与“接受局部功能性改造的人类 + 活性颜料未来生活区”的世界观一致。
- [ ] 远距离先读用途/威胁/交互，近距离再读材质和细节。
- [ ] 图标在 32×32、色盲模拟和暗色 HUD 上仍可区分；八图案不依赖文字缩写；同一图标跨界面一致。
- [ ] 与其它方案相比，能明确看出“模块玩具”的差异，但不脱离全局美术语言。

## 5. 不通过的情况

复杂插画式图标、过细线条、只靠七色不同而没有形状区别。

同时不接受：低照度、废土脏乱、过度赛博霓虹、血腥生物化、写实军事风，或为了独特而破坏 UI、角色、建筑之间的统一精细度。

## 6. 选择建议

若该资源是第一批垂直切片资产，优先采用 **方案 A：清透机能** 作为主生产方向；方案 B 用于需要更强远读与卡通亲和力的资产；方案 C 只用于需要强调污染、事件或构筑反馈的局部节点。三个方案可以在同一地图并存，但同一单个资源最终只能选定其中一个作为主语言，避免混搭。

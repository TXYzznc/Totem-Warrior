## 固定网格映射

### 七元素矩阵（7 列）

从左到右：

1. Red / 火：火焰
2. Yellow / 雷：折角闪电
3. Green / 自然·毒：带叶脉的液滴
4. Blue / 冰：六臂雪花
5. Purple / 异变：带节点的螺旋
6. Gold / 神圣：四芒光与光环
7. White / 纯能·光：切面能量晶体

### 八图案矩阵（8 列）

从左到右：

1. Line：直线与中央冲击节点
2. Ring：双同心环与四向短射线
3. Spiral：三圈螺旋
4. Zigzag：四段阶梯折线
5. Bolt：带分叉的闪电，轮廓与 Zigzag 明确区分
6. Star：五角星与四个轨道节点
7. Stream：三道平行流线
8. Beast：兽爪与召唤弧

### 五状态矩阵（5 行）

从上到下：

1. 单色 / 中性线稿
2. 正常 / 语义色
3. 禁用 / 灰阶
4. 选中 / 状态环
5. 掉落物 / 小尺寸徽章

图案本身是可着色的中性遮罩语义：第二行只演示方案默认着色，运行时应继续由所选 `ColorId` 着色，不把图案永久绑定到某一种元素色。

## 三套视觉规则

- A 清透机能：深炭蓝面板、暖白细边、统一线宽、克制的青绿色状态光；材质为雾面树脂与细喷砂金属。
- B 模块玩具：奶油白底、深海军蓝粗轮廓、湖蓝与珊瑚状态色；使用饱满圆角、软触塑料和明显的模块分段。
- C 颜料失序：稳定干净的暗色基底；只有选中态出现小面积颜料流带或晶化边，基础图形不被失序效果遮挡。

## 生成提示词摘要

六次生成均采用 `stylized-concept` / `game UI icon design board`：

- 元素稿：严格 5 行 × 7 列；火、雷、自然·毒、冰、异变、神圣、纯能；单色、语义色、禁用、选中、掉落物五状态。
- 图案稿：严格 5 行 × 8 列；Line、Ring、Spiral、Zigzag、Bolt、Star、Stream、Beast；相同五状态。
- 共通约束：固定列序、同列造型一致、32×32 可识别、无文字、无数字、无图例、无水印、无额外图标、无复杂场景。
- A 追加清透机能材质与青绿色克制状态光；B 追加粗轮廓、圆角模块、奶油白/湖蓝/珊瑚配色；C 追加“仅选中态少于 15% 面积的非对称颜料流带或晶化边”。

## 使用边界

本次交付为完整图标系统的视觉设计与状态展示稿，适合风格选定、评审、切片规范确认和后续 Sprite 制作参考；尚未拆分为独立透明背景运行时 Sprite，也未写入 Unity 图集或资源索引。若进入工程实现，应从最终选定的一套方案统一切片，不应在同一套运行时图标中混用 A / B / C。

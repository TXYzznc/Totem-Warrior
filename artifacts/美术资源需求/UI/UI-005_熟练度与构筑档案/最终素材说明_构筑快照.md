# UI-005｜构筑快照（BuildSnapshotForm）结构与素材清单

## 0. 依据、边界与归属

- **唯一视觉依据**：`UI-005_A_清透机能_03_构筑快照.png`（1672×941）。它表达的是构筑档案、图案—颜料—身体部位关系与个人使用记录；不把本页实现为武器 DPS 或直接 PVP 强度面板。
- **结构契约**：`openspec/specs/ui-asset-catalog/spec.md`；**通用壳体规范**：`artifacts/美术资源需求/通用UI组件/组件规范.md`。UGUI 使用 `Canvas Scaler = Scale With Screen Size`、Reference Resolution `1920×1080`、Match `0.5`；交互与文字在 90% title-safe 内。
- **分类约定**：`ui-shell` 为静态壳体/遮罩；`runtime-slot` 为运行时视觉内容的容器；`data-asset` 为业务系统提供的 ID、记录、状态或地址；`text` 一律为 `TMP_Text`。所有 `runtime-slot` 均 `preserveAspect=true`，可拉伸背景壳体则为 `false`。
- **运行时红线**：构筑卡数据、图案、颜料、身体部位、头像与战绩（次数、成功数、成功率、历史记录、收藏对象）均由 `data-asset` 驱动并装入 `runtime-slot`/`text`；普通文案、数值、日期、按钮名与按键名称全走 TMP，不生成文字图片。
- 本台账**只定义结构、引用和迁移候选**；不移动、不删除、不重命名，也不生成 PNG。

## 2. 交互壳体状态

所有 `focused` 均必须显示不依赖色彩的 2px 描边或角标；`pressed` 以同一壳体压暗 8% 且内缩 2px 表现；`disabled` 为 45% alpha 加通用 `state_disabled`，不能仅用变灰；`locked` 为半透明遮罩加 `state_lock` 和 TMP 解锁原因。

| 交互壳体 | normal | focused | pressed | disabled | locked / 额外说明 |
| --- | --- | --- | --- | --- | --- |
| `BuildCard` | 通用 `ContentCard` 常规 Tint | `FocusOutline` + `SelectionFrame` | 同壳内缩、Tint 深 8% | `state_disabled`，保留不可载入原因 | 槽位不可用/权限未到时叠 `state_lock`；预览与名称仍由运行时内容提供。 |
| `EditNameAction` | 图标壳常规 | `FocusOutline` | 内缩 2px | `state_disabled` | 仅打开重命名流程；图标不携带按键或文案。 |
| `Load / Rename / Duplicate / Delete` | 通用 `InputPrompt` | `FocusOutline` + 当前设备 glyph 可见 | 内缩 2px | `state_disabled` + TMP 原因 | `Delete` 使用危险 Tint，仍复用同一 prompt 壳；glyph 与绑定文字动态注入。 |
| `FavoriteRosterCard`（可查看详情时） | 通用 `ContentCard` | `FocusOutline` | 内缩 2px | `state_disabled` | 收藏状态由 `BuildSnapshotId`/偏好数据驱动；头像绝不固化。 |
| `HistoryRow`（可打开记录时） | 通用 `ListRow` | `FocusOutline` | 内缩 2px | `state_disabled` | `locked` 用于隐私或未解锁的历史详情；成功/部分成功以通用状态层 + TMP 呈现。 |
| `Filter / ViewDetails / Back` | 通用 `InputPrompt` | `FocusOutline` | 内缩 2px | `state_disabled` | 当前设备 glyph 与绑定名由 InputModule 提供。 |
| 模态确认 / 取消 | 通用 ButtonShell / `InputPrompt` | 高对比 `FocusOutline` | 内缩 2px | `state_disabled` | 删除确认需 `locked` 风险提示与 TMP 目标名称；执行时转 `loading`，再由 success/failure 反馈。 |

非交互的详情面板、数据指标和时间线只展示数据，不伪造焦点态。

| 构筑档案列表 | 构筑卡数据、角色/外观预览、已装配图案与颜料、卡片 ID、是否可载入/收藏/锁定 | 序号、构筑名、保存/更新时间、占用槽位数、锁定原因 |

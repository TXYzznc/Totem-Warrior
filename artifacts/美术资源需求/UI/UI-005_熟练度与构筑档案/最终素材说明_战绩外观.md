# UI-005｜战绩与外观展示（ProfileShowcaseForm）结构与素材清单

## 0. 依据、边界与分类

- **视觉依据**：`UI-005_A_清透机能_04_战绩与外观展示.png`（1672×941）。页面表现个人战绩、可切换的角色外观预设、八图案徽章与分享入口；中央明亮室内和角色展示是场景/相机内容，不生产为 UI 背景图。
- **结构与组件依据**：`openspec/specs/ui-asset-catalog/spec.md`、`artifacts/美术资源需求/通用UI组件/组件规范.md`、`设计方案_A_清透机能.md`。Canvas Scaler 使用 `Scale With Screen Size`，Reference Resolution `1920×1080`、Match `0.5`；交互与文本置于 90% title-safe 内。
- **分类契约**：`ui-shell` 是静态壳体/遮罩；`runtime-slot` 是运行时视觉内容容器且 `preserveAspect=true`；`data-asset` 是业务、存档和地址数据；`text` 一律是本地化 `TMP_Text`。可拉伸背景壳体 `preserveAspect=false`。
- **运行时红线**：角色外观、服装/纹身层、预设内容、八图案徽章、玩家头像、分享卡预览和全部战绩（次数、成功数、成功率、日期、偏好图案）都是运行时内容；普通文字、数值、百分比、日期、按钮名与输入绑定文字均走 TMP，绝不生成文字贴图。
- 本台账仅定义结构、引用及迁移候选；**不移动、不删除、不重命名，也不生成 PNG**。

## 2. 交互壳体状态

所有 `focused` 都必须有不依赖颜色的 2px 描边或角标；`pressed` 使用同一壳体压暗 8%、内缩 2px；`disabled` 为 45% alpha 加通用 `state_disabled`；`locked` 为半透明遮罩加通用 `state_lock` 与 TMP 原因。normal/focused/pressed/disabled/locked 不制作页面状态位图。

| 交互壳体 | normal | focused | pressed | disabled | locked | loading / success / failure |
| --- | --- | --- | --- | --- | --- | --- |
| `AppearancePresetCard` | 通用 `ContentCard` 常规 Tint，预览由槽位加载 | `FocusOutline` + `SelectionFrame`，手柄可见 | 同壳内缩 2px、暗 8%，请求应用预设 | 45% alpha + `state_disabled`，保留预设名和不可用说明 | `state_lock` + 遮罩；仍可 focused 以读 TMP 解锁条件 | 预览/应用时 `state_loading`；完成以 `state_success` 反馈，失败以 `state_failure` + Retry。 |
| `MasteryEmblemCard` | 通用 `ContentCard`，图案徽章运行时加载 | `FocusOutline`，可打开图案/徽章详情 | 内缩 2px、暗 8% | 45% alpha + `state_disabled` | `state_lock` + TMP 条件；八徽章的拥有与等级不烘焙 | 徽章地址同步中 loading；地址缺失或请求失败显示 failure 占位与重试。 |
| `ShareStyleCard` | 通用 `ContentCard` | `FocusOutline` + 非色彩角标 | 内缩 2px、暗 8%，提交分享 | 隐私限制/离线时 `state_disabled` + 原因 | 分享资格未满足时 `state_lock` + 条件说明 | 生成分享数据时 loading；完成 success Toast；失败为 failure + RetryPrompt。 |
| `RotatePrompt` / 底部 `InputPrompt` | 通用 `prompt_` 底板 | 仅作为可独立聚焦操作时显示 FocusOutline | 绑定触发的短促缩放 | 当前动作不可执行时 `state_disabled` | 有权限门槛时 `state_lock` + TMP 条件 | 绑定解析中 loading；动作结果在反馈层统一反馈。 |
| `RetryPrompt` | 通用 `InputPrompt` | `FocusOutline` | 内缩 2px、暗 8% | 无可重试请求时 `state_disabled` | 不适用 | 仅在 failure 后出现；点击后转 loading，回到 success 或 failure。 |

`PersonalRecordPanel`、统计行、角色预览和页眉是信息展示节点，不伪造焦点态；角色旋转只由 `TotemInputService` / `ITotemInputProvider` 的当前绑定触发。

## 3. 通用/专属引用与素材归属

| 用途 | 资源或引用 | 分类 | 归属 | Unity 用法与限制 |
| --- | --- | --- | --- | --- |
| 个人战绩、外观预设、徽章区、Tooltip 与失败面板 | `panel_frame` | `ui-shell` | 通用 `PanelFrame` | Image / Sliced，12px border；只用 Tint 与尺寸区分层级。 |
| 预设卡、徽章卡、分享入口、统计行 | `card_frame` / `row_frame` | `ui-shell` | 通用 `ContentCard / ListRow` | Image / Sliced；状态由本页第 2 节的统一叠层组合。 |
| 当前选择、手柄焦点 | `focus_outline` / `selection_frame` | `ui-shell` | 通用 `FocusOutline / SelectionFrame` | Image / Simple；focused 必有 2px 描边/角标。 |
| 原旧文件中的三种统计环 | `ring_track` / `ring_fill` | `ui-shell` | 通用 `ProgressRing` | Track 用 Simple/Sliced、Fill 用 Filled/Mask；如果产品需要环形成功率，数值与填充由运行时数据驱动，颜色只用 Tint。 |
| 禁用、锁定、加载、成功、失败 | `state_disabled` / `state_lock` / `state_loading` / `state_success` / `state_failure` | `ui-shell` | 通用 `state_` | 叠加到卡、Prompt 或槽位；状态图标必须配 TMP，不能只变色。 |
| 手柄/键鼠操作底板 | `prompt_input` | `ui-shell` | 通用 `InputPrompt` | Image / Sliced；glyph 和绑定文案都为运行时子节点。 |
| 总对局、成功纹身、连续撤离的统计语义图标 | `profile_showcase_stat_matches_icon`、`profile_showcase_stat_success_icon`、`profile_showcase_stat_streak_icon` | `ui-shell` | UI-005 专属 | Image / Simple；只表示指标类别，不含数值、文字、日期或结果。复用旧图标候选前须复核透明边界。 |
| 外观区标题语义图标、无预设/无徽章标记 | `profile_showcase_icon_appearance`、`profile_showcase_empty_mark` | `ui-shell` | UI-005 专属（待补制） | 仅在通用库没有同义形状时才生成；透明 RGBA，不含普通文案、角色或图案。 |
| 角色、服装、纹身、预设缩略图、分享预览 | `CharacterAppearanceSlot` / `PresetPreviewSlot` / `SharePreviewSlot` | `runtime-slot` + `data-asset` | 运行时 | 由 `TotemAssetService` 按地址加载；保持 `preserveAspect=true`。 |
| 八图案徽章、偏好图案图标 | `EmblemVisualSlot` / `CurrentFavoritePatternSlot` | `runtime-slot` + `data-asset` | 运行时 | `PatternDefinition.EmblemAddress` 等数据提供。八种图案与示例莲花都不进入静态 Sprite。 |
| 战绩、预设 ID/权限、当前应用外观、分享资格/隐私 | `PlayerProfile`、`AppearancePreset`、`MasteryState`、`ShareCardComposition` | `data-asset` | 运行时 | 由档案、外观、熟练度与分享业务系统提供，禁止烘焙到卡面。 |
| 标题、标签、名称、次数、成功率、日期、百分比、操作/按键名、错误说明 | 本地化键 + `TMP_Text` | `text` | 运行时 | 普通文字一律 TMP；InputModule 提供当前设备 glyph 与绑定文字。 |

| 徽章展示 | **八图案徽章**、图案 ID、拥有/锁定、熟练度与展示权限 | 图案名、`MASTER` 等本地化层级标签、锁定条件。 |

| 输入与反馈 | 当前设备 glyph、绑定、操作可用性、异步请求与错误码 | Navigate / Filter / Showcase / Back / Rotate、Tooltip、空态、错误与无障碍描述。 |

## 5. 效果图外但完整界面必需的 UI 资源/节点

| 模块 | 分类 | 必要性与资源策略 |
| --- | --- | --- |
| 预设与徽章的滚动、筛选、焦点恢复 | `ui-shell` + `runtime-slot` + `text` | 效果图只露出 3 个预设和 8 徽章；完整目录必须支持更多内容、筛选、手柄遍历与模态关闭后回焦。复用 `ContentCard`、`FocusOutline`、`InputPrompt`，无新 Sprite。 |
| 角色/预设/徽章/分享预览的 loading、失效和重试 | `ui-shell` + `runtime-slot` + `text` | 资源地址可能异步或失效；使用通用 `state_loading` / `state_failure` 与 TMP，不用假角色或固定图案占位。 |
| 空预设、无可展示徽章与新账号降级态 | `ui-shell` + `text` | 无数据时不能留白；使用 `profile_showcase_empty_mark`（通用库无同义件时）及 TMP 引导，不使用某个角色、预设或图案冒充空态。 |
| 锁定原因、隐私说明与分享前确认 | `ui-shell` + `text` | 预设、徽章和分享都有权限/隐私条件；Tooltip、确认框与 Retry 复用 `PanelFrame`、`InputPrompt`、`state_lock`，目标名称/日期均由 TMP。 |
| 本地化、设备切换与无障碍 | `runtime-slot` + `text` | 输入 glyph/绑定随设备替换；读屏需说明当前外观、战绩、锁定条件与分享结果。状态必须同时用图标、颜色和文字表达。 |

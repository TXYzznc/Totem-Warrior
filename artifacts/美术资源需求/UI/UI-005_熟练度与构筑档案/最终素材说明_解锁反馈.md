# UI-005｜新解锁反馈（UnlockFeedbackForm）结构与素材清单

## 0. 依据、边界与归属

- **视觉依据**：`UI-005_A_清透机能_05_新解锁反馈.png`（`1672 × 941`）。画面表达的是 `BRANCH` 图案达成里程碑后，获得新样式权限、展示前后进度并给出下一目标；背景仍是档案页上下文，不是本弹窗的静态背景图。
- **设计与交付依据**：`设计方案_A_清透机能.md`、`交付清单.md`。解锁反馈服务于“图案独立成长、局内成功纹身计入熟练度、样式权限逐级开放”，不是 PVP 强度提示。
- **结构契约**：`openspec/changes/restructure-ui-asset-catalog/art/prefab-layout.md`；**通用壳体规范**：`artifacts/美术资源需求/通用UI组件/组件规范.md`。Canvas Scaler 为 `Scale With Screen Size`，Reference Resolution 为 `1920 × 1080`，Match 为 `0.5`；交互和文字位于 90% title-safe 内。
- **分类约定**：`ui-shell` 是静态壳体、遮罩和无文字装饰；`runtime-slot` 是异步图像/特效的容器；`data-asset` 是业务、存档和资源地址；`text` 一律是本地化 `TMP_Text`。所有 `runtime-slot` 保持 `preserveAspect=true`，可拉伸壳体保持 `false`。
- **运行时红线**：解锁图案、图案缩略图、样式预览与样式内容、解锁前后熟练度/百分比/进度段、下一目标与奖励数据（类型、数量、图标、完成进度）都是运行时内容；普通文字、数值、百分比、等级、按键名和错误说明全部走 TMP，绝不烘焙为 Sprite。
- 本台账只定义结构、引用和迁移候选；**不移动、不删除、不重命名，也不生成 PNG**。

## 2. 交互壳体与反馈状态

所有 `focused` 都须提供不依赖色彩的 2px 描边或角标；`pressed` 使用同一壳体压暗 8% 且内缩 2px；`disabled` 为 45% alpha 加通用 `state_disabled`，并保留 TMP 原因。所有输入 glyph 与绑定名由 `TotemInputService` / `ITotemInputProvider` 和 InputModule 在运行时注入。

| 交互壳体/阶段 | normal | focused | pressed | disabled | loading | success | failure | acknowledge |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `UnlockFeedbackForm` | 解锁数据已到位时展示模态与可读背景上下文 | 焦点交给首个可操作项，不给非交互徽章伪造焦点 | 不适用 | 数据为空时仅禁用业务操作，仍允许 Back | 事件、样式、奖励或图案资源到达前显示 `LoadingOverlay`，阻止重复确认 | 数据完整后播放一次运行时庆祝 VFX，`state_success` 与 TMP 摘要共同表达 | 使用 `FailurePanel`，保留返回路径和 Retry | 成功动画结束后锁定事件快照，显示 `AcknowledgeHint`；确认后回到来源页并恢复焦点 |
| `PreviewNowAction` | 通用 ButtonShell 常规 Tint | `FocusOutline` + 控制器焦点可见 | 内缩 2px、暗 8%，尝试打开样式预览 | 无可预览样式/资源失效时 `state_disabled` + TMP 原因 | 预览资源加载时防重入，叠 `state_loading` | 预览打开成功由页面切换/Toast 确认，不制作成功按钮贴图 | 预览失败显示 `state_failure` + Retry，解锁事件不丢失 | 已读但未继续时仍可预览；继续后该按钮不再接受输入 |
| `ContinueAction` / `AcknowledgeHint` | 通用 ButtonShell / InputPrompt | `FocusOutline`，作为成功后的默认焦点 | 内缩 2px、暗 8%，提交确认 | 返回目标不可用时 `state_disabled` + 原因 TMP | 确认提交或存档同步中使用 `state_loading` | 提交完成后用短暂 `state_success` 并关闭模态 | 提交失败保留模态与 `state_failure`，可 Retry 或 Back | 唯一负责确认“已阅读新解锁”；确认后写入已读状态、恢复来源页焦点 |
| `RetryAction` | 仅 failure 后显示的通用 ButtonShell / InputPrompt | `FocusOutline` | 内缩 2px、暗 8% | 无可重试请求时禁用 | 点击后进入 loading，原失败文案仍保留可读 | 重试成功回到 success，再进入 acknowledge | 失败时刷新 TMP 错误细节；不移除 Continue/Back 的安全出口 | 不适用 |
| `GoalCard`（可查看详情时） | 通用 ContentCard；图标和奖励内容运行时注入 | `FocusOutline`，提供目标详情 Tooltip | 内缩 2px、暗 8% | 无详情或该功能未开放时 `state_disabled` | 目标/奖励目录未到位时槽位显示 `state_loading` | 已完成目标以 `state_success` + TMP 说明，不能只变青色 | 缺少奖励图标或数据时 `state_failure` 占位 + 文本 | 模态确认后卡片不保存为静态截图；回到档案页时由实时目标列表重建 |

## 3. 通用引用与页面专属边界

| 需求 | 分类 | 归属 | 用法与限制 |
| --- | --- | --- | --- |
| 模态框、标题/分区容器、失败面板、输入阻断遮罩 | `ui-shell` | 通用 `PanelFrame` / Divider | Image / Sliced，12px 九宫格，以 Tint 和层级参数区分；不保留页面专属弹窗框。 |
| 样式卡、下一目标卡、预览/继续/重试按钮 | `ui-shell` | 通用 `ContentCard` / ButtonShell | Image / Sliced；普通、焦点、按下、禁用全部由同一壳体和状态叠层表达。 |
| 焦点、选择、禁用、锁定、加载、成功、失败 | `ui-shell` | 通用 `FocusOutline` / `SelectionFrame` / `state_*` | focused 有 2px 描边或角标；不得为解锁勾、读取、错误重复输出页面位图。 |
| 熟练度和目标进度 | `ui-shell` + `data-asset` + `text` | 通用 `ProgressBar` / `ProgressRing` | 轨道 Sliced/Simple、填充 Filled/Mask；前后数值、百分比、等级和分段状态来自数据并由 TMP 呈现。 |
| 控制器/键鼠操作提示 | `ui-shell` + `runtime-slot` + `text` | 通用 `InputPrompt` | 底板可复用；glyph 与绑定名运行时替换，绝不把 `A`、`X` 等按键烘焙进图片。 |
| 里程碑六边形空章 | `ui-shell` | UI-005 新解锁反馈专属 | 仅无文字的六边形等级容器；见第 6 节。它不携带等级、图案、奖励或成功勾。 |
| 解锁图案、样式预览、目标/奖励 icon、庆祝粒子 | `runtime-slot` + `data-asset` | 运行时内容 | 分别从 `PatternDefinition`、`StyleDefinition`、`GoalDefinition` / `RewardDefinition` 和 `UnlockVfxDefinition` 解析地址；保持原始比例，不进入页面 Sprite。 |
| 所有标题、名字、等级、进度、奖励数量、描述、错误、按钮/按键名 | `text` | 本地化 TMP | 普通文字一律 `TMP_Text`；数值随存档和奖励目录刷新。 |

## 5. 效果图未展示但完整界面必需的资源/能力

| 模块 | 分类 | 必要性与资源策略 |
| --- | --- | --- |
| 解锁事件、样式/奖励目录与图案图形的异步 loading / failure / retry | `ui-shell` + `runtime-slot` + `text` | 源图只展示成功态；实际加载中用通用 `state_loading`，失败用 `state_failure`、TMP 错误与 Retry，不能把缺图当成成功。 |
| acknowledge 已读确认、重复事件去重与焦点恢复 | `data-asset` + `ui-shell` + `text` | 防止奖励弹窗重复播放或确认后焦点丢失；用 `UnlockEventId`、已读状态、`FocusRestoreAnchor` 和 InputPrompt，不需要新 Sprite。 |
| 无预览样式、失效图案或奖励数据为空的降级态 | `runtime-slot` + `ui-shell` + `text` | 保留图案名与解锁事实，使用运行时默认占位/通用 `state_failure`，而非某个固定 BRANCH 或颜料图片。 |
| 多条新样式/目标的滚动、控制器遍历与长文本 | `ui-shell` + `runtime-slot` + `text` | 源图仅展示单个样式和三项目标；完整界面必须支持 N 项、Tooltip、文本截断/展开与手柄焦点。 |
| 可访问性与非色彩状态表达 | `ui-shell` + `text` | 读屏摘要同时报出图案、等级变化、样式与奖励；成功/失败/禁用必须共同使用图标、颜色和 TMP 文本。 |
| 庆祝粒子、音效和动效降级 | `runtime-slot` + `data-asset` | 特效应由 `UnlockVfxDefinition` 或运行时粒子系统播放；`reduced motion` 时静态显示通用 success 状态，不产出碎纸/闪光 PNG。 |

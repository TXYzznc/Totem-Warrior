# UI-005 局外熟练度与构筑档案｜方案 A：清透机能

> 类型：UI  
> 资源路径：`UI/UI-005_熟练度与构筑档案/`  
> 当前状态：待分配（本文件为制作/寻找资源前的设计与验收 Brief）

## 1. 方案定位

**资源任务**：八图案熟练度、样式权限、构筑快照、战绩与外观展示界面。

**范围说明**：按本资源目录的需求范围制作；不额外拆分未列入台账的资源。

**本方案的核心句**：以干净的合成材质、日照感和克制的颜料高光建立可信的未来生活区。

**适用判断**：推荐作为首个 60 秒美术垂直切片的默认方向；最容易验证角色、可进入建筑、UI 与刺青是否属于同一款游戏。

## 2. 该资源的具体设计

档案像清晰的城市服务终端：八图案按可比网格排列，熟练度、解锁、外观与构筑快照分层展示。

### 视觉构成规则

- **形体/信息层级**：圆角矩形与柔和斜切；主轮廓完整，第二层细节只在近看时出现。
- **材质与表面**：雾面合成织物、半哑光树脂、细颗粒喷砂金属；颜料只在交互、能量或刺青触发点出现。
- **色彩策略**：暖白、浅灰蓝、低饱和青绿为底；七种颜料只做语义色和局部高亮，禁止大面积彩虹铺色。
- **情绪目标**：晴朗、可亲近、仍带一点未知的技术感。
- **与刺青系统的关系**：刺青、颜料、掉落物与撤离信息必须优先于装饰性亮点；本资源只使用活性颜料来解释功能、风险或交互，不把它当作无意义贴纸。

## 3. 生产与交付

八图案熟练度总览、单图案详情、构筑快照、外观展示和新解锁反馈五个界面状态。

制作时需保留可替换材质、可复用模块或可导出的源文件结构；当前以画面效果为先，但不能把后续统一、替换和优化的余地做死。

## 4. 验收清单

- [ ] 在晴天、明亮街区基线下仍然清楚，不依赖黑暗背景或重后处理。
- [ ] 与“接受局部功能性改造的人类 + 活性颜料未来生活区”的世界观一致。
- [ ] 远距离先读用途/威胁/交互，近距离再读材质和细节。
- [ ] 玩家能理解熟练度按图案独立成长、初始拥有线与环、局内成功纹身也会记入熟练度；局外展示不伪装为直接 PVP 强度面板。
- [ ] 与其它方案相比，能明确看出“清透机能”的差异，但不脱离全局美术语言。

## 5. 不通过的情况

把颜色和部位误做成熟练度主轴；数值堆砌压过“我擅长什么构筑”的身份感。

同时不接受：低照度、废土脏乱、过度赛博霓虹、血腥生物化、写实军事风，或为了独特而破坏 UI、角色、建筑之间的统一精细度。

## 6. 选择建议

若该资源是第一批垂直切片资产，优先采用 **方案 A：清透机能** 作为主生产方向；方案 B 用于需要更强远读与卡通亲和力的资产；方案 C 只用于需要强调污染、事件或构筑反馈的局部节点。三个方案可以在同一地图并存，但同一单个资源最终只能选定其中一个作为主语言，避免混搭。

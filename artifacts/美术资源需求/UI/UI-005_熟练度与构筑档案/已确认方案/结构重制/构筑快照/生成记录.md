# UI-005｜构筑快照新版专属素材生成记录

生成日期：2026-07-27  
生成范围：结构重制版 `构筑快照/最终素材/`；旧版 `构筑快照` 目录和文件均未删除、移动或改名。

## 方式与可追溯性

本批 8 项都是无材质的纯色几何语义壳体：使用 Pillow 以 4× 超采样绘制，Lanczos 缩放，再作透明 Alpha 合成。脚本位于 `_source/build_snapshot_sprite_generator.py`；源层 PNG 在 `_source/`，合成中间 PNG 在 `_merged/`，唯一运行时引用目录是 `最终素材/`。

没有纹理、照片、人物、图案、颜料、部位、头像、战绩、文字或输入 glyph，因此无需也没有调用 `image_gen → #00ff00 绿幕 → 去绿 → 切图` 流程。

| 最终素材 | Unity 用法 | 内容边界 |
| --- | --- | --- |
| `build_snapshot_icon_archive.png` | Image / Simple | 档案语义；无标题、槽位数或构筑数据。 |
| `build_snapshot_icon_edit.png` | Image / Simple | 编辑入口；无按键或文案。 |

## 明确引用而非复制

- 面板、列表行、内容卡：通用 `PanelFrame`、`ContentCard/ListRow`（Sliced）。
- 焦点与选中：通用 `FocusOutline/SelectionFrame`。
- 锁、成功、加载、失败：通用 `state_lock`、`state_success`、`state_loading`、`state_failure`。
- XP 轨道/填充、输入提示：通用 `ProgressBar`、`InputPrompt`。
- 图案主图、导航缩略图、样式预览、货币图标：运行时 `TotemAssetService` 目录；所有文案和数值均为 TMP_Text。

本映射仅覆盖 `ProfileShowcaseForm` 的新版专属静态 `ui-shell`。所有最终素材均位于 `最终素材/`，透明 PNG 不含可运行时变化的内容。

| 资源键 | 最终文件 | 目标节点 / Unity 用法 | 内容边界 |
| --- | --- | --- | --- |
| `profile_showcase_icon_appearance` | `最终素材/profile_showcase_icon_appearance.png` | `AppearancePresetPanel/SectionIcon`，`Image.Type = Simple`，`preserveAspect = true` | 抽象的外观层级语义标记；不含角色、服装、纹身、预设缩略图、名称或序号。 |
| `profile_showcase_empty_mark` | `最终素材/profile_showcase_empty_mark.png` | `EmptyPresetState/EmptyMark` 与 `EmptyEmblemState/EmptyMark`，`Image.Type = Simple`，`preserveAspect = true` | 中性档案空态标记；不含头像、图案徽章、锁、加载状态、数值或 TMP 文案。 |

## 明确引用而非复刻

| 页面用途 | 引用来源 | 约束 |
| --- | --- | --- |
| 个人战绩、外观预设、徽章、分享、Tooltip 与失败容器 | 通用 `PanelFrame` | `Image / Sliced`；不制作页面专属面板框。 |
| 预设卡、徽章卡、分享入口与统计行 | 通用 `ContentCard / ListRow` | `Image / Sliced`；状态以通用叠层组合。 |
| 焦点与选中 | 通用 `FocusOutline / SelectionFrame` | 2px 非色彩依赖描边/角标由通用组件提供。 |
| 状态、进度与输入提示 | 通用 `state_*`、`ProgressRing`、`InputPrompt` | 不复制 lock/loading/success/failure、环形填充或输入 glyph。 |
| 三种战绩类别语义图标 | 旧目录候选：`../../战绩外观/战绩外观_图标_纹身机.png`、`../../战绩外观/战绩外观_图标_勾选.png`、`../../战绩外观/战绩外观_图标_日历.png` | 仅作为 `profile_showcase_stat_matches_icon`、`profile_showcase_stat_success_icon`、`profile_showcase_stat_streak_icon` 的待复核保留候选；本轮未复制、移动、重命名或改写。 |

## 运行时与 TMP 边界

- 角色外观、服装/纹身层、预设内容与缩略图、八图案徽章、玩家头像、分享预览构图、战绩数值/日期/百分比，均由运行时地址和数据资产提供。
- 所有标题、标签、名称、序号、数值、百分比、日期、锁定原因、输入绑定与反馈文案均由 `TMP_Text` / InputModule 提供。
- `CharacterAppearanceSlot`、`PresetPreviewSlot`、`EmblemVisualSlot`、`SharePreviewSlot` 和 `CurrentFavoritePatternSlot` 仅为运行时槽位，须 `preserveAspect = true`。

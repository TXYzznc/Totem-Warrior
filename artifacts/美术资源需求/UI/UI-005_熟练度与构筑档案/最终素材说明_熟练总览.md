# UI-005 八图案熟练度总览｜结构与素材清单

## 依据与边界

- **视觉依据**：`UI-005_A_清透机能_01_八图案熟练度总览.png`（`1672 × 941`）；本台账只对应 `MasteryOverviewForm`。
- **设计与交付依据**：`设计方案_A_清透机能.md`、`交付清单.md`。八图案固定为 `LINE`、`RING`、`TRIANGLE`、`WAVE`、`SPIRAL`、`BRANCH`、`HONEYCOMB`、`STARBURST`；`LINE`、`RING` 为初始拥有，不等同于把其图形或等级烘焙成页面 Sprite。
- **运行基准**：Canvas Scaler = Scale With Screen Size，Reference Resolution `1920 × 1080`，Match `0.5`；文字与交互在 90% title-safe 内。所有运行时图像槽位 `preserveAspect=true`，可拉伸背景壳体为 `false`。
- **结构边界**：`ui-shell` 才是静态 Sprite；`runtime-slot` 只定义容器、遮罩与比例；`data-asset` 由业务/存档系统给出；`text` 一律为 `TMP_Text`。本清单不删除、移动或生成任何 PNG；“删除候选”仅是后续清理评审结论。

## 可交互壳体状态

| 交互壳体 | normal | focused | pressed | disabled | locked | loading / success / failure |
| --- | --- | --- | --- | --- | --- | --- |
| `ArchiveNavItem` | 通用 `ListRow` 低对比 Tint | `focus_outline` 2px 青色描边与角标 | 同壳体压暗 8%、内缩 2px | 45% alpha + `state_disabled`；仍保留图标轮廓 | 不适用；无权限入口改为 disabled 并显示原因 Tooltip | 切页加载时用 `state_loading` 覆盖当前项；成功/失败以 Toast + TMP 反馈，不能只变色。 |
| `PatternMasteryCard` | 通用 `ContentCard`，进度环按数据 Fill | `focus_outline` + 非色彩角标；可由手柄逐卡到达 | 同壳体压暗 8%、内缩 2px；打开图案详情 | 45% alpha + `state_disabled`，用于暂不可查询/数据失效 | 通用 `state_lock` + 半透明遮罩；锁定卡仍可 focused 以查看解锁条件，不能把锁定误画成另一张静态卡 | 图案定义/存档同步时覆盖 `state_loading`；解锁刷新以 `state_success`，读取失败以 `state_failure` + 重试。 |
| `ViewRewardsButton` | 通用 ButtonShell / ContentCard 常规 Tint | `focus_outline` 2px 描边与角标 | 压暗 8%、内缩 2px | 45% alpha + `state_disabled` | 条件未达时使用 `state_lock` + Tooltip，不隐藏按钮 | 请求奖励列表时阻止重复触发并叠加 `state_loading`；结果使用 `state_success` / `state_failure` + TMP 文案。 |
| `InputPrompt` | 通用 `prompt_` 底板 | 仅当该操作可作为独立可选项时显示焦点框 | 按绑定触发的短促缩放 | 条件不满足叠加 `state_disabled` | 有权限门槛时叠加 `state_lock` 与条件说明 | 当前绑定切换/解析中可用 `state_loading`；操作结果由反馈层表达。 |
| `RetryButton` | 通用 ButtonShell | `focus_outline` | 压暗 8%、内缩 2px | 无可重试动作时 45% alpha + `state_disabled` | 不适用 | 自身只在 failure 后出现；点击进入 loading，恢复成功/失败 Toast。 |

非交互的 `IdentitySummaryPanel`、标题、统计与进度环不制造虚假 focus；它们只呈现数据与 TMP 文本。上述所有颜色变化均复用同一 Sprite，以 Unity Tint、Image Fill、遮罩和状态叠层实现。

## 效果图外但完整界面必需的补充 UI

| 模块 | 必要性 | 资源策略 |
| --- | --- | --- |
| 图案详情 Tooltip 与锁定原因 | 焦点落在锁定图案时必须告知下一步，而非只显示锁。 | 通用 `PanelFrame` + `state_lock`，图案预览运行时加载，说明用 TMP。 |
| 空档案 / 存档不同步降级态 | 新账号、离线或数据缺失时 2×4 网格不能空白无解释。 | `mastery_overview_empty_mark` + TMP；不使用某一具体图案替代空态。 |
| 数据/奖励请求 loading、success、failure 与重试 | 图案定义、云存档、奖励列表均可能异步失败。 | 复用通用 `state_loading/success/failure`、`PanelFrame`、ButtonShell 和 TMP。 |
| 手柄与键鼠设备切换、焦点恢复 | 页面含 8 张卡、导航与奖励按钮；切换输入或模态关闭后焦点不可丢失。 | 通用 `InputPrompt`、`FocusOutline`；glyph/绑定由 InputModule 提供。 |
| 本地化与屏幕阅读摘要 | 仅凭图标、青/珊瑚色或环形进度不足以传达拥有、锁定和等级。 | TMP 本地化文本与无障碍描述；状态须同时有图标、颜色和文字。 |

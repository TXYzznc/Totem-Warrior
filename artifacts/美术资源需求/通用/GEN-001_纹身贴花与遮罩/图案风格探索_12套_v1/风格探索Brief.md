# 八图案 × 十二风格探索 Brief

## 目标

本轮只用于选择纹身图形语言，不制作正式贴花、遮罩、身体部位适配或 Unity 运行时资源。

- 12 套风格，每套覆盖 8 种图案，共 96 款。
- 每套由一个独立 agent 负责，交付一张横版 `4 × 2` Flash 设计板。
- 画布目标为 `3840 × 2160`；若生成工具只返回较小原图，必须保留原图，并另存明确标注为 `upscaled` 的高质量放大版，不得把放大版描述成原生 4K。
- 本轮由用户选择风格；确认前暂停所有纹身相关正式素材生产。

## 固定图案顺序

图内不放文字、字母或数字，按位置建立稳定映射：

| 位置 | 图案类型 | 设计语义 |
|---|---|---|
| 第一行第 1 格 | 直线型 Line | 方向、贯穿、瞄准、加速；不是简单画一根直线 |
| 第一行第 2 格 | 环型 Ring | 包围、循环、护持、领域；不是简单画一个圆 |
| 第一行第 3 格 | 螺旋型 Spiral | 聚集、牵引、成长、涡流 |
| 第一行第 4 格 | 折线型 Zigzag | 变向、连锁、路径、折返；与闪电型轮廓明确不同 |
| 第二行第 1 格 | 闪电型 Bolt | 瞬发、爆发、穿透、分叉冲击 |
| 第二行第 2 格 | 星型 Star | 焦点、指引、爆点、辐射 |
| 第二行第 3 格 | 流线型 Stream | 运动、延展、连续、导流 |
| 第二行第 4 格 | 兽型 Beast | 本能、追猎、召唤、威慑；不限定为某一种动物 |

## 色彩合同

- 每款纹身的主体是一个可被七色颜料系统统一替换的纯色区域。
- 探索稿统一用深石墨色表现“可着色主体”，只允许通过纯色块、实线、点阵、排线和负形塑造层次，不使用半透明渐变冒充多色。
- 设计固有色只用于小面积焦点，例如眼睛、金属钉、封印节点、护符珠或颜料结晶。
- 固定色总面积不得超过单个图案可见墨色面积的 `15%`。
- 不能靠固定色区分八种图案；缩小后仍应先读出轮廓和节奏。

## 统一构图与验收

- 纯平面 tattoo flash sheet；不画人体、皮肤照片、UI、贴花预览或游戏场景。
- 暖白或浅中性纸张背景，八格留白一致，每格只有一个完整图案，互不连接、互不重叠。
- 图案在格内尺寸接近，四周保留安全边距；细节足以放大审阅，缩略图下仍能区分八种语义。
- 整体气质为“帅气、内敛、真实可纹”，避免廉价贴纸、企业 Logo、文字、宗教专属符号照搬、版权角色、血腥和水印。
- 同一张板必须像同一个纹身师的一套 Flash；不同板之间必须能明显看出风格差异。
- 最终 PNG 需检查文件签名、画布尺寸、8 格完整性、固定色比例和有无乱码/水印。

## 十二套风格

1. `S01_几何黑工`：硬朗实黑、精确负形、结构克制、现代黑工纹身。
2. `S02_新部落流线`：沿肌肉走势的粗细节奏、钩形与回旋，但避免复刻特定文化图腾。
3. `S03_细线秘纹`：细线、微型节点、护符式结构、低装饰密度，保持可纹性。
4. `S04_版画写意`：蚀刻排线、木刻节奏、具象隐喻；用单色排线而非灰阶渐变。
5. `S05_几何机能`：模块分段、技术刻度感、机械接口语法，但不是 UI 图标。
6. `S06_Cyber_Sigilism`：尖锐符印、断续路径、数字时代神秘感；避免不可读文字与现成 Logo。
7. `S07_生物机械`：肌腱、甲片、接口与有机机械融合，保持非血腥、非写实器官。
8. `S08_活性颜料裂变`：结晶、裂隙、流体张力和局部失序；固定色结晶面积仍不得超过 15%。
9. `S09_日式传统`：借鉴构图、风与波的节奏和留白，不直接复制传统宗教或帮派符号。
10. `S10_美式传统`：粗轮廓、紧凑构图、少量固定色焦点；主体仍保持单色可替换。
11. `S11_黑灰写实`：用单色点阵、排线和负形模拟写实层次，不使用灰阶透明渐变。
12. `S12_Tribal_Blackwork`：大块实黑、强负形、原始力量感；与 S02 的流线轻盈感明确区分。

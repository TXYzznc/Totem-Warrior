# GEN-001 图案风格探索索引

## 使用边界

- 本目录为 **12 套风格选择稿**，用于比较图形语言与确定后续正式生产方向。
- 每套画布均按固定 `4×2` 语义排列：上排 `Line / Ring / Spiral / Zigzag`，下排 `Bolt / Star / Stream / Beast`。
- 所有 `_upscaled.png` 均为 **非原生 4K 放大版**，实际尺寸已核验为 `3840×2160`；不能把放大版视为重新生成的原生 4K 细节。
- 本轮不包含正式贴花拆分、透明遮罩、人体曲面适配、Unity 导入与运行时接入。

## QA 结论

- 结构检查：`12/12` 套均具备原始 PNG、`_upscaled` PNG 和 `交付清单.md`。
- 文件检查：`12/12` 张放大版均可正常解码，实际尺寸均为 `3840×2160`。
- 目视检查：`12/12` 套均保持固定 `4×2` 语义；Zigzag 与 Bolt 可区分；未发现文字、水印、完整人物、场景或 UI 面板。
- 风格检查：12 套各自的主视觉语言成立，S02 与 S12 的部落/黑工方向也具有可辨别的轻重与几何差异。

### 非阻塞备注

1. S02 的 Zigzag 使用较柔和的连续 S 形回折，角度感弱于其他风格的 Zigzag；当前仍能凭连续路径与下排冲击式 Bolt 清楚区分。若该风格进入正式生产，建议加强折点节奏，同时保留新部落流线特征。

# v2 十二套风格定向

本文件补充 `重绘Brief.md`，用于确保十二套之间有明确区分，同时保持“美观 60% / 效果倾向 40%”。

| 编号 | 风格 | 本轮造型重点 | 避免 |
|---|---|---|---|
| S01 | 几何黑工 | 强轮廓、黑块与负形、精确切面、克制而有压迫感 | 公司 Logo、八枚技能图标 |
| S02 | 新部落流线 | 身体走向、刀锋曲面、收放节奏、现代抽象图腾 | 旧式模板感、机械重复 |
| S03 | 细线秘纹 | 纤细结构、点刺、微型结点、精致留白 | 直接复制宗教神圣符号 |
| S04 | 版画写意 | 木刻排线、自然意象、飞白、叙事剪影 | 八张小插画彼此无关 |
| S05 | 几何机能 | 模块结构、机械接缝、非对称焦点、可穿戴的工程美感 | HUD、准星、按钮图标 |
| S06 | Cyber Sigilism | 尖锐书写性、数字时代秘符、细黑线与尖刺张力 | 可读字母、现成乐队 Logo |
| S07 | 生物机械 | 优雅甲壳、肌腱与机械关节融合、沿身体生长 | 血腥器官、廉价怪物贴纸 |
| S08 | 活性颜料裂变 | 墨迹增殖、晶体分叉、细胞般扩散、受控失序 | 单纯泼墨、杂乱噪点 |
| S09 | 日式传统 | 风、水、绳、植物与异兽的构图节奏，饱满而可读 | 拼贴八个陈旧题材图标 |
| S10 | 美式传统 | 粗线、坚实色块、经典闪片构图、鲜明剪影 | 直接照搬常见图库纹身 |
| S11 | 黑灰写实 | 雕塑感、烟雾和材质层次、单体叙事构图 | 照片方框、灰泥一片 |
| S12 | Tribal Blackwork | 原创黑色图腾、肌肉走向、厚薄变化、强烈留白 | 挪用特定族群神圣纹样 |

## 特别保留与强化

- S05、S07、S09 是用户已经明确喜欢的方向，应保留风格识别度，同时将八个具体设计全部重做得更漂亮。
- S05 要像“可佩戴的机械结构”，不是界面符号。
- S07 要有生物与机械共生的优雅感，避免猎奇。
- S09 以完整纹身构图节奏为核心，让传统题材服务于画面，而不是题材清单。

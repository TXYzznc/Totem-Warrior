# 纹身图案风格探索 v2｜美观优先

## 本轮目标

- 重新绘制 12 种风格，每种风格 8 个独立纹身图案，共 96 个候选设计。
- 设计权重：美观、构图与身体贴合表现占 60%；玩家可感知的效果倾向占 40%。
- `直线 / 环 / 螺旋 / 折线 / 闪电 / 星 / 流 / 兽` 仅是内部槽位代称，不得按字面画成八枚符号或 UI 图标。
- 本轮只做风格探索稿；正式纹身贴花、遮罩与 Unity 入库继续暂停，等待用户选型。

## 八个内部槽位的隐藏语义

这些语义只用于指导视觉气质，不作为画面文字，也不要求使用对应的传统符号。

1. 精准、穿透、明确指向
2. 守护、循环、领域感
3. 聚集、牵引、生长
4. 连锁、转向、路径变化
5. 爆发、冲击、破势
6. 聚焦、辉光、致命一击
7. 延续、流动、机动
8. 本能、追猎、召唤、野性

## 画面与构图要求

- 横向高分辨率 4×2 展示板，完整呈现 8 个设计。
- 不放标题、编号、名称、说明文字、水印或装饰边框。
- 暖灰白纸张背景，图案间留出充足呼吸空间。
- 每个图案优先建立漂亮、易识别的整体轮廓，再组织内部节奏、负形与细节。
- 图案应像可落在人体上的真实纹身设计，而不是企业 Logo、技能图标、应用图标或素材包图标。
- 同一套八图案应像由同一位纹身师完成，但不能只是同一图案的轻微变体。
- 至少 3 个图案应采用间接隐喻表达效果倾向，避免落回旧槽位名称的字面图形。
- 允许对称、非对称、纵向、横向、环抱式等不同身体走向；以视觉完成度为第一标准。

## 颜色约束

- 主体为可整体换色的一种纯色，本轮统一以深石墨黑表现。
- 可保留少量设计固定色，用于视觉焦点或结构识别。
- 固定色总面积不得超过可见墨色面积的 15%。
- 固定色使用实色，不用透明渐变伪装多色；可用留白、点刺、排线和实色块建立层次。

## 验收规则

- 每套恰好 8 个完整、互不遮挡、无裁切的设计。
- 美观性优先于语义直白；效果倾向应“能感受到”，而不是“看见标签”。
- 不照搬 v1，不依赖旧八名称构图。
- 无明显重复轮廓、无文字乱码、无水印、无版权角色、无直接复制宗教或特定族群神圣符号。
- 保留原始生成图；若原图不足 4K，另交付等比例 Lanczos 放大并补边至 3840×2160 的“非原生4K”预览图。

# 纹身图案风格探索 v2｜选择索引

## 本轮口径

- 共 12 套风格、每套 8 个设计，共 96 个候选图案。
- 美观、画面表现与真实纹身构图占 60%；效果倾向暗示占 40%。
- 旧称 `直线 / 环 / 螺旋 / 折线 / 闪电 / 星 / 流 / 兽` 只作为内部历史槽位，不是画面题目。
- 主体为单一可换色深石墨色；允许不超过可见墨色面积 15% 的固定色。
- 本目录只用于风格选型；正式贴花、遮罩、拆分与 Unity 入库继续暂停。

## 审稿说明

- S03、S04 的首轮 v2 稿在独立审稿中被判定仍有较强的旧槽位逐格映射，因此已追加修订，并将修订稿设为最终评审稿；旧稿保留在各自目录，仅作过程对照。
- S01、S05 含少量可被联想到特定效果或生物轮廓的单体，但整套没有按八个旧称一对一排列，保留为候选。
- 所有 4K 图均为从原始生成图进行 Lanczos 等比例放大后补边得到的非原生 4K 评审图，不冒充原生细节。
- 每套目录中的 `交付清单.md` 记录了原始尺寸、提示词摘要、放大方式和自检结果。

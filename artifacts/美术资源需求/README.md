# 美术资源需求目录

本目录是 3D PvPvE 美术垂直切片及后续生产的唯一资源需求索引根目录。

- 总台账：`美术资源需求表.xlsx`
- 模型需求：`模型/`
- UI 需求：`UI/`
- 通用资源需求：`通用/`

## 使用规则

1. 先在 Excel 中新增或更新资源条目，再在表内规定的相对路径放入文件。
2. 资源文件名称应以台账编号开头，例如 `CHR-001_基础角色模型.fbx`。
3. 用户自行寻找的资源与由 Codex 制作的资源使用同一条目；来源差异在资源描述和状态中记录。
4. 只有验收通过的资源才能改为“已完成-符合”。需要返工的资源保留在原路径，并标记为“已完成-需返工”。
5. 不要通过复制资源绕过台账；一个可用资源至少对应一条编号记录。

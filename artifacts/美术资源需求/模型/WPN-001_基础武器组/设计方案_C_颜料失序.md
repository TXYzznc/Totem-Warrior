# WPN-001 基础武器组｜方案 C：颜料失序

> 类型：模型  
> 资源路径：`模型/WPN-001_基础武器组/`  
> 当前状态：待分配（本文件为制作/寻找资源前的设计与验收 Brief）

## 1. 方案定位

**资源任务**：短刀、重锤、手枪、弓、能量拳套；统一明亮活性颜料世界的轮廓与材质。

**范围说明**：按本资源目录的需求范围制作；不额外拆分未列入台账的资源。

**本方案的核心句**：保持明亮生活街区的底色，但让少量活性颜料泄漏、流动与结晶成为更醒目的个性签名。

**适用判断**：适合想强化“刺青构筑改变世界反馈”的路线；必须严格控制失序面积，不能压过战斗信息。

## 2. 该资源的具体设计

击发或蓄力时才沿武器功能线出现局部颜料流，不让常态外观过花，确保玩家先读到武器种类。

### 视觉构成规则

- **形体/信息层级**：稳定的生活化主形体上叠加局部不对称的滴落、流带、晶化或断续发光边。
- **材质与表面**：正常材质仍占主体；活性颜料呈现半透明凝胶、薄膜虹彩或结晶颗粒，但不使用脏污、血腥或黏腻写实处理。
- **色彩策略**：晴天暖中性色为底；一处物体通常只选一种主颜料色和一种弱辅助色，以明度差而非全色相堆叠制造危险。
- **情绪目标**：鲜明、危险、像一场尚未失控的街区颜料事故。
- **与刺青系统的关系**：刺青、颜料、掉落物与撤离信息必须优先于装饰性亮点；本资源只使用活性颜料来解释功能、风险或交互，不把它当作无意义贴纸。

## 3. 生产与交付

五类武器正交展示、第一/第三人称握持图、材质与颜料反应区说明、武器类别剪影图。

制作时需保留可替换材质、可复用模块或可导出的源文件结构；当前以画面效果为先，但不能把后续统一、替换和优化的余地做死。

## 4. 验收清单

- [ ] 在晴天、明亮街区基线下仍然清楚，不依赖黑暗背景或重后处理。
- [ ] 与“接受局部功能性改造的人类 + 活性颜料未来生活区”的世界观一致。
- [ ] 远距离先读用途/威胁/交互，近距离再读材质和细节。
- [ ] 五类武器在中远距离可一眼区分；与手臂、刺青、VFX 使用同一套圆角与能量语言；不需要黑暗背景才看得清。
- [ ] 与其它方案相比，能明确看出“颜料失序”的差异，但不脱离全局美术语言。

## 5. 不通过的情况

过度写实枪械、尖锐军武语汇、全武器霓虹常亮或多色 LED 堆砌。

同时不接受：低照度、废土脏乱、过度赛博霓虹、血腥生物化、写实军事风，或为了独特而破坏 UI、角色、建筑之间的统一精细度。

## 6. 选择建议

若该资源是第一批垂直切片资产，优先采用 **方案 A：清透机能** 作为主生产方向；方案 B 用于需要更强远读与卡通亲和力的资产；方案 C 只用于需要强调污染、事件或构筑反馈的局部节点。三个方案可以在同一地图并存，但同一单个资源最终只能选定其中一个作为主语言，避免混搭。

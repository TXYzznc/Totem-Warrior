# INT-PROP-008｜木质货箱

## 1. 资产定位

常见、低耐久、易识别的可破坏容器。默认尺寸 **0.80×0.80×0.75m**；保持跨地图通用，不刻入绿洲新城专属标记。

## 2. 默认造型与材质

- 状态：完整、未受击，无裂纹扩张或命中反馈。
- 轮廓：标准方箱，宽木板和圆角加固条形成大块面。
- 结构：六面板、四角加固、两侧搬运孔；仅预留合理破坏切分线。
- 材质：浅暖木色、低饱和青灰加固件，磨损克制。

## 3. 生产与交互预留

底面中心为原点，具有识别性的一侧为正面。面板与加固条应支持后续碎片规划，但当前不生成碎片、内部物资或破坏动画。

## 4. 多视图要求

六视图展示板材方向、角部连接、搬运孔和底部接地；各面细节可变化，但板厚和加固结构必须一致。

## 5. 检查清单

- [ ] 大块面清楚，未堆砌写实碎木细节。
- [ ] 木纹尺度在六面保持一致。
- [ ] 堆叠与接地稳定。
- [ ] 未提前生成碎片或破坏状态。

# INT-PROP-008｜木质货箱

## 1. 资产定位

常见、低耐久、易识别的可破坏容器。默认尺寸 **0.80×0.80×0.75m**；保持跨地图通用，不刻入绿洲新城专属标记。

## 2. 默认造型与材质

- 状态：完整、未受击，无裂纹扩张或命中反馈。
- 轮廓：标准方箱，宽木板和圆角加固条形成大块面。
- 结构：六面板、四角加固、四个竖向面各一个搬运孔；仅预留合理破坏切分线。
- 材质：浅暖木色、低饱和青灰加固件，磨损克制。

## 3. 生产与交互预留

底面中心为原点，具有识别性的一侧为正面。面板与加固条应支持后续碎片规划，但当前不生成碎片、内部物资或破坏动画。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 正面由四条等高横向宽木板组成，上方第一条木板中央开一个横向圆角矩形搬运孔；孔洞为真实贯穿，不是黑色贴花。
- 左右两根低饱和青灰竖向加固条从顶角延伸至底角，顶部和底部均由加厚圆角护块包覆。
- 最下方保留一条较厚木质底梁，整面无文字、钉牌、裂纹或斜向木条。

### 背面 Rear

- 背面与正面使用相同的四条横向木板、中央搬运孔、两根竖向加固条和上下角护块。
- 木板拼缝高度、板厚和木纹尺度与正面一致，但细小木纹不做完全镜像复制。
- 背面不得增加铰链、箱盖缝、金属锁或标签；该货箱不是可开盖物资箱。

### 左侧 Left

- 左侧同样由四条横向宽木板组成，上方第一条木板中央保留一个与正面同尺寸的搬运孔。
- 前后两根青灰竖向加固条完整夹住木板边缘，角护块尺寸与正面一致；底部木梁连续接地。
- 左侧不增加斜撑、锁扣或破坏裂纹，板材方向仍保持水平。

### 三视图共同约束

- 四个竖向面各有 1 个同尺寸搬运孔，确保轴测图已出现的相邻两面搬运孔能够成立；顶面没有搬运孔。
- 每个竖向面均为 4 条横板，四角加固结构相同；木纹可以自然变化，但纹理尺度和方向必须一致。

## 5. 检查清单

- [ ] 大块面清楚，未堆砌写实碎木细节。
- [ ] 木纹尺度在六面保持一致。
- [ ] 堆叠与接地稳定。
- [ ] 未提前生成碎片或破坏状态。

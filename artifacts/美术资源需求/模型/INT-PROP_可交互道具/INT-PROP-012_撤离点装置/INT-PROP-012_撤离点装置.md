# INT-PROP-012｜撤离点装置

## 1. 资产定位

撤离点唯一的世界空间装置，以一个模型同时承担中远距离地标和近距离撤离操作入口。默认占地 **1.20×1.20m**、高度 **2.80m**；不再额外制作独立撤离终端。

## 2. 默认造型与材质

- 状态：未激活，屏幕待机，无光束、范围环、粒子或倒计时。
- 轮廓：上窄下稳的高耸主柱，顶部开放式信号框形成远读轮廓。
- 结构：地面锚座、主柱、顶部信号结构、基座正面倾斜交互面、输入/身份读取区和背部维护接口。
- 材质：暖白主柱、深灰结构件与交互面、少量低饱和青绿半透明信号面；屏幕内容由运行时 UI 提供。

## 3. 生产与交互预留

原点位于锚座底面中心，交互面侧为正面。锚座、主柱、信号框、交互面和维护件合理分件；玩家站位侧必须无阻挡。激活、撤离读条、离开范围暂停、成功/失败状态、光束与声音挂点在 Unity 导入前另行确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以基座倾斜交互面所在方向为正面；黑色空白屏幕位于站立操作高度并向上后方倾斜，屏幕下方中央是突出的输入/身份读取模块。
- 基座左右各有一条暖白承力侧框包住交互面，中央主柱从基座后部向上收窄，不遮挡玩家站位。
- 四个地面锚座固定为前左、前右、后左、后右各 1 个；正视图主要显示两个前锚座，深灰底脚稳定接地并带中性青绿小嵌条。
- 顶部开放式信号结构由中央轴和四片向外张开的深灰框臂组成，每片内嵌一条中性青绿半透明面；默认不发光。

### 背面 Rear

- 背面不出现屏幕和读取模块；基座中央设置一块封闭的深灰维护面板，下方保留一个带封盖的小型维护接口。
- 两根对称斜撑从主柱下部连接至后左、后右锚座，形成稳定三角受力；斜撑不得侵入前方玩家操作区。
- 后方两个锚座完整可见，位置与前方锚座形成 1.20×1.20m 方形占地。
- 主柱、顶部中央轴和四片信号框臂与正面保持相同高度和展开角度；背面不增加屏幕、天线或电缆。

### 左侧 Left

- 左侧清楚显示交互台的楔形截面：屏幕向后倾斜，读取模块从前方下部突出，前方保留完整站立净空。
- 左侧前后两个锚座和一根连接后锚座的斜撑完整可见；锚座不得移动到中央或增加第五个支脚。
- 主柱从宽基座向上均匀收窄，侧面保留轴测终稿中的纵向暖白大面和少量中性青绿嵌条。
- 顶部信号结构侧视仍为开放框架，前后框臂不合并成实心塔头。

### 三视图共同约束

- 屏幕与读取模块仅位于正面；维护面板和维护接口仅位于背面；四个锚座的位置固定。
- 高度固定 2.80m、占地固定 1.20×1.20m；不得改变信号框臂数量、屏幕倾角、锚座数量或玩家侧净空。
- 所有屏幕、灯带和信号面保持关闭/中性，不生成光束、范围环、倒计时、文字或粒子。

## 5. 检查清单

- [ ] 无特效时仍能在中远距离识别撤离点。
- [ ] 近距离可自然站立操作，交互面不被支撑结构遮挡。
- [ ] 单一模型覆盖地标与操作需求，不依赖独立终端。
- [ ] 屏幕、倒计时和范围反馈未固定烘焙。

# INT-PROP-007｜泄漏危险颜料罐

## 1. 资产定位

用于危险资源、局部环境风险或高收益交互点。默认尺寸 **0.75×0.75×1.10m**；以不对称护框和危险接口区别于正常封存罐。

## 2. 默认造型与材质

- 状态：主体完整，存在受控泄漏迹象，但未被玩家操作。
- 轮廓：放大的罐体配偏置保护框和集液托盘。
- 结构：一处风险接口、警示护框、集液托盘；本阶段不制作破坏切换。
- 材质：浅色主壳、深灰护框、珊瑚警示件；颜料颜色不固定烘焙。

## 3. 生产与交互预留

底面中心为原点，风险接口侧为正面。接口、护框、托盘和罐体应独立分区；粒子、流体、伤害范围、关闭阀门和破坏状态均后续确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以风险接口和集液托盘所在面为正面；上半部纵向深色观察窗居中，下半部圆形风险接口与其同轴。
- 风险接口由深灰基座、珊瑚橙八边外环和珊瑚橙圆形封盖构成；封盖保持关闭，不喷射液体。
- 深灰集液托盘从接口下方水平向前突出，宽度略大于接口，底部与护框底脚稳定接地；托盘内部只保留深灰格栅。
- 四根深灰护框立柱包围暖白罐体，顶部两条珊瑚橙横向护杆连接前后框架；顶部深灰封盖居中。

### 背面 Rear

- 背面不设置观察窗、风险接口或托盘；暖白罐体背面保持完整连续。
- 深灰保护框仍由四根立柱和上下横梁闭合，背面左右各有一条对称斜撑，形成稳定三角支撑。
- 两条珊瑚橙顶部护杆在背面端点与深灰框架连接；背面不添加阀门、控制盒或泄漏痕迹。

### 左侧 Left

- 左侧主要显示深灰保护框的侧向轮廓：前后立柱之间设置单条对角斜撑，形成一个大三角开口。
- 暖白罐体侧面为连续大面，不设置观察窗或接口；正面托盘只在画面右缘表现其向前突出的侧面厚度。
- 珊瑚橙顶部护杆前后贯通，深灰底框与前后立柱完整接地。
- 左侧不得出现第二托盘、第二风险接口或固定色液体。

### 三视图共同约束

- 观察窗、风险接口和集液托盘都仅位于正面；危险结构的不对称性不得被镜像或复制到背面。
- 静态泄漏迹象仅允许接口下缘一条极轻微中性污痕，不生成彩色液池、滴流、烟雾或粒子。

## 5. 检查清单

- [ ] 无特效时也能与正常颜料罐区分。
- [ ] 托盘与风险接口的对应关系明确。
- [ ] 结构仍是完整容器，不误读为已爆炸残骸。
- [ ] 危险颜色和范围可由运行时替换。

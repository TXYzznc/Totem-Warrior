# INT-PROP-001｜小型补给箱

## 1. 资产定位

少量基础补给、低风险拾取点或教学阶段使用的轻型容器。默认尺寸 **0.65×0.45×0.42m**，可跨地图独立摆放；与标准物资箱共享家族语言，但必须明显更轻、更便携。

## 2. 默认造型与材质

- 状态：关闭、完整、未交互，无发光、粒子或领取反馈。
- 轮廓：短窄箱体配一体化顶部提手，不得做成手提包。
- 结构：上盖、单主锁扣、两侧搬运凹槽、底部耐磨脚垫；盖缝和铰链位置必须可解释。
- 材质：暖白/浅灰复合树脂外壳、深灰蓝底板、少量低饱和青绿功能条。

## 3. 生产与交互预留

原点位于底面中心，正面以主锁扣侧为准。上盖、锁扣和箱体可在建模阶段按未来交互需要拆分，但本阶段不定义开启角度、动画、内容物或碰撞逻辑。

## 4. 多视图要求

后续需生成 front、rear、left、right、top、axon 六张同版本纯色背景图；完整展示提手、盖缝、锁扣、搬运凹槽和接地脚垫，并提供 1m 尺度参照与材质分区。

## 5. 检查清单

- [ ] 体量明显小于 INT-PROP-002。
- [ ] 主锁扣侧固定为正面，六视图结构一致。
- [ ] 功能色、稀有度和提示信息未烘焙进几何。
- [ ] 未提前制作开启或领取状态。

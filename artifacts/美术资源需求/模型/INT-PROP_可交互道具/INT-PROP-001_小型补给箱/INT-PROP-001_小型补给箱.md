# INT-PROP-001｜小型补给箱

## 1. 资产定位

少量基础补给、低风险拾取点或教学阶段使用的轻型容器。默认尺寸 **0.65×0.45×0.42m**，可跨地图独立摆放；与标准物资箱共享家族语言，但必须明显更轻、更便携。

## 2. 默认造型与材质

- 状态：关闭、完整、未交互，无发光、粒子或领取反馈。
- 轮廓：短窄箱体配一体化顶部提手，不得做成手提包。
- 结构：上盖、单主锁扣、两侧搬运凹槽、底部耐磨脚垫；盖缝和铰链位置必须可解释。
- 材质：暖白/浅灰复合树脂外壳、深灰蓝底板、少量低饱和青绿功能条。

## 3. 生产与交互预留

原点位于底面中心，正面以主锁扣侧为准。上盖、锁扣和箱体可在建模阶段按未来交互需要拆分，但本阶段不定义开启角度、动画、内容物或碰撞逻辑。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以单个主锁扣所在面为正面；锁扣严格位于水平中心线，上端跨接箱盖、下端落在箱体锁座内。
- 箱盖与箱体之间保持一条连续水平盖缝，正面不增加第二锁扣、显示屏或标签。
- 顶部一体化提手横向居中，深灰握把与两端支座完整可见；提手不得偏向任一侧。
- 暖白主壳下方是连续深灰蓝耐磨底带，正面左右各有一个短脚垫/护角落地。

### 背面 Rear

- 背面不出现锁扣、屏幕或搬运凹槽；主体保持一块连续暖白壳面与相同水平盖缝。
- 盖缝上方设置两个低矮铰链座，分别位于背面宽度约 1/3 与 2/3 处；两者尺寸、颜色和高度一致。
- 顶部提手仍保持正中，背面能看到两端支座；深灰底带和左右落地脚与正面对齐。
- 背面只保留浅层结构分缝，不增加通风孔、接口或装饰贴花。

### 左侧 Left

- 左侧中央偏上设置一个横向矩形搬运凹槽，形状与轴测图可见侧面的凹槽完全一致：深灰内腔、青绿色上沿、暖白外框。
- 水平盖缝从前至后贯通；左侧不出现主锁扣或铰链正面。
- 提手左端支座位于顶面中部，不侵入侧面搬运凹槽；底部深灰耐磨带前后各形成一个落地护角。
- 左侧外壳除搬运凹槽外保持大块连续面，不添加按钮、标签或接口。

### 三视图共同约束

- 主锁扣 1 个、背部铰链 2 个、左右搬运凹槽各 1 个；数量和位置不得变化。
- 继续使用轴测图的暖白主壳、深灰蓝底座/握把与少量青绿嵌条，不生成文字或稀有度信息。

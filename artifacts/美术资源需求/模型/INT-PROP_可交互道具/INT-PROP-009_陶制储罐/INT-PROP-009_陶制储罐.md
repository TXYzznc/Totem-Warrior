# INT-PROP-009｜陶制储罐

## 1. 资产定位

脆性可破坏容器，与木箱、金属箱形成直观材质差异。默认尺寸 **直径0.60m、高0.90m**，适合生活区、仓储区等多种场景。

## 2. 默认造型与材质

- 状态：完整、未受击，无裂纹。
- 轮廓：厚口沿、宽腹、收窄底部，稳定而非细长花瓶。
- 结构：主罐体、厚底和简化把手；釉面分区不绑定地图纹样。
- 材质：暖白陶胎、青绿或蓝灰釉面带，允许轻微自然釉色变化。

## 3. 生产与交互预留

底面中心为原点，把手对称轴确定正面。完整罐体作为默认模型；破碎块、内部内容物、碰撞切换和碎裂动画在 Unity 导入前另行确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 正面沿两个把手的对称中线观察：左右把手同时完整可见，并在肩部同高连接罐体。
- 轮廓从厚圆口沿向内收成短颈，再扩张到最宽腹部，最后缓慢收窄至稳定圆底；不得拉成长颈花瓶。
- 肩部环绕一条浅青绿釉带和一条蓝灰釉带，底部重复相同顺序的两条环带；釉带连续绕罐一周。
- 罐口保持敞开，能看到统一厚度的内壁与中性空腔，不展示内容物。

### 背面 Rear

- 背面与正面共享相同的整体曲线、左右把手轮廓、口沿厚度和四条环绕釉带。
- 背面大面积暖白陶胎保持干净，只允许轻微自然釉色变化；不增加纹样、文字、裂纹或背部附件。
- 把手连接点与正面保持同高同宽，左右不得出现不同数量的连接凸台。

### 左侧 Left

- 左视图中左侧把手位于轮廓外侧中央，表现为一个完整椭圆环；另一侧把手被罐体遮挡，不额外画成第二个外露把手。
- 罐口、短颈、宽腹和窄底的纵向曲线必须与正面一致；环绕釉带在侧面保持水平且宽度不变。
- 底部圆形接触面完整落地，侧面不增加出水口、盖子或装饰浮雕。

### 三视图共同约束

- 把手固定为相对的 2 个，釉带固定为肩部 2 条、底部 2 条；陶罐前后不区分功能部件。
- 保持自然陶胎与釉面质感，不制作裂纹、缺口、内容物或地图专属纹样。

## 5. 检查清单

- [ ] 重心和底面足以稳定放置。
- [ ] 陶胎与釉面区域清楚。
- [ ] 无地图专属文字或纹样。
- [ ] 未提前制作裂纹与碎片。

# INT-PROP 可交互道具生产阶段与确认门禁

## 当前定位

本组资源属于游戏内容资产，不属于任何地图的专属装饰。绿洲新城可以摆放这些道具，但道具的功能、模型编号、Prefab 和后续交互逻辑均独立维护。

“默认状态详细描述”已于 2026-08-05 通过用户确认。随后复核并移除实体纹身工作台与三类缺少玩法依据的独立终端，将撤离终端功能合并进撤离点装置；当前共保留 12 个单项资源目录。12 张轴测图等待用户确认，其他多视图、3D 生成、Blender 和 Unity 导入尚未开始。

## 固定生产顺序

1. 需求登记：确认资产类别、变体数量和游戏用途。
2. 详细描述：确认默认状态、轮廓、尺度、材质语言和功能识别点。
3. 轴测与多视角效果图：逐项确认正面轴测、背面轴测、正/侧/背/顶视图及材质分区。
4. 3D 建模：依据已确认效果图生成或制作基础模型。
5. Blender 处理：结构整理、比例和轴向校验、UV、PBR、LOD、碰撞、枢轴与可交互状态方案。
6. Unity 导入：仅在模型及可交互状态通过确认后进行材质、Prefab 和导入设置。

每一步均是独立确认门禁。前一步未确认，不得提前执行后一步。

## 本阶段边界

- 只描述默认静态状态。
- 不定义开启、关闭切换、受击、破坏、领取、激活、成功或失败动画。
- 可以预留合理的门缝、铰链、抽屉、盖板、屏幕、接口和拆分线，但不把预留视为已确认的交互结构。
- 元素颜色、稀有度、玩家身份和事件内容优先预留为运行时材质、贴花、屏幕或挂点，不烘焙成专属几何。
- 不创建 FBX、贴图、Blender 文件、Prefab 或 Unity 材质。

## 跨资源统一规则

- 美术语言：明亮、干净、生活化的近未来设备；圆角、清楚的功能分区和克制的活性颜料反应区。
- 主色：暖白、浅灰蓝、低饱和青绿；结构件可用深灰蓝，警示件可少量使用珊瑚橙。
- 禁止：军事写实、废土脏污、暗黑赛博、无意义霓虹、密集小零件、满表面发光和无法判断用途的抽象造型。
- 比例：统一按 Unity 1 单位 = 1 米设计；本阶段尺寸为效果图和建模基线，后续可在详细评审时微调。
- 可读性：第三人称中距离首先依赖轮廓和体块区分，文字和小图标只作为辅助。

## 下一确认节点

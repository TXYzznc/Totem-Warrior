# INT-PROP-004｜便携颜料罐

## 1. 资产定位

用于小份颜料采集、拾取或携带的手持级容器。默认尺寸 **0.28×0.28×0.45m**；脱离具体地图也应能通过窗口和密封结构被识别为颜料容器。

## 2. 默认造型与材质

- 状态：密封、完整、未交互，液位静止。
- 轮廓：竖向小罐，顶部握柄与底部防滚结构明显。
- 结构：密封盖、透明观察窗、可替换标签槽和防滚底座。
- 材质：雾面浅色外壳、半透明树脂窗口、软触深灰握柄；颜料颜色运行时控制。

## 3. 生产与交互预留

底面中心为原点，观察窗朝正面。密封盖、握柄、窗口和罐体可分件；开盖、倾倒、采集和液体动画不在本阶段定义。

## 4. 多视图要求

六视图需清晰展示握柄厚度、窗口位置、密封盖和防滚结构；窗口内部只表现中性静止液位，不固定元素颜色。

## 5. 检查清单

- [ ] 单手可搬的尺寸与握持逻辑成立。
- [ ] 不与补给箱或普通水壶混淆。
- [ ] 半透明窗口与外壳材质区分明确。
- [ ] 未制作流动、喷溅或开盖状态。

# INT-PROP-004｜便携颜料罐

## 1. 资产定位

用于小份颜料采集、拾取或携带的手持级容器。默认尺寸 **0.28×0.28×0.45m**；脱离具体地图也应能通过窗口和密封结构被识别为颜料容器。

## 2. 默认造型与材质

- 状态：密封、完整、未交互，液位静止。
- 轮廓：竖向小罐，顶部握柄与底部防滚结构明显。
- 结构：密封盖、正面透明观察窗、左右两侧可替换标签槽和防滚底座。
- 材质：雾面浅色外壳、半透明树脂窗口、软触深灰握柄；颜料颜色运行时控制。

## 3. 生产与交互预留

底面中心为原点，观察窗朝正面。密封盖、握柄、窗口和罐体可分件；开盖、倾倒、采集和液体动画不在本阶段定义。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以纵向透明观察窗所在面为正面；窗口位于壳体中轴，采用细长八边形轮廓、深灰内框和中性灰蓝静止液位。
- 顶部深灰螺纹密封盖居中，外圈为低饱和青绿锁环；一体化提手横跨左右，位于盖体上方并保持足够握持净空。
- 暖白罐体两侧保持轻微切角，底部深灰防滚底座形成多段短脚并完整接地。
- 正面不出现标签文字、元素颜色或额外接口。

### 背面 Rear

- 背面不设置观察窗或标签槽；中央保持一块连续暖白壳面，只保留轴测终稿已有的浅层结构分缝。
- 提手、密封盖、青绿锁环与防滚底座保持和正面完全相同的中心位置与宽度。
- 背面不得增加阀门、管线、液位窗或说明文字；壳体以连续大面为主。

### 左侧 Left

- 左侧中央设置一块浅凹矩形可替换标签槽，尺寸与背面标签槽一致；不设置透明观察窗。
- 侧视时提手表现为前后两根深灰支座与上方握把厚度，握把不得与密封盖穿插。
- 顶部锁环、罐体水平拼缝和底部防滚底座保持连续；前后各见一个稳定短脚。
- 左侧不增加开关、喷嘴或流体痕迹。

### 三视图共同约束

- 仅正面有观察窗；左右两侧各有 1 个空白标签槽，背面为连续壳面。密封盖 1 个、提手 1 个，不改变数量。
- 窗口液位使用中性灰蓝且保持静止，不绑定任何元素色。

## 5. 检查清单

- [ ] 单手可搬的尺寸与握持逻辑成立。
- [ ] 不与补给箱或普通水壶混淆。
- [ ] 半透明窗口与外壳材质区分明确。
- [ ] 未制作流动、喷溅或开盖状态。

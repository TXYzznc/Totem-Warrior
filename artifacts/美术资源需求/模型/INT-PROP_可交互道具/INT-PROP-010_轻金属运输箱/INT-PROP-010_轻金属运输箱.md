# INT-PROP-010｜轻金属运输箱

## 1. 资产定位

中等耐久的工业运输容器。默认尺寸 **1.10×0.75×0.65m**；需通过薄板折弯和压筋语言区别于木箱以及高价值装甲箱。

## 2. 默认造型与材质

- 状态：完整、未受击，无凹陷、火花或烧蚀。
- 轮廓：低矮横向箱体，大面积压筋与折弯边构成主要细节。
- 结构：主壳、压筋面、搬运握位和简化锁止件。
- 材质：喷砂浅金属、深灰蓝缓冲件、少量可替换功能色条。

## 3. 生产与交互预留

底面中心为原点，锁止件侧为正面。外壳面、锁件和缓冲件分区明确；凹陷变形、碎片、破坏阈值及内容物均后续定义。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以单个锁止件所在长边为正面；锁止件严格居中，深灰主体配一条低饱和青绿上沿。
- 薄板箱盖与箱体之间保持一条窄水平缝；正面大面只使用一圈浅压边和少量可见铆点，不增加装甲框。
- 顶盖保留两条前后走向的细长压筋和一圈浅矩形压边，整体平整，不设置顶部提手。
- 深灰蓝底部缓冲条横向连续，前方左右各有一个包角缓冲块。

### 背面 Rear

- 背面不出现锁止件；箱盖后缘设置两个低矮扁平铰链，分别位于宽度约 1/3 与 2/3 处。
- 背面主体保持一块轻薄金属大面，仅有与正面一致的浅压边和少量铆点。
- 顶盖两条压筋、水平开缝、底部缓冲条和左右包角与正面严格对齐。
- 不增加风扇、接口、标签或第三个铰链。

### 左侧 Left

- 左侧上半部中央设置一个横向矩形搬运握位，采用深灰凹腔、青绿上沿和薄金属折边外框；与轴测图可见右侧握位镜像一致。
- 水平盖缝从前到后贯通，前后折角保持薄板圆角；底部前后各有一个深灰缓冲包角。
- 侧面只保留一圈浅压边，不增加锁扣、铰链正面或厚重护甲。

### 三视图共同约束

- 正面锁止件 1 个、背面铰链 2 个、左右搬运握位各 1 个；顶盖压筋固定为 2 条。
- 所有边缘必须保持薄板折弯感，不得增厚成 INT-PROP-003 的装甲保护框。

- [ ] 与 INT-PROP-003 的厚重护甲语言有明显差异。
- [ ] 未提前制作受击变形。

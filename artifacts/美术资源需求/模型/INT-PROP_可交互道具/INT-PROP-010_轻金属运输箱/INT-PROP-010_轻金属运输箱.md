# INT-PROP-010｜轻金属运输箱

## 1. 资产定位

中等耐久的工业运输容器。默认尺寸 **1.10×0.75×0.65m**；需通过薄板折弯和压筋语言区别于木箱以及高价值装甲箱。

## 2. 默认造型与材质

- 状态：完整、未受击，无凹陷、火花或烧蚀。
- 轮廓：低矮横向箱体，大面积压筋与折弯边构成主要细节。
- 结构：主壳、压筋面、搬运握位和简化锁止件。
- 材质：喷砂浅金属、深灰蓝缓冲件、少量可替换功能色条。

## 3. 生产与交互预留

底面中心为原点，锁止件侧为正面。外壳面、锁件和缓冲件分区明确；凹陷变形、碎片、破坏阈值及内容物均后续定义。

## 4. 多视图要求

六视图必须一致表达板厚、折边、压筋走向、握位和底部缓冲结构；不得因视角改变压筋数量。

## 5. 检查清单

- [ ] 看起来是轻金属运输箱而非保险柜。
- [ ] 压筋与折弯符合薄板结构逻辑。
- [ ] 与 INT-PROP-003 的厚重护甲语言有明显差异。
- [ ] 未提前制作受击变形。

# INT-PROP-005｜标准颜料封存罐

## 1. 资产定位

常见颜料资源容器，是颜料罐系列的标准比例基准。默认尺寸 **0.52×0.52×0.80m**，适合单独放置或在资源点成组陈列。

## 2. 默认造型与材质

- 状态：密封、完整、压力稳定，未交互。
- 轮廓：稳定竖向圆筒，顶部和底部均有宽密封环。
- 结构：观察窗、压力接口、封存锁环，接口数量保持克制。
- 材质：浅灰蓝主壳、低饱和青绿功能环、半透明内容窗口。

## 3. 生产与交互预留

底面中心为原点，观察窗为正面。锁环、窗口、接口与主体分区明确；颜色、元素标签、液位和压力反馈由后续材质或特效控制。

## 4. 多视图要求

六视图需保持圆筒比例、锁环厚度、接口方位和窗口尺寸完全一致；顶视图必须能读出封盖与接口布局。

## 5. 检查清单

- [ ] 与便携罐、大型储罐形成清楚的尺寸层级。
- [ ] 接口有用途且没有无意义科技细节。
- [ ] 内容颜色未固定烘焙。
- [ ] 未提前制作气泡、泄漏或压力动画。

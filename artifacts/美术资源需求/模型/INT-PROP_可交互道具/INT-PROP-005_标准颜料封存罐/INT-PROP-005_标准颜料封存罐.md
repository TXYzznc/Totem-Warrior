# INT-PROP-005｜标准颜料封存罐

## 1. 资产定位

常见颜料资源容器，是颜料罐系列的标准比例基准。默认尺寸 **0.52×0.52×0.80m**，适合单独放置或在资源点成组陈列。

## 2. 默认造型与材质

- 状态：密封、完整、压力稳定，未交互。
- 轮廓：稳定竖向圆筒，顶部和底部均有宽密封环。
- 结构：观察窗、压力接口、封存锁环，接口数量保持克制。
- 材质：浅灰蓝主壳、低饱和青绿功能环、半透明内容窗口。

## 3. 生产与交互预留

底面中心为原点，观察窗为正面。锁环、窗口、接口与主体分区明确；颜色、元素标签、液位和压力反馈由后续材质或特效控制。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以纵向观察窗所在面为正面；窗口严格居中，采用窄长八边形外框、深灰内框和中性灰蓝静止液位。
- 顶部宽青绿锁环与底部青绿密封环均水平连续，厚度保持轴测终稿比例；顶部中央深灰封盖可见但不发光。
- 上锁环正中保留一个低矮矩形锁止块，下密封环正中保留一个对应的短矩形结构块，二者与观察窗同轴。
- 深灰圆形底座带均匀分段护脚，正面不增加文字、压力表或第二窗口。

### 背面 Rear

- 背面不设置观察窗；圆筒主体保持连续浅灰蓝大面，仅保留与正面同宽的浅层壳体分区。
- 唯一的压力接口位于背面上半部中心、紧邻上锁环下方，表现为小型深灰封帽与短基座，不带表盘、软管或发光。
- 顶部封盖、上下密封环、底座和分段护脚与正面完全同高同轴。

### 左侧 Left

- 左侧不设置观察窗和压力接口，只显示圆筒曲面上的浅层竖向分区面。
- 上下青绿密封环连续绕行，顶部封盖保持中心位置；深灰底座前后各见一段落地护脚。
- 侧面不得添加把手、标签、阀门或第二接口。

### 三视图共同约束

- 观察窗仅 1 个且位于正面；压力接口仅 1 个且位于背面；锁环和底环均保持完整闭合。
- 圆筒直径、高度、窗口宽度和环体厚度在三视图中不得变化。

## 5. 检查清单

- [ ] 与便携罐、大型储罐形成清楚的尺寸层级。
- [ ] 接口有用途且没有无意义科技细节。
- [ ] 内容颜色未固定烘焙。
- [ ] 未提前制作气泡、泄漏或压力动画。

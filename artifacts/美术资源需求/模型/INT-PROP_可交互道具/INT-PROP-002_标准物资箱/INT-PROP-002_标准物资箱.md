# INT-PROP-002｜标准物资箱

## 1. 资产定位

地图中最常见的常规搜刮容器，也是物资箱系列的比例与造型基准。默认尺寸 **1.00×0.65×0.65m**，能够独立摆放或成组堆放。

## 2. 默认造型与材质

- 状态：关闭、完整、未交互，活动件全部收拢。
- 轮廓：横向长方体，略高箱盖和双侧锁扣形成稳定节奏。
- 结构：主盖、双锁扣、两侧把手、底部脚垫；避免写实军箱的密集扣件。
- 材质：半哑光浅色树脂与轻金属框，预留可替换色条或贴花槽。

## 3. 生产与交互预留

底面中心为原点，双锁扣侧为正面。盖、锁扣、箱体可合理分件；堆放面不得被把手或附件破坏。开启、掉落展示、稀有度和交互提示留待 Unity 导入前确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以双锁扣所在长边为正面；两个锁扣沿宽度对称布置在约 1/3 与 2/3 位置，锁扣尺寸、青绿上沿和深灰主体完全一致。
- 正面箱盖较薄且略高于箱体，水平盖缝贯穿整面；箱体中央是一块宽大的浅凹矩形面板，不添加文字。
- 顶盖为平整可堆叠大面，仅保留轴测图中的浅层周边折线和角部青绿嵌条，不设置顶部提手。
- 深灰蓝底座横向连续，左右角脚和中部短支撑均稳定接地。

### 背面 Rear

- 背面不出现锁扣和搬运把手；设置两个宽度一致的低矮铰链，位置分别对应正面两个锁扣的横向节奏。
- 水平盖缝、四角暖白护壳、深灰底座与正面保持同高；背部主体为一块宽浅凹面板。
- 顶盖保持完整堆叠平面，背面不得增加风扇、插口、标签板或第三个铰链。

### 左侧 Left

- 左侧上半部居中设置一个横向矩形搬运凹槽，采用深灰内腔、青绿上沿和暖白外框；与轴测图右侧把手镜像一致。
- 水平盖缝从前到后连续，侧面不出现锁扣；前后角柱均由暖白壳体包覆并落在深灰角脚上。
- 侧面主体保持单块浅凹面板，底座前后各有一个短落地脚，不破坏顶面堆叠净空。

### 三视图共同约束

- 正面锁扣 2 个、背面铰链 2 个、左右搬运凹槽各 1 个；顶面禁止提手和凸起附件。
- 必须维持比 INT-PROP-001 更长、更宽的横向比例，不得缩成小型手提箱。

## 5. 检查清单

- [ ] 作为物资箱家族基准，轮廓中性且高频耐看。
- [ ] 顶面支持合理堆叠，接地稳定。
- [ ] 屏幕、文字与稀有度均为运行时内容。
- [ ] 未提前制作开启状态或内部物资。

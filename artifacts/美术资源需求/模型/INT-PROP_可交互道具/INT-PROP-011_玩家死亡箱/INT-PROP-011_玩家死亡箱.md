# INT-PROP-011｜玩家死亡箱

## 1. 资产定位

玩家死亡后生成的掉落容器，必须与世界固定物资箱明显区分。默认尺寸 **1.15×0.75×0.55m**，基础几何全玩家共用。

## 2. 默认造型与材质

- 状态：关闭、未领取，无玩家专属信息和领取反馈。
- 轮廓：低矮胶囊形/圆角棺盒形，方向明确，顶部有大面积身份槽。
- 结构：统一基础壳、身份槽、侧面领取接口、底部落地缓冲环。
- 材质：中性浅灰主体；玩家颜色、阵营、图案和姓名全部运行时注入。

## 3. 生产与交互预留

底面中心为原点，领取接口侧为正面。盖板、身份槽、接口和主体可分件；开启、清空、归属保护、发光和 UI 锚点在 Unity 导入前确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以领取接口所在短边为正面；接口严格居中，采用深灰圆角矩形翻盖/读取座和一条中性青绿上沿，默认关闭。
- 顶部身份信息槽是一块大面积空白浅色嵌板，占据顶盖主要区域；槽内不得出现姓名、头像、阵营、纹身图案或编号。
- 主体轮廓低矮、圆角、近胶囊形，顶盖与下壳之间的水平分缝在左右圆角处连续。
- 深灰底部缓冲环环绕箱体，正面左右包角和中部底边稳定接地。

### 背面 Rear

- 背面不出现领取接口、显示槽或玩家信息；圆角壳体保持连续浅色大面。
- 顶盖后缘设置两个隐藏式低矮铰链座，分别位于背面约 1/3 与 2/3 处，外观克制且不突出胶囊轮廓。
- 顶部身份槽仍可见其后缘，但内容保持空白；底部缓冲环与正面同高连续。
- 背面不得增加把手、散热孔、铭牌或第二领取接口。

### 左侧 Left

- 左侧为连续圆角胶囊壳面，只显示顶盖/下壳分缝和环绕底部的深灰缓冲环。
- 顶部身份槽从侧面表现为低矮嵌入式面板，不高于顶盖外轮廓；正面领取接口只在画面右缘表现其厚度。
- 左侧不设置搬运把手、锁扣或信息屏，前后包角保持对称接地。

### 三视图共同约束

- 领取接口仅 1 个并固定在正面；背面铰链 2 个；身份槽仅位于顶面且始终空白。
- 保持中性浅灰、深灰缓冲环和少量青绿占位条，不生成任何具体玩家身份信息。

## 5. 检查清单

- [ ] 一眼区别于世界物资箱和棺材道具。
- [ ] 玩家身份变化不增加几何变体。
- [ ] 落地姿态稳定，方向清晰。
- [ ] 未提前制作开启、清空或领取状态。

# INT-PROP-006｜大型颜料储罐

## 1. 资产定位

固定式大容量颜料储存设施，可作为资源点或设施组成部分。默认尺寸 **直径1.80m、高2.40m**；必须在多个方向保持识别度，不能退化为普通油桶。

## 2. 默认造型与材质

- 状态：固定安装、密封、未交互，管线接口封闭。
- 轮廓：高大圆筒置于宽底座，纵向观察窗贯穿主要视觉区。
- 结构：底座、主罐、顶部维护盖、两处大规格接口，并预留检修梯/踏点连接位。
- 材质：浅色复合外壳、喷砂金属骨架、半透明观察窗。

## 3. 生产与交互预留

原点位于底座中心，观察窗主面为正面。主罐、骨架、封盖、接口和维护部件需可独立管理；管线、检修梯是否作为独立模块在建模前确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 以主纵向观察窗和两处下部管线接口所在面为正面；观察窗位于上部圆筒中轴，窄长、竖直并使用中性灰绿静止液位。
- 两个封闭接口位于下部锥台区域：观察者左侧为大口径圆形封盖，右侧为较小圆形封盖；二者高度错开但都不接软管。
- 喷砂金属骨架由左右两根主立柱、顶部与中部环梁以及对称斜撑组成；立柱脚通过螺栓座落在宽深灰底台上。
- 顶部中央维护盖保持封闭，左右各有一个低矮弧形吊装/维护握位。

### 背面 Rear

- 背面不设置观察窗和管线接口；中央保留完整浅色罐壁。
- 后部设置两条平行竖向维护安装轨，轨道上均匀布置三组相互对齐的空白踏点安装座；只表现安装预留，不生成完整梯子。
- 外骨架立柱、上下环梁与斜撑在背面形成闭合受力关系，底部所有柱脚均与底台接触。
- 顶部维护盖和两个弧形握位位置不变，背面不得添加舱门、表盘或电箱。

### 左侧 Left

- 左侧圆筒中部设置一条与正面同尺寸的纵向观察窗，使设施从侧向也能识别为颜料储罐；液位高度与正面一致。
- 两根侧向骨架立柱之间采用单组 X 形斜撑，斜撑不得遮挡观察窗中心区域。
- 左侧不出现正面的两个管线接口；下部锥台、柱脚和八边形底台保持连续接地。
- 顶部维护盖居中，前后弧形握位在侧视中以对称短轮廓出现。

### 三视图共同约束

- 观察窗固定为正面、左侧、右侧各 1 条，背面无窗口；两处管线接口都固定在正面下部。
- 背面仅有维护安装轨和踏点安装座，不生成梯子、软管、阀门组或外接设备。
- 罐体高度 2.40m、直径 1.80m，骨架柱数量、接口直径差和底台占地不得随视图变化。

## 5. 检查清单

- [ ] 多方向识别成立，背面不是空白未设计面。
- [ ] 底座与罐体受力关系合理。
- [ ] 外接接口均有封盖且不表现流动。
- [ ] 维护净空和角色可达性可解释。

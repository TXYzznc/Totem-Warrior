# INT-PROP-003｜高价值加固箱

## 1. 资产定位

用于危险区域奖励、关键资源和高价值战利品。默认尺寸 **1.25×0.80×0.78m**；价值感主要来自厚重结构和安全机构，而不是满铺金色或持续发光。

## 2. 默认造型与材质

- 状态：完全闭合，安全锁待机，未解锁、未领取。
- 轮廓：宽厚、低重心，外保护框和四角护甲形成强识别。
- 结构：中央安全锁、双层盖缝、加厚底座和保护角。
- 材质：暖白主壳、喷砂金属护框、少量珊瑚橙安全件；中央预留稀有度显示区。

## 3. 生产与交互预留

底面中心为原点，中央锁侧为正面。保护框、主盖、中央锁和主体按逻辑分件；解锁机构、开盖动画、光效和战利品展示后续确认。

## 4. 正面、背面、左侧外观定义（已确认）

### 正面 Front

- 中央安全锁组件严格居中，由上方横向黑色空白显示槽、外层喷砂金属框和下方深灰机械锁体组成；珊瑚橙只用于小型安全拨件。
- 正面左右各保留一块暖白浅凹面板；外侧四角护甲和纵向金属框从顶盖连续包覆至深灰底座。
- 双层盖缝横向贯穿正面，内层仅以一条细窄珊瑚橙密封线表现，不发光。
- 加厚底座保持低重心，左右前角各有宽护脚，中部底边不得悬空。

### 背面 Rear

- 背面不出现中央安全锁或显示槽；左右各为一块暖白浅凹面板，中间由喷砂金属纵向加强框分隔。
- 顶盖后缘设置两个宽厚铰链组件，分别位于背面约 1/3 与 2/3 处，并被外保护框包覆。
- 四角护甲、双层盖缝、橙色密封线和加厚底座必须与正面同高连续绕行。
- 不增加散热栅、供电口、文字或额外安全锁。

### 左侧 Left

- 左侧中央设置一个横向深灰搬运握位，外圈为厚金属矩形保护框，握位下沿带单条珊瑚橙安全件；结构与轴测图可见右侧握位镜像一致。
- 前后两根纵向护框完整可见，并与顶盖护框和底座形成闭合受力框架。
- 双层盖缝与橙色密封线从前至后贯通；侧面不出现中央锁或显示槽。
- 暖白侧板保持大块面，仅允许轴测终稿已有的浅层分区线。

### 三视图共同约束

- 正面中央锁 1 套、背面铰链 2 套、左右侧握位各 1 个、四角护甲共 4 组。
- 价值感只来自厚框、护角和锁体层级，不增加金色、强光、宝石或武器化细节。

## 5. 检查清单

- [ ] 中远距离明显比标准物资箱更稳重、更稀有。
- [ ] 不依赖文字、金色满铺或强光识别价值。
- [ ] 安全机构结构合理且未表现已解锁。
- [ ] 运行时显示区与实体材质分区清楚。

# INT-PROP-003｜高价值加固箱

## 1. 资产定位

用于危险区域奖励、关键资源和高价值战利品。默认尺寸 **1.25×0.80×0.78m**；价值感主要来自厚重结构和安全机构，而不是满铺金色或持续发光。

## 2. 默认造型与材质

- 状态：完全闭合，安全锁待机，未解锁、未领取。
- 轮廓：宽厚、低重心，外保护框和四角护甲形成强识别。
- 结构：中央安全锁、双层盖缝、加厚底座和保护角。
- 材质：暖白主壳、喷砂金属护框、少量珊瑚橙安全件；中央预留稀有度显示区。

## 3. 生产与交互预留

底面中心为原点，中央锁侧为正面。保护框、主盖、中央锁和主体按逻辑分件；解锁机构、开盖动画、光效和战利品展示后续确认。

## 4. 多视图要求

六视图重点展示保护框包覆关系、双层盖缝、中央锁深度和底座接地，不得在不同视图改变护角或锁件数量。

## 5. 检查清单

- [ ] 中远距离明显比标准物资箱更稳重、更稀有。
- [ ] 不依赖文字、金色满铺或强光识别价值。
- [ ] 安全机构结构合理且未表现已解锁。
- [ ] 运行时显示区与实体材质分区清楚。

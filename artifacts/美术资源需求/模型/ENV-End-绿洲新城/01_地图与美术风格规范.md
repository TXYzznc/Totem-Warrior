# 绿洲新城｜地图与美术风格规范

> 状态：已确认的风格与布局原则。最终俯视布局须在建筑/装饰编号锁定后另行绘制。

## 1. 城市一句话定义

一座在热砂绿洲上持续运作的未来新城：人们在明亮石灰岩拱廊、遮阳织物、浅水庭和风塔之间生活，以低饱和青绿的活性颜料接口维系日常服务。

它不是荒废遗迹，也不是全金属赛博城。城市总体应明亮、可亲近、有人居住；未来感集中在能源接口、颜料容器、风水循环和少量导向光中。

## 2. 风格构成与比例

| 层级 | 视觉语言 | 使用边界 |
|---|---|---|
| 基底 60% | 温暖浅砂岩、石灰泥墙、尖拱/浅拱、低矮台基、围院 | 大体块、道路、常规住宅与公共建筑。 |
| 气候构件 25% | 风塔、深窗洞、遮阳帆、拱廊、导水槽、水庭、绿植 | 解决日照、通风、行走与停留，并形成绿洲识别。 |
| 未来设施 10% | 青绿色能源端口、细金属导管、纹样环、颜料封存、低亮指示灯 | 仅在功能节点出现，不覆盖完整外墙。 |
| 生活叙事 5% | 织物、陶罐、货物、座椅、标识、晾晒与小型摊位 | 服务于人的尺度与区域功能，不堵塞通路。 |

### 推荐色彩

- 主墙：暖白、浅砂、低对比石灰色。
- 装饰砖/釉面：低饱和青绿、蓝绿。
- 金属：暗铜、烟灰金属；禁止大面积镜面铬。
- 织物：褐红、赭金、深靛小面积点缀。
- 活性颜料光：低强度青绿；只用于交互、能量和状态提示。

## 3. 街区与道路规则

1. **反规整**：主路不能为笔直十字轴线；至少使用折线、弧形、错位门洞、斜切广场或高差之一。
2. **围院优先**：建筑群以半围院、内庭、连廊、桥接平台组织，避免独立盒子等距排布。
3. **三层路网**：
   - 主游逛路：可容纳双向角色和集散，串联入口、纹身店、商区、Boss 区。
   - 次级巷道：通向住宅、工坊和侧门，允许转折、遮阳和视觉遮挡。
   - 微路径：楼梯、短桥、屋顶连廊、庭院穿行；必须作为可选探索路径而非唯一主线。
4. **每段有用途**：道路边至少承担“店前停留、导水、遮阳、绿化、货运、看景”之一，不能只是一条空通道。
5. **视线节奏**：每 35–60m 主路径至少设置一个远景锚点、门洞框景、庭院开口或地标；不得长距离无遮挡直线到底。

## 5. 后续俯视图的硬性要求

1. 先使用 [02_建筑目录与功能规格.md](02_建筑目录与功能规格.md) 和 [03_场景装饰目录与摆放规格.md](03_场景装饰目录与摆放规格.md) 中的编号。
2. 图中每一座可进入建筑标注实例编号，例如 `BF-17-03`；装饰以类型编号加群组编号标注，例如 `DE-06-G04`。
3. 俯视图必须标出主路、次巷、台阶、桥、可进入门、屋顶/楼梯连接、水体和事件候选区。
4. 三选一事件只画“候选触发空间”，不得把它绑定为某一座固定建筑的专属功能。
5. 若采用四象限渲染：先完成一张统一比例、统一编号、可拼接的 4K 线稿；四张渲染图共享同一原点、边界和颜色规范，再拼接。

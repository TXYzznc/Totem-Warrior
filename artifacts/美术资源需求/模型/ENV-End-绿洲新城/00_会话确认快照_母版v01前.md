# 绿洲新城｜会话确认快照（截至 BF-01 外观身份母版 v01 生成前）

> 归档目的：把本轮会话中已达成一致、且发生在开始生成 `BF-01「晖纹纹身庭」外观身份母版 v01` **之前**的内容固化为可执行基线。  
> 起点：提出“设计完整地图、不是 60 秒地图，并让建筑与街道具有异域/未来风格”的需求。  
> 截点：开始生成 `BF-01「晖纹纹身庭」外观身份母版 v01` 之前。  
> 归档日期：2026-07-28。

## 1. 已确认的核心目标

| 项目 | 已确认结论 |
|---|---|
| 地图范围 | 制作可完整游玩的城市地图，不是 60 秒关卡。 |
| 主风格 | 采用方案 1：**绿洲新城**。以异域绿洲城市为基础，混入克制的未来生活设施和活性颜料科技。 |
| 建筑与街道 | 建筑要有鲜明身份；街区不能是规整棋盘格，应形成曲折、错位、围院、桥接和高低变化的风格化城市肌理。 |
| 建筑种类 | 至少 20 种建筑类型；本归档以 24 类作为生产目录。 |
| 装饰种类 | 至少 30 种场景装饰；本归档以 32 类作为生产目录。 |
| 可进入建筑 | 至少 60 座真实可进入、可探索的建筑；本归档的最低配额为 67 座。 |
| 地图设计顺序 | 必须先确定全部建筑类型与装饰编号，再绘制带编号的俯视地图；不能先画地图再倒推功能。 |
| 图纸策略 | 大地图可先做 4K 俯视线稿；若一次生成不稳定，可按四象限分别渲染，再拼成完整俯视设计图。 |

## 2. 已确认的玩法边界

| 玩法项 | 约束 |
|---|---|
| 纹身师 | 使用固定、唯一的建筑；全图仅 1 座纹身店。 |
| 商人 | 属于随机出现的功能；本地图按 4 个商人商店配置。商店具有功能识别，但地标性弱于纹身店。 |
| 三选一事件 | 与建筑无绑定，是独立事件；可在任何满足触发条件的位置发生。 |
| Boss | 必须有对应的特殊建筑；Boss 通常位于该建筑内部。 |
| 可探索性 | “可交互建筑”指玩家可实际进入内部探索，不得用仅有外立面的假建筑计数。 |

## 3. 已确认的生产约定

1. 所有相关设计文档、建筑设计和设计图统一放在本目录。
2. 每栋建筑必须分别拥有：
   - 带尺寸的**详细设计案**：开发/Blender/Unity 的尺寸与位置真源；
   - **设计图需求提示词**：用于生成多视角、含室内结构的效果参考图。
3. 效果图不能作为精确施工图。开发时以详细设计案中的尺寸、物品位置、门窗、通道和验收条件为准，以效果图确认视觉效果。
4. 文档应能被后续 AI/Blender 工作流直接理解：每类资产必须写清使用位置、摆放规则、禁用条件和验收条件。

## 4. 本快照不包含的内容

- `BF-01` 外观身份母版 v01 及其后续各轮效果图修订。
- 后续为 BF-01 制作的 Unity ProBuilder 白模、门洞调整、渲染校验与 Blender 布局 JSON 优化。
- 尚未进入“全部编号完成后的最终俯视地图绘制”阶段的具体地块坐标和最终渲染图。

上述内容不应反向修改本历史快照；它们应在对应建筑目录或后续地图布局文档中独立版本化。

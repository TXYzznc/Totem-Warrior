## 真源优先级

```text
建筑详细设计案 + 楼层布局 JSON
  > 地图布局图 / 白模
  > 多视角效果图
  > 本目录的总览规范
```

效果图只用于风格、轮廓和氛围参考；尺寸、物品位置、碰撞、通行与交互净空以“建筑详细设计案”和对应 JSON 为准。

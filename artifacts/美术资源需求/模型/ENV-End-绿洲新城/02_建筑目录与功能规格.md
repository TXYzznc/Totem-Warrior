# 绿洲新城｜建筑目录与功能规格

> 编号规则：`BF` = Building Function。每个实例采用 `BF-xx-yy`；例如第二座庭院住宅为 `BF-17-02`。  
> 本表的“最低实例数”均为可进入、可探索的室内实例，不将纯立面、封闭背景壳体计入。

## 2. 功能绑定规则

| 项目 | 规则 |
|---|---|
| 固定纹身师 | 只能绑定 `BF-01`，全图仅一座。 |
| 随机商人 | 本地图只在 `BF-02`～`BF-05` 的 4 座商店中选择/生成；不在 `BF-01` 或 Boss 建筑中出现。 |
| 三选一事件 | 不绑定任何 `BF` 编号；在广场、巷口、桥头、屋顶平台、庭院等候选空间触发。 |
| Boss | 绑定 `BF-06`；Boss 建筑必须可完整进入，不能只做封闭立面或场景背景。 |
| 可进入计数 | 每实例须有可到达入口、室内可走区域、至少一个功能/叙事点，以及可返回室外的路径。 |

## 3. 各类建筑的共同规格

1. 每座建筑都要有“街道身份”：入口、门牌/纹样、遮阳、窗/导风口或材料变化中至少两项。
2. 常规建筑以首层可读性优先；进入门不得被外摆、绿植、货物或装饰遮挡。
3. 每个可进入实例至少保留一条连续主通道；住宅类通常不少于 1.2m，公共/商店类不少于 1.8m。
4. `BF-01` 和 `BF-06` 是强地标；`BF-02`～`BF-05` 必须较克制，避免重复高塔、巨型悬挂标志或同等级门洞。
5. 所有建筑的尺寸、门窗、楼梯、家具锚点和交互净空必须在该建筑自己的详细设计案中落为数值；本目录只定义类型级规范。

## 4. 单栋详细设计案的最低内容

- 建筑身份、功能、实例数量和相邻街道/分区。
- 总包围盒、每层长×宽、每层面积、层高、净高、墙体和楼板厚度。
- 房间编号、房间尺寸、门窗编号/尺寸/坐标、楼梯与屋顶规则。
- 玩家入口、交互锚点、碰撞、主通道和逃生/返回路径。
- 固定装饰编号、坐标、旋转、变体和不可侵占区域。
- Blender/Unity 验收项及对应的设计图提示词文件名。

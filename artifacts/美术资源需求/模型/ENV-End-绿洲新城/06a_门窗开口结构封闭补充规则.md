# 彩色白模补充规则：门窗开口的结构封闭

适用范围：BF-03 至 BF-24 的 Unity ProBuilder 白模制作与验收。本文件补充《06_彩色白模制作合同》。

## 强制规则

- 门、窗、通风口在白模中都是**开口**，不是用 `CB_Entrance` 色块替代整段墙体；彩色门窗块只表达洞口净空或洞口位置。
- 每个开口必须由同色 `CB_Structure` 墙段完整围合：开口两侧有墙垛；门洞上方有同厚度、同高度连续的过梁/上墙段；窗洞同时有窗下墙段和上墙段。
- 上墙段、过梁与附近墙体使用同一份 `CB_Structure` 材质（中性灰 `#A9B0B7`），厚度与所在墙面一致；不得留下凹槽、悬空缝、露天缺口或可看穿的外壳。
- 仅当 P1 详细设计案或布局 JSON 明确写为“通高开口”时，才可没有上墙段。

## 截图验收

在正、背、左、右四个立面逐一确认：

1. 所有门窗洞口上方均有连续结构墙体；
2. 窗洞上下均存在结构墙段；
3. 彩色门窗块不会被误读成结构墙；
4. 过梁与邻墙颜色一致，且不改变墙体外壳的连续性。

# BF-23 城门巡查所｜白模制作规范

> P2 交接，遵守 `../../06_彩色白模制作合同.md`；不制作城门本体或世界落位。

## 颜色、命名与层级

`CB_Structure #A9B0B7` 为建筑壳、楼板、栏杆；`CB_Walkable #D4B56A` 为前室、记录室、侧通道与观察廊；`CB_Function #4F93D1` 为问询台/记录台；`CB_Vertical #9569C9` 为 ST01；`CB_Entrance #5FBF76` 为 D01-D04；`CB_Interaction #42C6C6` 为两锚点无碰撞；`CB_Restricted #D95C5C` 为城门主路外的巡查限制边。

根为 `BLD_BF23_ROOT`，建立九个 Collection：`GEO_Structure/GEO_Walkable/GEO_Function/GEO_Vertical/GEO_Entrances/GEO_InteractionPreview/GEO_RestrictedPreview/COL_Collision/COL_Anchors`；示例 `CB_Vertical_ST_F1_F2_01`、`CB_Walkable_F2_ObservationWalk`、`CB_Entrance_D02`。对象局部 Scale=1、Rotation=0。

## BF 特化验收

- 玩家通过 `D01→问询→记录/侧通道→ST01→观察廊→ST01→D02/D01`；外侧城门人行线只预留净空、不能被白模队列/桌台占据。
- ST01 20 级×0.1725m=3.45m，踏面 0.30m、净宽 1.8m、平台 1.8×1.8m、头净高 2.4m、栏杆 1.1m；观察廊全边有可碰撞栏杆。
- 角色代理核验四门、两窗、一梯、两锚点；城墙垛、旗杆、攀爬梯严禁作为紫色路线。

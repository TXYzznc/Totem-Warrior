# BF-11 导水维护所｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-11`；实例配额：1；建议分区：城市循环设施带、临街导水槽或水庭的服务侧，不作为广场地标。

## 1. 建筑身份与层级限制

这是服务城市循环水网的可进入维护节点：玩家能看见导管、阀门、检修走道与水流去向，但不会进入危险或不可读的设备迷宫。

- 体量低于公共地标；以低矮设备屋、可读的导水墙和一处维护平台识别，不使用塔楼、巨型门洞或大面积发光。
- 青绿只用于功能状态、阀门标识或 `DE-14` 能源柱，主体保持暖白石材、金属包边和受控的水体色彩。
- 导管、线缆与阀门必须有明确起止和服务对象；不得悬空穿过玩家主通道。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 城市叙事 | 让玩家读懂“水从街侧导水槽进入、经阀组分配、再流向城市”的循环关系。 |
| 可交互点 | 预留一个阀组/检修读数交互锚点；其前方保持可站立与回身的净空，不能被设备或货物挤占。 |
| 探索 | 不只是外墙加检修门：玩家可进入并绕行至观察水流的维护平台。 |
| 事件边界 | 不绑定三选一事件、随机商人或 Boss；`DE-32` 如需出现，只能作为维护说明/独立候选点。 |

## 3. 最小可探索室内与竖向结构

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 街侧前室 | 进入、读取水网标识 | 主门进入后可一眼看到阀组与前方维护走向；入口不能被 `DE-20`、`DE-22` 封堵。 |
| F1-02 | 阀组检修间 | 交互、阀门与导管叙事 | 使用 `DE-15`、`DE-16`、`DE-29`；设备沿墙或吊顶组织，中央保留可走通路。 |
| F1-03 | 导水观察廊 | 观察明渠/沉槽、水流方向 | 与室内连通，水面不做实体碰撞；临水高差处使用连续 `DE-27` 栏杆。 |
| F1-04 | 上部维护平台 | 俯看阀组、形成短环路 | 仅可通过正式楼梯抵达；不得把维护梯、攀爬杆或装饰梯计为探索路线。 |

上部平台若在 P1 保留，必须通过室内或半室外的可走楼梯连接：踏步、平台、栏杆与最小头部净空均按总规范闭合，并有原路返回至 F1-01 或第二处可走出口的路线。平台边缘设连续 1.1m 防护栏；任何导管不得压低玩家头部净空。

## 4. 玩家流线

```text
临水服务街 / 导水槽侧步道
  → 主入口与前室（F1-01）
  → 阀组检修间交互（F1-02）
  → 导水观察廊（F1-03）
  → 正式楼梯 → 上部维护平台（F1-04）
  → 原楼梯返回检修间 / 连通观察廊
  → 主入口或临水侧次出口
```

进入、查看/交互、登台观察和返回四段均须可连续完成；关闭的设备舱门、装饰性检修梯与水槽内部均不能承担必经返回路线。

## 5. 外部接街、维护与 DE 约束

- 接城市循环设施带的次级服务街或临水步道，主入口面向人行侧；维护门可转向服务侧，不设最终城市坐标。
- `DE-04` 导水槽转角避开门前；如使用 `DE-28` 跨槽板，净宽不得低于 1.2m，且不得截断主路。
- 可使用 `DE-14/15/16/17/27/29/30/31`，其中 `DE-31` 只放维护角；任何设备、导管、碎石和罐体不得封堵入口、主路或楼梯落点。

## 6. P0 验收条件

- [ ] 明确为 `BF-11` 导水维护所，能读出导水、分配、检修关系，而非普通仓房或纯外观设备墙。
- [ ] 至少有前室、阀组检修间、可达观察廊三类真实可走空间。
- [ ] 若存在上部平台，只有正式可走楼梯可达，栏杆、平台、头部净空及返回路径均已列入 P1 约束。
- [ ] 水体、导管、设备与装饰均不侵占主通道、交互净空、门洞或楼梯落点。
- [ ] 不绑定随机商人、三选一事件或 Boss；未写入最终城市世界坐标。

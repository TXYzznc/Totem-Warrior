# BF-09 档案馆｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、档案内容、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-09`；实例配额：1 座可进入实例；建议分区：水庭公共区（邻近安静公共步行面）。

## 1. 身份与层级限制

档案馆承担城市叙事探索：以安静主厅、侧阅览室与档案后室组成可阅读的内部序列。它的辨识应来自深窗、安静门廊、受控采光和内部秩序，而不是高塔、强发光或纪念性巨门。

- 不是公告/任务大厅（`BF-10`）、商店、住宅或封闭收藏背景；档案阅读是其核心空间身份。
- 保持公共建筑的可读入口与连续主通道，同时避免与 BF-01/BF-06 竞争地标级体量与视觉语汇。
- 本 P0 以单层连续探索组织档案主厅、侧阅览与后室；不得以高书架、夹层立面或不可到达阁楼暗示假二层。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 叙事探索 | 提供可阅读的档案、地图、记录或物件展示锚点；不在 P0 撰写具体剧情文本。 |
| 主厅导向 | 玩家进门后能识别主阅览方向与侧阅览入口，不靠 HUD 指路。 |
| 侧阅览 | 承担可选探索与安静停留，与主厅构成不同节奏。 |
| 档案后室 | 提供更私密的整理/保存叙事，并形成短回路而非不可达背景。 |
| 交互边界 | 阅读/展示锚点、座位和档案架必须在 P1 中不侵占主通道及返回门。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 安静门廊与入口 | 从公共区进入、减速、读身份 | 门廊可停步但不堵公共步行面。 |
| 主档案厅 | 方向建立、主阅读/展示 | 进门即可读到主厅中心和侧阅览分支。 |
| 侧阅览室 | 可选阅读、安静探索 | 有实际门洞/开口连接主厅，不能只作为窗后布景。 |
| 档案后室 | 保存/整理叙事、回路一端 | 与主厅或侧阅览形成可通行连接，并保留可回到主入口的路径。 |
| 服务侧门/整理廊 | 后勤叙事与第二离开 | 接公共服务边或安静巷，避免和主入口抢功能。 |

## 4. 玩家流线

```text
水庭公共步行面 → 安静门廊 → 主档案厅 → 侧阅览室
                                      └→ 档案后室 → 服务整理廊 → 服务侧门 → 外部服务边
```

- 玩家可从主厅分别到达侧阅览与后室，并可经任一分支回到主厅和正门；不要求先触发任务或交互才可通过。
- 至少保留正门原路返回，服务侧门为第二可选离开；档案架、阅读桌、展示物和门扇不得堵住这两条路径。
- 本类型为单层：禁止使用不可行走阁楼、攀爬书架、跳跃高台、传送或装饰梯伪造可探索层级；若 P1 变为多层，须新增实际可走楼梯、楼层可达表与每层回到正门/侧门的连续路径，禁止把疏散依赖单向坠落。

## 5. 外部接街与净空

- 正门接水庭公共区的安静步行面；服务侧门接后侧服务边或次级巷，不指定总图位置与建筑邻接实例。
- 门廊、深窗和导向装饰不能遮住入口或把人流挤入水边/主路；入口前保留停步、转身与看清室内方向的空间。
- 服务侧不得堆放档案箱而封住后室返回，且不会把货运活动引向主要公共阅读入口。

## 6. P0 验收条件

- [ ] `BF-09` 为 1 座可进入档案馆，主厅、侧阅览室和档案后室均是可走空间。
- [ ] 阅读/叙事探索、主厅导向和两条返室外路径已定义，未依赖任务触发通行。
- [ ] 非多层假象：所有标记为可探索的区域在单层均真实可达；未来加层有楼梯与返回约束。
- [ ] 未与 BF-10 的公告协作功能、商店或地标建筑混淆。
- [ ] 未编造档案剧情、城市坐标、三选一事件、Boss 或数值内容。

# BF-22 封存旧宅｜P0 功能任务卡

> 阶段：P0 功能定义；本卡不锁定尺寸、平面、局部坐标、白模或效果图。  
> 建筑编号：`BF-22`；实例配额：5 座可进入实例；建议分区：E. 工坊与居住坡巷（靠近安静内巷、旧生活庭或边缘转角，但仍与主城步行网保持可读联系）。

## 1. 建筑身份与层级限制

这是被妥善封存、可安全进入的旧住宅，用于承载安静环境叙事和时间层次。它可以显得旧、少有人使用，却绝不能成为坍塌废墟、不可进入布景或危险跑酷场。

- 封存感来自关闭的部分房门、被覆盖的家具、旧门牌、有限积砂或受控修补痕迹；主体结构、楼板、楼梯、栏杆和可走地面必须完整安全。
- 至少保留一条明确开放的进入路径和一组可探索室内空间；被封的房间可作为可见叙事背景，但不得被统计为可探索区域。
- 不做恐怖屋、Boss 前置地牢、随机商人店或公共档案馆的替代品；视觉强度保持低于 BF-06，青绿设施仅在合理维护节点少量出现。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 安静叙事探索 | 玩家沿安全、低干扰的室内路线阅读旧住户遗留信息，至少在两处空间获得前后关联。 |
| 封存辨识 | 开放区、隔离区和仅可窥见区必须通过门、封条、格栅或可读边界区分，避免误导玩家撞墙。 |
| 轻交互 | 每实例至少 1 个可检查的环境叙事/轻交互候选点；不绑定固定战斗、商人或三选一事件。 |
| 结构信任 | 玩家能凭结构状态判断哪些路可走：完整楼梯、明确栏杆、稳定楼板和可见回程优先于惊险断裂。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能与可达要求 |
|---|---|---|
| F22-01 | 封存门廊/开放前室 | 唯一明确的可进入入口，建立“维护后开放”的安全预期。 |
| F22-02 | 旧起居室 | 实际可走的主叙事空间，含可检查或可观察的遗留信息。 |
| F22-03 | 内庭/采光井或过渡廊 | 可走的安静转场，或明确可绕行的内向光源节点。 |
| F22-04 | 私密旧房 | 至少 1 间实际可进入的次级叙事空间，与主叙事形成关联。 |
| F22-05 | 封闭可视房/维护角 | 可从安全边界窥见的封存信息；只有门开启并具备路径时才可转为探索区。 |

## 4. 玩家流线与竖向规则

```text
安静内巷
  → 开放前室（F22-01）
  → 旧起居室（F22-02）
  → 内庭/过渡廊（F22-03）
  → 私密旧房（F22-04）
  → 原路线返回开放前室 → 安静内巷
```

- 二层/屋顶：均为可选；若开放，必须通过已维护的真实楼梯抵达，至少包含一处可走房间/平台，并有连续栏杆、完整楼板和返回地面的安全路线。
- 被封楼梯、断裂夹层、外墙残台、封闭屋顶与只能从下方仰望的二层可作为叙事背景，必须清楚标为不可达，不能计入探索或引导玩家尝试危险跳跃。
- P1 必须为开放楼梯、平台、屋顶边缘和内廊按《04》落实踏步闭合、头部净空与 1.1m 栏杆；封存边界不得留下可穿模、跌落或单向困住玩家的缺口。

## 5. 接巷与外部净空

- 接安静内巷、生活庭边或居住坡巷的次级转角；门口应有维护后可进入的清楚信号，但不写最终坐标、地块、道路朝向或世界位置。
- 门前积砂、陶罐、封存标识或低矮绿化只能增强旧感，不得堵住唯一入口、视线、楼梯或撤回室外的主通道。
- 外部可预留一处不绑定功能的安静停留点；不可把封存旧宅外立面设为三选一事件、战斗或商人的专属触发器。

## 6. 允许实例变体

- 可变：开放房间与封闭可视房比例、旧住户叙事主题、内庭/过渡廊形式、局部修补痕迹、是否开放一处安全二层或屋顶。
- 不可变：一条明确开放的安全主流线、至少两处可探索叙事空间、开放/封存边界可读，以及无条件返回街巷的路径。
- 5 座实例应分别表达不同的旧生活主题（如迁居、维护中断、代际遗留、季节性封存、修复待启用）；不得用同一套封条、家具和封闭门重复。

## 7. P0 验收条件

- [ ] `BF-22` 是结构安全、可实际探索的封存旧宅，不是不可进入废墟壳体或危险跳跃关卡。
- [ ] 开放区、封存可视区和不可达背景区边界明确；至少两处室内叙事空间可走并可返回街巷。
- [ ] 任何开放二层或屋顶均具备合规楼梯、完整楼板、栏杆和返回路径；所有不可达旧构件未计入探索。
- [ ] 唯一入口、主通道、楼梯、转身平台和回程没有被封存陈设、积砂、家具或装饰阻挡。
- [ ] 5 座实例在封存状态与叙事主题上有差异，同时保持“旧但安全”的原型边界。

## 8. 确认后进入 P1 的工作

输出开放/封存/仅可视区域图例、各层可达声明、完整楼板与楼梯/栏杆数值、门与封存边界、叙事锚点、接巷净空、实例变体矩阵、布局 JSON 和设计图需求提示词；P2 白模须以多种颜色方块区分可探索房间、封存可视区、不可达背景、稳定楼板、楼梯、栏杆与回程路线，禁止用破碎外观掩盖碰撞或可达性问题。

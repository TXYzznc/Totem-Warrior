# BF-12 风塔服务站｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-12`；实例配额：1；建议分区：通风/能源设施节点、开阔街段或屋顶线附近的服务侧。

## 1. 建筑身份与层级限制

风塔服务站是维护城市通风与局部能源分配的可探索设施。它可以有明确竖向构件和风向识别，但室内必须比外观更易读，不能变成只可仰望的纪念塔。

- 风塔为功能性次地标：高度与发光均克制，显著性低于 BF-01 与 BF-06；不使用纹样环、巨型尖塔或全立面霓虹。
- `DE-17` 风向仪/小风轮、`DE-30` 通风帽和 `DE-14` 能源柱仅在有设备逻辑的位置使用。
- 竖井、风机和高处风道可见，但玩家探索路线与危险设备区须清晰分离。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 城市叙事 | 让玩家从进站、看见风道、登上观察层的过程中理解风塔吸风/导风的作用。 |
| 可交互点 | 预留服务面板或风量读数锚点，面板前不可堆放设备、箱体或装饰。 |
| 探索 | 提供地面服务室、可见竖井的内廊和可达观察平台；风机本体不替代可玩内容。 |
| 安全边界 | 不绑定三选一事件、随机商人或 Boss；高处与机房危险面用结构和栏杆表达，不能以不可见墙糊弄。 |

## 3. 最小可探索室内与竖向结构

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 服务前室 | 进站、读取服务标识 | 主入口后即见服务面板和上行方向，避免高柜或风机外壳挡住视线。 |
| F1-02 | 风道控制室 | 面板交互、风道叙事 | `DE-15/16` 沿墙与顶棚走线，中央为连续可走带。 |
| F1-03 | 竖井内廊 | 观看风道与风机隔离面 | 以可透视格栅/围护组织视线，`DE-26` 不得封死必经通路。 |
| F2-01 | 风塔观察层 | 观察、短暂停留、回望城市 | 必须是实体可走楼层或平台，不得以屋顶贴图、梯子或悬空装饰代替。 |

F1 至 F2 必须由正式楼梯连接；楼梯宽度、均匀踏步、中间平台、2.4m 最小头部净空和 1.1m 栏杆在 P1 定量。若风塔另有更高的封闭维护层，该层不作为本卡要求的可探索目标；不得以垂直维护梯替代 F2 的可走楼梯或返回路线。

## 4. 玩家流线

```text
开阔服务街 / 风塔脚下步道
  → 服务前室（F1-01）
  → 风道控制室读数（F1-02）
  → 竖井内廊（F1-03）
  → 正式楼梯
  → 风塔观察层（F2-01）
  → 原楼梯返回 F1-03
  → 主入口离站
```

上行视线须由楼梯、采光或低亮导向灯自然提示；每次登高后都能无歧义返回。维护梯、通风管攀爬点、封闭机房门不得成为唯一出口。

## 5. 外部接街、维护与 DE 约束

- 接开阔街段或设施侧步道，入口保留人行到达空间；维护面和设备卸换口面向非主路服务侧。
- 可使用 `DE-13/14/15/16/17/26/27/30`；悬挂物与托架最低边距地 2.4m，风塔设备不得遮挡主入口识别。
- 不在塔脚、楼梯出口、门扇扫掠区放 `DE-20/22/31`；能源柱不占服务面板交互净空。

## 6. P0 验收条件

- [ ] 建筑可读为通风/能源服务站，风塔竖向构件有明确功能且未抢占城市主地标层级。
- [ ] 玩家可进入地面控制空间、经过可见竖井内廊、经正式楼梯抵达观察层并返回。
- [ ] 不将维护梯、风机外壳、屋顶贴图或封闭设备层计为可探索路线。
- [ ] 高处栏杆、楼梯头部净空、平台及人行/维护分流已被列为后续硬约束。
- [ ] 不绑定随机商人、三选一事件或 Boss；未写入最终城市世界坐标。

## 7. 确认后进入 P1 的工作

输出各层和塔体层级、正式楼梯与平台参数、设备隔离区、交互锚点、固定 `DE` 坐标、布局 JSON 与设计图提示词。其后的 P2 白模必须用多色方块区分可走层、墙体、竖井/设备禁入区、楼梯、栏杆及风道，验证每层的真实可达与返回。

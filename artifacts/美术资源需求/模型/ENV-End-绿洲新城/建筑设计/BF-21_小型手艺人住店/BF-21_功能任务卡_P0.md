# BF-21 小型手艺人住店｜P0 功能任务卡

> 阶段：P0 功能定义；本卡不锁定尺寸、平面、局部坐标、白模或效果图。  
> 建筑编号：`BF-21`；实例配额：5 座可进入实例；建议分区：E. 工坊与居住坡巷（接次级巷、近邻工坊或生活小庭）。

## 1. 建筑身份与层级限制

这是手艺人把小型展示/接待、实际工作台和私宅合并的自营住店。它应呈现“人住在手艺旁”，但不承担 BF-02～BF-05 的随机商人职能，也不扩展成大型工坊或市场摊位。

- 前部是小尺度展示或来客接待，核心是可使用的工作区；后部或上部是明确分离的私住空间。
- 作业物、热源或工具必须有安全边界，不能挤入玩家主通道；不做高温重工规模，以免和 BF-13～BF-15 混淆。
- 门面以工作痕迹、少量样品、门牌和遮阳识别，禁止使用商人店级大招牌、随机商人柜台或大型外摆占道。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 手艺展示 | 玩家能从前部看到作品/样品，再进入或绕过工作区理解制作过程。 |
| 工作与居住分区 | 工作台区与私住区在动线、视线或门洞上有明确边界；居住不是工作台后的贴图背景。 |
| 叙事/轻交互 | 每实例至少 1 个与手艺、订单、修补或家庭生活有关的环境叙事/轻交互候选点。 |
| 非商人边界 | 不作为随机商人容器；不设交易锚点，不把三选一事件、Boss 或纹身功能绑定到本类型。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能与可达要求 |
|---|---|---|
| F21-01 | 巷侧前店/展示角 | 小尺度迎客、样品观看和身份识别；不等同于商人柜台。 |
| F21-02 | 工作台区 | 实际可绕行、可观察的制作区；作业面与玩家路径分开。 |
| F21-03 | 储料/清洁角 | 服务工作流程，可进入或明确可见；不得侵占逃生与楼梯。 |
| F21-04 | 私住起居区 | 后住或上住的真实可走生活空间。 |
| F21-05 | 私住辅助房 | 至少一间可进入的休息、洗护或储物空间。 |

## 4. 玩家流线与竖向规则

```text
工坊/居住次巷
  → 前店/展示角（F21-01）
  → 工作台区外围（F21-02）
  → 储料/清洁角（F21-03）
  → 后住或经楼梯到上住（F21-04 / F21-05）
  → 原入口或独立生活侧门返回巷道
```

- 若采用上住，首层到私住必须经可走的住宅楼梯；楼梯从工作区安全边界外起步，不穿越作业台、热源、货架或对客展示的唯一通道。
- 上住/可达屋顶一旦采用，必须至少提供可走私住空间或可走屋顶停留面，并配合连续楼梯、平台、栏杆和可回到地面的安全路线；封闭阁楼、假二层和仅摆放通风帽的屋顶不计入探索。
- 若私住后置在同层，工作和生活之间仍需通过门洞、转折或屏风形成可读过渡，且不削弱主通道与安全回程。

## 5. 接巷与外部净空

- 对接工坊与居住坡巷的次级巷，前店入口保持可辨认，后勤/生活侧门（若采用）不得抢占主门身份；不指定最终坐标或相邻工坊实例。
- 门前可少量使用遮阳、陶罐、样品展示或低亮导向，但任何外摆不得占用入户、上楼、货运或巷道连续通行。
- 可与工坊街形成视觉关联，但不放置大批货物、重型卸货口或高温设备，维持小型手艺人尺度。

## 6. 允许实例变体

- 可变：手艺主题（修补、编织、小型木作、器物维护等）、前店开口、工作台朝向、后住/上住布局、侧门是否采用与门前样品组合。
- 不可变：前部展示、可绕行工作区、明确私住、工作/生活分区以及独立返回巷道的连续流线。
- 5 座实例的手艺主题和陈设语言必须不同；不得用相同工作台、相同前门和相同住区位置复制成五家假店铺。

## 7. P0 验收条件

- [ ] `BF-21` 清楚表达小型手艺人“住+作+展示”，但不与 BF-02～BF-05 的随机商人店或大型工坊混淆。
- [ ] 前店、工作、储料/清洁和私住均具有真实可走或可读的空间关系；私住并非不可进入背景。
- [ ] 上住/屋顶如存在，拥有安全楼梯、平台、栏杆和返回路径；不可达装饰层未计入探索。
- [ ] 作业物、货物和外摆不侵占门洞、楼梯、主通道、转身平台或返回路径。
- [ ] 5 座实例具备手艺与布局差异，同时不破坏住店原型功能。

## 8. 确认后进入 P1 的工作

输出工作安全区、展示/工作/私住分区、各层与楼梯数值、热源/工具/货物净空、门窗与栏杆、叙事锚点、接巷关系、实例变体矩阵、布局 JSON 和设计图需求提示词；P2 以多种颜色方块区分前店、工作安全区、储料区、私住、楼梯、可走屋顶和不可探索设备面。

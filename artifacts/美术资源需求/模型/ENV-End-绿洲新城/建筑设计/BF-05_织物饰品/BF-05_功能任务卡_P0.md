# BF-05 织物饰品｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-05`；实例配额：1 座可进入实例；建议分区：商旅巷街（可接有遮阳的街侧停留带）。

## 1. 身份与层级限制

这是四座随机商人商店之一，承担织物、饰品与旅行穿戴的商店功能。它可比其他商店更具柔和遮阳和外摆辨识度，但应保持日常、亲近、低矮，不能升级为城市地标或活动舞台。

- 随机商人只可在 `BF-02`～`BF-05` 出现；商人不在时，玩家仍可从样布、包装与整理台探索店铺用途。
- 允许短遮阳帘、低矮展示架和克制外摆；禁止大面积旗帜幕墙、跨街悬挂装置、巨型发光招牌或 BF-01 专属纹样表达。
- 单层可探索是本 P0 基线；内部不得只是橱窗后景，亦不得把试戴/展示区域做成不可进入的隔离盒。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 主要交互 | 商人锚点位于前店饰品柜台内侧，玩家在柜台外侧完成交易。 |
| 服务表达 | 表达布料挑选、饰品陈列、包装与旅行穿戴补给；不锁定商品、经济或换装数值。 |
| 可选探索 | 可走入展示边、样布整理台和后部包裹/库存间，形成非交易的阅读内容。 |
| 视觉引导 | 以织物色彩、低饱和招牌和遮阳边缘引导入口；不得依赖 HUD 或强发光。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 遮阳门廊 | 识别、短暂停留、进店 | 遮阳与外摆留在门侧，不遮挡街道、门洞或室内首段视线。 |
| 前店展示区 | 浏览织物/饰品、到达柜台 | 陈列可形成两侧浏览，中央保留连续主通路。 |
| 饰品柜台区 | 随机商人交易 | NPC 锚点、玩家站位和绕行边界明确。 |
| 样布/包装整理区 | 生活叙事、可选探索 | 可由前店近看或走入，不能替代后部库存空间。 |
| 后部包裹/库存间与侧门 | 库存、货运、短回路 | 以实际内门接前店，再经侧/后门回到次级巷道。 |

## 4. 玩家流线

```text
商旅巷街 → 遮阳门廊 → 前店展示区 → 饰品柜台交互
                            └→ 样布/包装整理区 → 后部库存间 → 侧/后门 → 次级巷道
```

- 玩家可从展示区直接交易，也可绕过柜台浏览整理区后返回；柜台不得成为唯一堵点。
- 需保留原前门返回和经库存侧门离开的可选返回路径，二者在白模前都须被记录为不可侵占通行面。
- 本类型为单层：禁止用挂布、展示台或不可攀爬的装饰梯制造假二层；若 P1 改为多层，须增加真实可用楼梯、明确上下行可达性、至少一条回到一层/室外的连续路径，并禁止跳跃、攀爬陈列架或传送作为楼层连接。

## 5. 外部接街与净空

- 正门接商旅巷街；侧/后门接次级巷道或货运面，不为该原型指定城市坐标。
- 遮阳、织物外摆和座椅只能占用店面附属停留带，须始终留出从主路进门、绕开外摆和看清招牌的空间。
- 后门不对主游逛路抢视觉，且包裹暂放不得封住返回路径。

## 6. P0 验收条件

- [ ] `BF-05` 为 1 座可进入织物饰品商店，并正确受随机商人范围限制。
- [ ] 前店、柜台、整理区、库存间、两条返街路径均可在 P1 转化为实走空间。
- [ ] 遮阳与外摆增强识别而不堵街、不堵门、不遮挡主视线。
- [ ] 非商人状态可探索，且不涉及三选一事件、Boss 或未确认的具体经济功能。
- [ ] 标识和体量低于 BF-01、BF-06，且未编造世界坐标。

# BF-05 织物饰品商店｜白模制作规范

> 后续 P2 必须遵守全局《06_彩色白模制作合同》。仅作 P1 前置，不创建 Unity 场景、ProBuilder 对象或截图；尺寸、位置以 `BF-05_楼层布局.json` 为准。

## Collection 与结构读取

```text
BLD_BF05_ROOT
├── GEO_Structure
├── GEO_Walkable
├── GEO_Function
├── GEO_Vertical
├── GEO_Entrances
├── GEO_InteractionPreview
├── GEO_RestrictedPreview
├── COL_Collision
└── COL_Anchors
```

根对象为首层完成面中心；Layout `+Z`、正门 `-Y`，Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`。白模应一眼读出 10×15m 窄长矩形、退入的屏风门廊与纵向连续展示廊，而非“前店加两个后室”的横向分块。

## 七类 CB 对象

| 类别 | 色值 | 本资产对象与要求 |
|---|---|---|
| `CB_Structure` | #A9B0B7 | `CB_Structure_F1_MainBar`、`CB_Structure_F1_ScreenPorch`、内墙、屋面、女儿墙；门廊两侧留出屏风边带与中央可走带。 |
| `CB_Walkable` | #D4B56A | `CB_Walkable_F1_ScreenPorch`、`CB_Walkable_F1_DisplayGallery`、`CB_Walkable_F1_CounterBay`、`CB_Walkable_F1_SamplePrep`、`CB_Walkable_F1_Stock`；从门廊连续铺至 D02。 |
| `CB_Function` | #4F93D1 | `CB_Function_P01_AccessoryCounter`、`CB_Function_P02_TextileTable`、`CB_Function_P03_StockRack`；功能块全部贴侧，不得封住中央纵向流线。 |
| `CB_Vertical` | #9569C9 | 单层，Collection 为空；严禁装饰梯、挂布假二层和屋顶出入口。 |
| `CB_Entrance` | #5FBF76 | `CB_Entrance_D01`、`CB_Entrance_D02`、`CB_Entrance_D03`、`CB_Entrance_D04`；D01 后退在门廊内，D02 是侧/后勤出口。 |
| `CB_Interaction` | #42C6C6 | `CB_Interaction_ANCHOR_MERCHANT`、`CB_Interaction_ANCHOR_TRADE`、`CB_Interaction_ANCHOR_TEXTILE_TABLE`、`CB_Interaction_ANCHOR_STOCK`；均无实体碰撞。 |
| `CB_Restricted` | #D95C5C | `CB_Restricted_R01_RoofDrainNorth`；只表示北侧排水检修边，不得侵入库存通道或被读为玩家路线。 |

- 结构、`P01`～`P03`、`E03` 与 `R01` 进入 `COL_Collision`；锚点、`E01`、`E02`（挂布）不加实体碰撞。用 1.80m/0.70m 角色代理完成门廊→D01→所有区域→D02 与原路返回。
- [ ] 七类色彩、Collection、命名及空 `stairs` 与 JSON 一致。
- [ ] 门廊中央、D01 视线和纵向主通路连续；屏风与展示物只在两侧，不能形成不可进入橱窗或封路。
- [ ] 后续 P2 输出正、背、左、右、轴测五视图和室内剖切；本轮不输出截图。
- [ ] 不混入图片、FBX、`.unity`、最终材质或世界坐标。

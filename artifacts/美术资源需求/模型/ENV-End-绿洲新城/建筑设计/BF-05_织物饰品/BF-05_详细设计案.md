# BF-05 织物饰品商店｜详细设计案

> P1 施工真源：本文件与 `BF-05_楼层布局.json` 完全一致。设计图提示词仅作视觉参考，不能修改结构。本轮不创建 `.unity`、白模、FBX、贴图或图片。

## 1. 身份、坐标与尺度

- 资产 `BF-05`（TextileAccessoryShop），1 座可进入实例；商旅巷街。D01 位于退入式门廊内，接主游逛路；D02 是东侧/后部的侧勤门，接次级巷道。
- 原点为首层完成面中心 `(0,0,0)`；Layout `+Z` 向上、正门朝 `-Y`；Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`。所有坐标均为局部坐标，不写最终世界坐标。
- 总包围盒为 X 宽 10m（`-5..5`）、Y 深 15m（`-7.5..7.5`）；单层主体墙高 4.8m、室内净高 4.2m、女儿墙顶 5.9m；外墙 0.30m、内墙 0.20m、屋面 0.30m。
- 这是窄长纵向廊店：南端 `8.8×1.8m` 织物屏风门廊向内退入，之后按门廊→展示廊→柜台→样布整理→库存顺序沿 Y 轴串联。无横向扩展翼、夹层或屋顶活动空间。
- D01 位于门廊北端，门外净深由门廊提供 1.8m；D02 外侧净深 1.2m。门廊两侧挂布屏风只占附属边带，不能遮挡 D01、中央主通道或街侧识别。

## 4. 流线、碰撞与验收

- 纵向流线：`主游逛路 → F1_ScreenPorch → D01 → F1_DisplayGallery → D03 → F1_CounterBay → F1_SamplePrep → D04 → F1_Stock → D02 → 次级巷`；任意节点可原路经 D01 返回。
- `P01` 外侧交易站位、`P02` 东侧、`P03` 西侧与 D01/D02/D03/D04 必须保持净空；主通道不小于 1.8m，侧勤支路不小于 1.2m。门廊中央与 D01 视线不得被屏风、招牌或外摆遮挡。
- 结构、`P01`～`P03`、`E03` 与 `R01` 使用简化实体碰撞；锚点、`E01`、`E02` 与 `CB_Interaction` 无实体碰撞。室内最低净高为 4.2m。
- 用 1.80m 高、0.70m 直径角色代理走通门廊、D01、所有锚点、D02 及原路返回。
- 验收：本文件的 10×15m 包围盒、纵向房间序列、洞口、窗、锚点、固定物、禁区与 JSON 一致；不得加入 P0 外功能、世界坐标或系统数值。

# BF-07 商旅行馆｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、房间数量、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-07`；实例配额：1 座可进入实例；建议分区：商旅巷街（接主游逛路，并有安静的后勤侧巷）。

## 1. 身份与层级限制

商旅行馆提供休息、信息获取和短住服务：一层是面向路人的公共厅，二层是可探索的客房层。它是商旅巷街的重要公共服务节点，但不应成为比 BF-01/BF-06 更强的城市地标。

- 层级必须清楚：一层公共厅、接待和公共服务；二层客房及安静走廊。二层不是纯立面、不可进门的假窗或只作屋顶背景。
- 以入口门洞、遮阳、接待可见性和旅人行李叙事建立身份；禁止高塔、巨幅悬挂招牌、强发光门面及与 Boss 区相同的压迫式仪式入口。
- 住宿/信息功能只定义空间承载，不在 P0 锁定存档、任务、经济或具体 NPC 系统。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 公共服务 | 一层公共厅承载休息、问询、信息读取与接待交互的可能性。 |
| 短住探索 | 二层客房层可被玩家实际抵达和探索；不要求 P0 指定全部房间数。 |
| 接待交互 | 接待点可被进门玩家直接识别，但不得堵死上楼、后勤或原路离开的通道。 |
| 环境叙事 | 行李、路线信息与公共停留形成商旅感；不把室内做成单一交易窗口。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 街侧门廊 | 抵达、识别、短暂停留 | 从商旅巷街可读到入口与接待方向，门廊不堵主路。 |
| 一层公共厅 | 休息、问询、信息、接待 | 门厅、接待、停留与通往楼梯的首段动线清楚分开。 |
| 接待与信息边 | 服务交互 | 接待点对入口可见，玩家可绕过而非被柜台卡死。 |
| 可用公共楼梯与中间平台 | 上下二层 | 是唯一允许的层间主连接，必须实际可走且可双向返回。 |
| 二层客房走廊 | 到达客房、安静探索 | 可连续通行并服务至少一个可探索客房/公共阅读点。 |
| 二层可探索客房 | 短住叙事 | 至少一间可进入、可转身、可返回走廊的房间；其余数量由 P1 定。 |
| 后勤侧门/服务通道 | 后勤与第二返回 | 从一层接到安静侧巷，不替代街侧正门。 |

## 4. 玩家流线与楼梯规则

```text
商旅巷街 → 街侧门廊 → 一层公共厅 → 接待/信息边
                                  ├→ 公共楼梯 → 二层走廊 → 可探索客房 → 原楼梯返回一层
                                  └→ 后勤侧门/服务通道 → 安静侧巷
```

- 玩家进入后可先使用/绕过接待，再选择上二层探索或从一层后勤通道离开；无需与接待交互也能完成完整短探索。
- 楼梯必须是可实际行走的双向楼梯，含可停步、转身的中间平台；二层至少有一条经该楼梯返回一层公共厅的连续路径。
- 二层不得设置死端客房、只能跳下的露台、装饰性假楼梯或单向传送；禁止把床、行李、柜台、门扇或装饰放进楼梯、平台和返回通道。
- P1 必须按公共楼梯规范锁定净宽、踏步、净空、栏杆和门扇开启区，并验证二层每个可探索房间可返回室外。

## 5. 外部接街与净空

- 正门接商旅巷街的主游逛路，后勤门接安静侧巷；不定义最终地块坐标、朝向或相邻建筑实例。
- 街侧保持入口、看见接待方向和旅人停步的净空；遮阳、座椅、行李等不得压入主路或封住正门。
- 后勤侧门提供服务/第二离开可能，不能让侧巷货物侵占公共厅返回路径。

## 6. P0 验收条件

- [ ] `BF-07` 为 1 座可进入商旅行馆，明确一层公共厅与二层可探索客房层。
- [ ] 一层接待、公共停留、上楼与后勤离开互不堵塞。
- [ ] 存在真实可用的双向公共楼梯，二层可经楼梯连续返回一层和室外。
- [ ] 二层至少预留一间可探索客房，非纯外观或封闭假层。
- [ ] 未锁定城市坐标、具体住宿系统、三选一事件或 Boss 功能，地标层级低于 BF-01/BF-06。

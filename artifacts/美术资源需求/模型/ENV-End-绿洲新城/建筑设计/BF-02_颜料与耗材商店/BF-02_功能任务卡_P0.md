# BF-02 颜料与耗材商店｜P0 功能任务卡

> 阶段：P0 功能定义，尚未锁定尺寸、平面、白模或效果图。  
> 建筑编号：`BF-02`；实例数：1；功能分类：随机商人商店（四座商店之一）。

## 1. 建筑身份

一间出售活性颜料、针具、封存容器和旅行耗材的小型商店。它应当像绿洲新城中的日常服务点：有颜色、有材料和手作气息，但绝不能与唯一地标 `BF-01 晖纹纹身庭` 竞争。

### 层级限制

- 不使用高塔、悬挂纹样环、双高巨型拱门或大面积发光。
- 入口识别靠低矮尖拱门、颜料封存罐、短遮阳帆和一块店招完成。
- 青绿活性颜料只出现在容器标签、少量能源接口和工作台边缘；主体仍为暖白石材与低饱和青绿饰带。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 商人 | 本建筑是随机商人候选容器之一；商人未出现时，建筑仍可进入并保留环境叙事。 |
| 主交互 | 商人锚点位于前店主柜台内侧；玩家在柜台外侧完成交易。 |
| 交互净空 | 玩家站位周围直径 3.0m 不放置永久碰撞物；柜台前主通道不小于 1.8m。 |
| 探索 | 至少可探索“前店展示区 + 后部储存/调制区”两类空间；不是只有一间交易窗。 |
| 出入口 | 主入口面向商旅弯街；设置一处后勤侧门或后门，用于货运和形成短探索环路。 |
| 事件 | 不绑定三选一事件；该类事件仅可在店外街角/遮阳区等独立候选点发生。 |

## 3. 建议空间结构

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 街侧前店 | 进店、浏览、交易 | 入口后能立即看见柜台与颜料陈列；不能用高货架封死视线。 |
| F1-02 | 商人柜台区 | 随机商人交互 | 柜台、商人锚点、玩家站位三者明确；后方留补货通道。 |
| F1-03 | 颜料展示壁 | 商品识别与叙事 | 使用 `DE-21` 颜料封存罐、小型货架和低亮标签；不做霓虹墙。 |
| F1-04 | 后部调制/储存间 | 环境探索、货物后勤 | 可放置 `DE-20`、`DE-22`、`DE-15`；与前店有一扇可视或可通过的内门。 |
| F1-05 | 遮阳门廊 | 入口停留和街道过渡 | 使用 `DE-10/11/13/19` 中的克制组合；不把摊位摆到主路中央。 |

## 4. 玩家流线

```text
商旅弯街
  → 遮阳门廊（F1-05）
  → 前店展示区（F1-01）
  → 柜台交互（F1-02）
  → 颜料展示壁 / 后部调制储存（F1-03 / F1-04）
  → 后勤侧门或后门
  → 次级货运巷
```

主流线必须允许玩家不交易也能完成一次短探索并返回街道；后勤门不应变成可绕过主入口的视觉主门。

## 5. P0 验收条件

- [ ] 建筑明确是 `BF-02`，而非纹身店的复制品、普通货摊或纯背景商铺。
- [ ] 商人随机出现时可完成交易；商人不出现时建筑仍有可探索内容。
- [ ] 至少存在前店与后部空间两层探索信息，且有真实室内可走区域。
- [ ] 主入口、柜台交互区、货运出口和主通道的职责清晰。
- [ ] 地标性显著低于 BF-01；不使用塔楼/纹样环/巨型门洞等 BF-01 专属语汇。
- [ ] 不绑定三选一事件或 Boss 功能。

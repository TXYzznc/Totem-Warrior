# BF-02 颜料与耗材商店｜详细设计案

> P1 尺寸真源：本文件与 `BF-02_楼层布局.json` 必须一致。`BF-02_设计图需求提示词.md` 只提供视觉参考，不能修改结构。本轮不创建 `.unity`、白模、FBX、贴图或图片。

## 1. 身份、坐标与总尺度

- `BF-02`（PigmentAndSupplyShop）是紧凑的颜料调制店：12m 宽、16m 深的单层深矩形，前店之后并列西侧调制间与东侧储存间。其辨识来自“深进式前店＋左右后场”，而不是 BF-03 的横向门廊。
- 原点为首层完成面中心 `(0,0,0)`；Layout `+Z` 向上，唯一街道主门朝 `-Y`；导入 Unity 使用 `Unity(X,Y,Z)=Layout(X,Z,Y)`。
- 外轮廓 `X=-6～6m`、`Y=-8～8m`；主体高 4.8m，室内净高 4.2m，屋面完成面 Z=4.8m，连续女儿墙顶 Z=5.9m。外墙 0.30m、内墙 0.20m、屋面 0.30m；封闭面积 192.0㎡，净可探索面积 171.9㎡。
- 严格单层平屋顶：无夹层、楼梯、塔、阳台、假二层或可达屋顶；地标等级低于 BF-01/BF-06。

## 4. 流线与验收

- 连续流线：`D01 → F1_FrontRetail → 柜台/展示 → F1_BackCorridor → D03/D04 → 西调制或东储存 → D02`；亦可原路由 D01 返回。
- 前店主通道 ≥1.8m，柜台侧绕行 ≥2.0m，后走道 ≥1.0m（仅承担短连接）；门扇不得扫入通道或交互净空。
- 正背立面恒为 12m 宽、左右立面恒为 16m 深；南面只有 D01 和 W01，东面只有 D02，北面只有 W03/W04。平屋顶与单张小遮阳帆保持颜料店的紧凑、深进式外观。

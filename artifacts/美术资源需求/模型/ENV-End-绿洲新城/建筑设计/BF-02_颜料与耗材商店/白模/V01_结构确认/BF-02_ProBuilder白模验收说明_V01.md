## 白模语义配色（仅用于结构审阅）

| 颜色 | 构件语义 |
|---|---|
| 暖砂色 | 外墙、门洞上方墙体和外立面体块。 |
| 青绿色 | 屋面、女儿墙和屋顶轮廓。 |
| 浅蓝色 | 室内隔墙、后部房间分区。 |
| 深灰/黑色 | 门窗洞、可见开口。 |
| 橙色 | 柜台、货架、展示台、调制台等功能家具。 |
| 砖红色 | 单张遮阳帆。 |
| 蓝灰色 | 地坪和建筑基座。 |

这些颜色不是最终材质、配色或效果图指令；它们只让白模中的体块、开口、功能物和屋顶边界一眼可区分。

## V01 已验证项

- 单层主体：正背宽12m、左右深16m，主体高4.8m、女儿墙顶5.9m。
- 正面只有偏西 D-01 主入口和偏东 W-01 展示窗；门前为单张遮阳帆。
- 东侧后半段为 D-02 后勤门；西侧前半段为 W-02 窗；北侧为 W-03/W-04 两扇高侧窗。
- 前店、后走道、西调制间、东储存间、柜台与货架均已用独立 ProBuilder 体块表示。
- 无二层、夹层、楼梯、塔楼、屋顶路径或其他会提升地标层级的结构。

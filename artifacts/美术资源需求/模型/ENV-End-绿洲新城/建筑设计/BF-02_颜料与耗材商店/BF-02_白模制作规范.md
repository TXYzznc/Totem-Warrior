> P2 必须同时遵守全局《06_彩色白模制作合同》。本文件是 BF-02 的 P1 补充真源，不创建场景、ProBuilder 对象或截图。

## 根节点与差异结构

```text
BLD_BF02_ROOT
├── GEO_Structure / GEO_Walkable / GEO_Function / GEO_Vertical
├── GEO_Entrances / GEO_InteractionPreview / GEO_RestrictedPreview
├── COL_Collision / COL_Anchors
```

根节点位于首层完成面中心；Layout `+Z`、主门 `-Y`，Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`。BF-02 必须保持 **12×16m 深进式紧凑矩形**：前店之后分出西调制间和东储存间，平屋顶仅有一张短遮阳帆；不可误做为 BF-03 的横向双跨门廊。

## 通行、碰撞与验收

- `CB_Structure`、`CB_Function` 的实体家具和货架进入 `COL_Collision`；所有 `CB_Interaction` 仅作预览，禁止实体碰撞。
- 用 1.80m 高、0.70m 直径角色代理验证：`D01 → 前店 → 后走道 → D03/D04 → 两个后场 → D02`，并验证从所有可达点原路返回 D01。
- 交互直径 3.0m、D01 外侧净深 1.8m、D02 外侧净深 1.2m、前店主通道 1.8m、柜台绕行 2.0m 均不得被占用。
- P2 截图应含正、背、左、右、轴测与室内剖切；本轮不输出图片、FBX、`.unity`、最终材质或世界坐标。

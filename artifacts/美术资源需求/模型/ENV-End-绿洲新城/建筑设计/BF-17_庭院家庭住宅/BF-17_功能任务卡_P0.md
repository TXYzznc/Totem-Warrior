# BF-17 庭院家庭住宅｜P0 功能任务卡

> 阶段：P0 功能定义；本卡不锁定尺寸、平面、局部坐标、白模或效果图。  
> 建筑编号：`BF-17`；实例配额：12 座可进入实例；建议分区：E. 工坊与居住坡巷（与次级巷道、微路径或小型生活庭相接）。

## 1. 建筑身份与层级限制

这是供一户家庭日常起居的低层围院住宅。它以小院组织采光、通风、会面和家庭生活，是“新城仍被认真居住”的基础单元，而非商铺、旅店或地标。

- 默认由首层生活空间与 2–3 间可进入房间围合小院；可采用可达屋顶或可达二层之一，也可两者均有，但每一实例都须在 P1 明确其实际可达范围。
- 高度、门洞、光源和纹样强度均低于 BF-01、BF-06 及公共建筑；不设塔楼、巨型店招、无功能青绿发光立面或高耸风塔。
- 家庭入口应是可辨认但克制的街道身份：门牌/门槛、遮阳、窗洞、材料变化中至少两项；不可把庭院入口伪装成封闭背景。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 生活探索 | 玩家可阅读一个家庭的生活秩序：会客/用餐、休憩、储物或照料植被至少各有一处明确空间信息。 |
| 叙事点 | 每个实例至少设 1 个环境叙事或轻交互候选点；不绑定随机商人、纹身师、Boss 或三选一事件。 |
| 庭院用途 | 小院承担采光、通风、短暂停留和房间之间的步行组织，不能只是从外部看得见的贴图井。 |
| 探索边界 | 进入后至少可完整走访首层生活区、庭院及一处私密/服务房；若建二层或屋顶，必须实际可走。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能与可达要求 |
|---|---|---|
| F17-01 | 巷侧门厅/门廊 | 从次级巷道明确进入，提供由公共到家庭空间的过渡。 |
| F17-02 | 家庭起居/用餐区 | 首层核心空间；可停留、可观察生活陈设，并连通庭院。 |
| F17-03 | 小院 | 真实可踏入的环路节点；可布置水罐、低矮绿化或座位，但不堵通道。 |
| F17-04 | 私密房间 | 至少 1 间可进入的卧室/学习间/照护间，作为家庭叙事的安静层。 |
| F17-05 | 服务房或储物龛 | 至少 1 处可进入或可清晰窥见的日常服务空间；不得用纯立面代替。 |

## 4. 玩家流线与竖向规则

```text
居住次巷
  → 门厅/门廊（F17-01）
  → 起居/用餐区（F17-02）
  → 小院环路（F17-03）
  → 私密房间与服务房（F17-04 / F17-05）
  → 原入口返回居住次巷
```

- 二层/屋顶：可选。选择建造即必须从首层设置真实、连续的住宅楼梯抵达；只在外立面出现的假二层、封闭楼顶或不可攀爬阳台不得计入探索空间。
- 若有可达二层，二层至少含一间可进入房或可走内廊；若有可达屋顶，屋顶至少具备可走停留面、明确边界与回到室内/地面的同一路径或独立安全路径。
- 楼梯、楼板开口、屋顶边缘和内廊均须在 P1 按《04》落实踏步闭合、头部净空及连续 1.1m 栏杆；门扇不得扫入楼梯平台，且楼梯不承担被家具堵塞的储物功能。

## 5. 接巷与外部净空

- 主门接一条居住次巷；允许以短门廊、门前台阶或小型导水槽形成过渡，但不指定最终道路朝向、地块或世界坐标。
- 门外保持可辨认的入户净空，庭院周边保留连续步行环；DE-06/09/20/23/24/26 可作后续候选，均不得侵占门扇、楼梯或主通道。
- 可在屋顶与邻屋形成**有限的可选**连通预留，但不得假定邻屋已存在；其缺失时本实例仍须能独立探索并返回街道。

## 6. 允许实例变体

- 可变：小院偏置方向、房间开口朝向、私密房功能、屋顶或二层的实际采用、门前生活物组合与窗洞节奏。
- 不可变：围院家庭身份、至少 2–3 间房的可探索信息、首层生活核心、可进入小院与独立返回街道的主流线。
- 12 座实例须至少形成三种家庭生活叙事（如照料植物、多人用餐、安静学习）；不得复制同一平面和同一门前陈设。

## 7. P0 验收条件

- [ ] 可明确识别为 `BF-17` 家庭围院住宅，不与商店、工坊或旅馆混淆。
- [ ] 每一实例均有可到达入口、真实首层室内、可踏入小院、至少一个叙事/轻交互点及返回室外的连续路径。
- [ ] 任何采用的二层或屋顶均有符合结构安全要求的楼梯、栏杆和返回路径；不可达装饰层未被计入探索。
- [ ] 住宅主通道、门前和楼梯均未被家具、货物、绿植或装饰侵占。
- [ ] 实例变体满足配额多样性，同时不破坏家庭围院原型。

## 8. 确认后进入 P1 的工作

输出总包围盒、各层平面与可达声明、庭院环路、门窗/楼梯/栏杆数值、交互与叙事锚点、外部净空、实例变体矩阵、布局 JSON 和设计图需求提示词；P2 白模须以多种颜色方块区分墙体、楼板、可行走面、楼梯、庭院与功能区，并验证全路径可探索。

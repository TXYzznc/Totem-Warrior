# BF-20 巷道窄面住宅｜P1 详细设计案

本文与 JSON 是尺寸位置真源。布局为 X右/Y后/Z上，首层完成面中心为原点、正门向 `-Y`；Unity 使用 `Unity(X,Y,Z)=Layout(X,Z,Y)`。

## 结构与纵深流线

包围盒 `6×16×4.8m`，外/内墙 `0.30/0.20m`；单层，完成面0、净高4.2、板顶4.8，无二层、夹层、可达屋顶和楼梯。F20-01 前室 `5.4×4`、F20-02 可踏入采光庭 `5.4×2.4`、F20-03 后起居 `5.4×4.2`、F20-04 私密服务房 `5.4×2.8`，均为可探索空间。

D01 是唯一街门 `(0,-8,1.3)`、净 `1.2×2.6`；D02 是后段内门。W01 高侧窗、W02 庭院窗、W03 北窗的中心、尺寸和窗台均见 JSON。P01 收纳、P02 水罐、P03 床及 A01/A02 锚点不能压缩 `1.2m` 主路。路线固定为 `D01→F20-01→F20-02→F20-03→D02→F20-04→原路D01`；采光庭可踏入、不可作为贴图井。

坐标索引（Layout）：D02=`(0,4.1,1.25)`；W01/W02/W03=`(3,-5.7,2.8)/(3,-1.5,1.6)/(0,8,1.6)`；P01/P02/P03=`(-2.3,-5.5,0)/(2.2,-1.2,0)/(-1.4,5.8,0)`；A01/A02=`(0,-5.2,0)/(0,2,0)`。

接窄次巷，门外净空1.8m；不写最终巷宽、朝向、世界坐标或邻楼。6个实例可变天井偏左/右、门洞节奏、生活叙事与遮阳，不能增设商店柜台、工作台或不可达假层。

## 碰撞与验收

墙、屋面、收纳、水罐、床为简化实体碰撞；庭院地面及锚点无阻挡。1.8m/0.7m代理可走完整往返；验收层1、门2、窗3、楼梯0。

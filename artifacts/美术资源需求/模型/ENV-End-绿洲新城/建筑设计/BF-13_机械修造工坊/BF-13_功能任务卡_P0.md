# BF-13 机械修造工坊｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-13`；实例配额：2；建议分区：工坊/服务后街或临近货运支路，两座实例共享原型、可在 P1 做立面和庭院变体。

## 1. 建筑身份与层级限制

这是修理城市机械、制作零件的工作型建筑。识别来自工具台、零件架、可见传动导管和后门卸货，而不是夸张烟囱或工业地标。

- 维持中低层工坊尺度；不得以高塔、巨型车间门或大面积青绿发光取得地标感。
- 工作台、夹具、零件与 `DE-22` 货箱均属于作业边缘，不能被摆成穿过工区的迷宫。
- 两座实例均保持“前部可进入服务/接待 + 主作业间 + 后勤货运”功能，不允许一座退化为纯外观。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 服务/叙事 | 玩家可理解零件从后门进场、在主作业区修造、再由前部交付/查询的流向。 |
| 交互点 | 预留工作委托板或检修台锚点；玩家站位周围留出回身空间，作业台不越过主通道。 |
| 探索 | 至少有前部服务区、主作业间、后部零件库/后门三层信息。 |
| 事件边界 | 不绑定三选一事件、随机商人或 Boss；`DE-32` 若使用仅为工坊说明/独立候选点。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 前部接待/委托台 | 进入、交互、阅读修造信息 | 从街侧可见工作氛围，但柜台和展示不能封死进作业间的视线。 |
| F1-02 | 主修造间 | 台架、工具、机械修理 | 工作岛和 `DE-29` 护角沿边组织；中间保留连续人行主路。 |
| F1-03 | 零件库 | 可探索的分类存放与叙事 | `DE-22` 靠墙/分区摆放，和主要人行通道净距不小于 0.9m。 |
| F1-04 | 后勤装卸门廊 | 货运、设备进出 | 与前部人行流线分离；后门可作为返回街道的次出口，但不能压过正门。 |
| F1-05 | 可选夹层观察/工具架层 | 丰富作业纵深 | 仅在 P1 采用时才建；必须有正式楼梯、平台、栏杆和明确下行返回路线。 |

若采用夹层，夹层须能让玩家站立、通行和回转，不得只做高货架顶端。必须有正式可走楼梯；禁止把维护梯或货架攀爬面计入玩家路线。夹层边缘用连续 1.1m 栏杆，楼梯下和夹层下保持 2.4m 最小头部净空。

## 4. 玩家流线

```text
工坊街人行侧
  → 前部接待/委托台（F1-01）
  → 主修造间外侧人行带（F1-02）
  → 零件库探索（F1-03）
  → 可选正式楼梯 → 夹层（F1-05）→ 原楼梯返回
  → 后勤门廊（F1-04）
  → 货运支路 / 回到前部街侧
```

不交互也能完成一次可读的“接待—作业—零件—后勤”短探索。作业岛、货物和开启的门均不得切断玩家从任一深处区域返回两个出口中的至少一个。

## 5. 外部接街、货运与 DE 约束

- 主入口接工坊街人行侧；后门接货运支路或后巷，装卸区不得侵占主街和入口前净空。
- 可使用 `DE-13/15/16/19/22/29/30`；`DE-22` 仅靠墙、库位或装卸边，主路保持可读。
- 高处线缆托架最低边距地 2.4m；不在楼梯落点、交互锚点、门扇扫掠区放工具、箱体或能源柱。

## 6. P0 验收条件

- [ ] 两座 `BF-13` 均具备可进入的前部服务、主作业、零件库和后勤货运叙事。
- [ ] 作业物、工具台与货箱不封堵主通道、门洞、交互区或返回路径。
- [ ] 如有夹层，必须由正式楼梯到达，具备栏杆、头部净空和真实下行返回；维护梯不计入探索。
- [ ] 主入口与后门货运职责分离，货运不占主路。
- [ ] 未写入最终城市世界坐标，也不绑定商人、三选一事件或 Boss。

## 7. 确认后进入 P1 的工作

输出共享原型及两座实例变体的尺寸、夹层取舍、门窗/楼梯、交互锚点、固定 `DE` 坐标、布局 JSON 和设计图提示词。其后的 P2 白模必须用多色方块分明表示结构、作业设备、可走人行带、货运区、楼梯与栏杆，并实测室内及夹层可探索性。

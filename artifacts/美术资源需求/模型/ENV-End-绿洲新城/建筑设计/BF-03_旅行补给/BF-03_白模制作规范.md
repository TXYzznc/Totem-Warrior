# BF-03 旅行补给商店｜白模制作规范

> P2 必须同时遵守全局《06_彩色白模制作合同》。本文件是 BF-03 的 P1 补充真源，不创建场景、ProBuilder 对象或截图。

## 根节点与差异结构

```text
BLD_BF03_ROOT
├── GEO_Structure / GEO_Walkable / GEO_Function / GEO_Vertical
├── GEO_Entrances / GEO_InteractionPreview / GEO_RestrictedPreview
├── COL_Collision / COL_Anchors
```

根节点位于首层完成面中心；Layout `+Z`、正门 `-Y`，Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`。BF-03 必须保持 **14×12m 横向浅体量**和低矮双跨门廊：西跨 `D01` 是唯一街道门，东跨 `W01` 只是展示窗；不允许用两个绿色入口体块或两扇街道门把它误做成双入口。

## 通行、碰撞与验收

- `CB_Structure`、实体 `CB_Function` 进入 `COL_Collision`；`CB_Interaction` 与锚点进入 `COL_Anchors` 且无实体碰撞。
- 用 1.80m 高、0.70m 直径角色代理验证 `D01 → 前店 → 转换走道 → D03 → 东打包区 → D02`；验证 D04 的西储架探索和从所有可达点原路返回 D01。
- 主路径/打包环路 ≥1.8m，次通路 ≥1.2m，交易直径 3.0m，D01/D02 外侧净深 1.8m/1.2m 均不得被货物、门廊支撑或碰撞体占用。
- P2 截图应含正、背、左、右、轴测与室内剖切；本轮不输出图片、FBX、`.unity`、最终材质或世界坐标。

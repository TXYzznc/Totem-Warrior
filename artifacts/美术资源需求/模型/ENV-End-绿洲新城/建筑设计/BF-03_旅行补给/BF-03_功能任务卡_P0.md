# BF-03 旅行补给｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-03`；实例配额：1 座可进入实例；建议分区：商旅巷街（商业街界面，邻近主游逛路与可选货运侧巷）。

## 1. 身份与层级限制

这是四座随机商人商店之一，提供旅途中即时补给的可进入服务点。其街道身份应由清晰招牌、可见补给架、短遮阳与入口门洞共同建立；玩家从主游逛路可读到「补给」用途，但它不是地标。

- 随机商人只能在 `BF-02`～`BF-05` 间选择出现；未出现时，本建筑仍须可进入并有可阅读的补给整理叙事。
- 视觉体量、入口仪式感和发光强度均低于 `BF-01` 与 `BF-06`；禁止高塔、巨型悬挂标志、纹样环和大面积发光立面。
- 建筑以单层可探索空间为本 P0 目标；不得用封闭立面、交易窗口或纯货架背景替代真实室内。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 主要交互 | 随机商人锚点设置在前店补给柜台内侧，玩家在柜台外侧完成交易。 |
| 服务内容 | 表达旅行消耗品、容器、包具与路线补给的售卖/整理功能；不在本阶段定义物品数值或商品表。 |
| 非商人状态 | 柜台无 NPC 时仍可探索前店与后部补货间，并从清单、空容器和货运痕迹理解用途。 |
| 净空意图 | 柜台交互位、进门落脚位、主通路和后勤通路必须职责分离；P1 再锁定具体尺寸与碰撞。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 街侧门廊 | 识别、短暂停留、进店过渡 | 招牌/货箱/遮阳只能辅助识别，不能遮住门洞或主通路。 |
| 前店补给区 | 浏览、交易、读取补给信息 | 进门即可辨认柜台和补给陈列，货架不得封死柜台视线。 |
| 柜台交互区 | 随机商人交易 | NPC 锚点、玩家站位与排队/绕行空间可被清楚区分。 |
| 后部补货与整理间 | 可选探索、货物整理与后勤 | 与前店通过可见或可通行的内门连接；不能作为不可到达的布景。 |
| 货运侧门 | 货运叙事与短探索回路 | 连接次级货运巷，不取代街侧主入口。 |

## 4. 玩家流线

```text
主游逛路 → 街侧门廊 → 前店补给区 → 柜台交互
                               └→ 补给陈列 → 后部补货/整理间 → 货运侧门 → 次级货运巷
```

- 玩家可在不交易的情况下完成「进入—浏览—到后部—返回街道」的短探索。
- 返回路径至少包含原路经前门返回；货运侧门是第二条可选返回路径，不得成为主入口的视觉或功能替代。
- 本类型为单层：禁止以隐形坡道、跳跃落差、传送或不可交互梯子伪造第二层/后部可达性；若 P1 扩展为多层，须补写可用楼梯、各层入口、至少一条不经过封闭门的返回路径及楼梯禁区。

## 5. 外部接街与净空

- 正门接商旅巷街的主游逛路，侧/后门只接次级货运巷；不在本卡编造最终城市坐标、朝向或地块边界。
- 门前保留从街道看见招牌与进入门洞的视线，以及玩家进出、停步和绕过外摆的连续净空；外摆、货物和遮阳不得侵占主游逛路。
- 侧门周边保留货物搬运与玩家离开的通行面，避免与街侧交易停留区对撞。

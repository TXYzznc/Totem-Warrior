# BF-03 旅行补给商店｜详细设计案

> P1 尺寸真源：本文件与 `BF-03_楼层布局.json` 必须一致。设计图提示词只作视觉参考，不能修改结构。本轮不创建 `.unity`、白模、FBX、贴图或图片。

## 1. 身份、坐标与总尺度

- `BF-03`（TravelSupplyShop）是横向浅体量的旅行补给站：14m 宽、12m 深，正面由一张低矮**双跨遮阳门廊**组织。西跨容纳唯一街道主门 D01；东跨只框出 W01 补给展示窗，绝不是第二入口。
- 原点为首层完成面中心 `(0,0,0)`；Layout `+Z` 向上，街道正面 `-Y`；导入 Unity 使用 `Unity(X,Y,Z)=Layout(X,Z,Y)`。
- 外轮廓 `X=-7～7m`、`Y=-6～6m`；主体高 4.8m，室内净高 4.2m，屋面完成面 Z=4.8m，女儿墙顶 Z=5.9m。外墙 0.30m、内墙 0.20m、屋面 0.30m；封闭面积 168.0㎡，净可探索面积 150.7㎡。
- 严格单层：无夹层、楼梯、屋顶路线、跳跃捷径或假二层；体量、店招和发光均低于 BF-01/BF-06。

## 4. 流线与验收

- 可探索环路：`D01 → F1_FrontSupply → 交易/补给陈列 → F1_TransferAisle → D03 → F1_EastPacking → D02`；可由 D04 进入西储架区，并可由 D01 原路返回。
- 主通路与打包环路 ≥1.8m，次通路 ≥1.2m；D01/D02 外侧净深分别 1.8m / 1.2m，门扇不得扫入路径或锚点。
- 正面恒为 14m、侧面恒为 12m。南面只允许 D01 与 W01：双跨门廊表现为“入口跨＋展示跨”，不是两扇主门；东面只允许 D02。轴测应清楚显示浅横向体量、门廊、打包台和货运门。

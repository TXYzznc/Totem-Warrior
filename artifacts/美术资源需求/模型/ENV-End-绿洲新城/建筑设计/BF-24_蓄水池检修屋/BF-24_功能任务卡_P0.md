# BF-24 蓄水池检修屋｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-24`；实例配额：1；建议分区：蓄水池边缘、低位水庭或城市循环设施侧，不作为水景中心地标。

## 1. 建筑身份与层级限制

蓄水池检修屋是一个小型但完整可进入的水务设施：连接水体、检修口与半地下叙事。它必须让玩家真正下到可探索的检修层，而非只在地面放一个井盖。

- 地上部分保持低矮、克制，作为检修入口和水池边的功能标识；不建塔、不做巨大水殿或高亮景观。
- 半地下空间通过安全楼梯、明确平台和可见水池壁/管路表达；不可进入的深水、狭窄检修井与管道内部只作背景。
- `DE-14/15/16` 仅用于水务功能点；青绿状态光限于低亮读数或阀门标识。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 水务叙事 | 玩家可理解蓄水池与城市导水网络的连接，并看见检修层对水位/阀门的服务关系。 |
| 可交互点 | 预留水位计、阀轮或检修记录锚点，设在干燥可站立的平台，不能贴近深水边缘。 |
| 探索 | 至少有地上入口室、正式下行楼梯、半地下阀室和临水检修步道四类可走空间。 |
| 安全边界 | 深水、井口、管道内腔和狭窄维护孔不可计入探索；用可见栏杆/围护和水位边界表达限制。 |

## 3. 最小可探索室内与地下结构

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 地上检修前室 | 进入、读取水位/安全信息 | 入口不被导水槽、罐体或门扇阻塞，能清楚看见下行楼梯。 |
| B1-01 | 下行楼梯与落地平台 | 安全到达半地下层 | 为正式可走楼梯，非井梯；落地后有回身空间与明确返回方向。 |
| B1-02 | 阀室/读数台 | 水位交互、阀门叙事 | 设备沿墙组织，交互锚点位于干燥可走区。 |
| B1-03 | 临水检修步道 | 看见水池内壁、完成短探索环路 | 水面无实体碰撞；临水高差用连续 `DE-27` 栏杆保护。 |
| B1-04 | 次级回程廊/服务门 | 避免地下死角、回到前室或地上侧门 | 只在可安全连通时启用；不得通向无出口的维护孔。 |

地下层必须以正式楼梯连接。P1 需锁定均匀踏步、足够净宽、转向平台、2.4m 最小头部净空和连续 1.1m 栏杆；玩家从 B1 任意可走点可沿楼梯安全返回 F1-01。固定爬梯、井梯、阀门后维护孔、管道内腔和水池底部均不得作为玩家路径或替代出口。

## 4. 玩家流线

```text
蓄水池边人行步道 / 设施侧步道
  → 地上检修前室（F1-01）
  → 正式下行楼梯与落地平台（B1-01）
  → 阀室/读数台交互（B1-02）
  → 临水检修步道（B1-03）
  → 次级回程廊（B1-04，可选）/ 原楼梯返回
  → 地上前室 → 人行步道
```

下行后必须看见安全、可走的返回方向；不得让玩家因水池、设备围挡或关闭维护门而只能跳跃、攀爬或卡位返回。

## 5. 外部接街、维护与 DE 约束

- 接蓄水池边或低位水庭的设施侧步道；地上入口给人行使用，维护检修口/服务门转向非主路侧，且不写最终城市坐标。
- 可使用 `DE-02/04/13/14/15/16/20/27/28/30`。`DE-04` 不切断入口，`DE-28` 跨槽板只在保持连续步道时采用。
- 所有罐体、管线、能源柱、砂石和维护物都不能侵占入口、下行楼梯、落地平台、交互锚点或临水步道的净空。

## 6. P0 验收条件

- [ ] 建筑明确为 `BF-24` 蓄水池检修屋，地上入口、半地下阀室和水池检修关系可读。
- [ ] 玩家能经正式楼梯到达半地下层，在阀室和临水步道探索，并安全返回地面。
- [ ] 深水、井口、井梯、狭窄维护孔与管道内腔均未被计为可探索路线。
- [ ] 地下层的楼梯、平台、栏杆、头部净空、设备净空和返回路径均作为后续硬约束。
- [ ] 未写入最终城市世界坐标，也不绑定商人、三选一事件或 Boss。

## 7. 确认后进入 P1 的工作

输出地上/半地下尺寸与高差、楼梯和平台参数、可见水位边界、交互锚点、固定 `DE` 坐标、布局 JSON 与设计图提示词。其后的 P2 白模必须用多色方块区分地上结构、地下可走面、设备、深水/禁入区、楼梯、平台和栏杆，并验证地下可探索及安全回程。

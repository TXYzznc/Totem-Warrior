# BF-14 染料织物工坊｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-14`；实例配额：2；建议分区：带遮阳的小工坊街或小庭院边，两座实例共享原型、可调整晾晒朝向与院落关系。

## 1. 建筑身份与层级限制

这是将染料调制、浸染、晾晒与织物展示分开的可进入工坊。颜色服务于生产状态与织物识别，不能把整栋建筑做成霓虹广告。

- 体量为中低层工坊；入口以遮阳、低矮店招和局部织物展示识别，不使用高塔、巨拱或大型发光装置。
- 湿作业、清洗水和染缸应靠排水/庭院侧组织，展示与人行侧保持干燥、清晰。
- `DE-21` 仅用于染料相关区域；布幔 `DE-11`、遮阳帆 `DE-10` 必须保留入口、标识与头部空间。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 生产叙事 | 玩家应读出“颜料储存—湿作业—晾晒/织作—展示”的单向工序。 |
| 可交互点 | 预留样布/染料批次台或织机说明锚点；锚点前不可被染缸、晾架或箱体围死。 |
| 探索 | 至少进入展示前室、湿作业间、半室外晾晒庭三类空间。 |
| 事件边界 | 不绑定三选一事件、随机商人或 Boss；功能说明点可使用 `DE-32`，但不将其变成专属事件建筑。 |

## 3. 最小可探索室内与室外作业区

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 干区展示前室 | 进入、看样布、读取工坊功能 | 入口至后方工坊有清晰视线或引导，不以帘幕封死主要门洞。 |
| F1-02 | 染料/配液台 | 原料与批次叙事 | 使用 `DE-21`、`DE-20` 靠墙布置；台前留可达交互带。 |
| F1-03 | 湿作业间 | 浸染、漂洗、排水 | 湿区边界、低位导水与可走干区清楚；水面不做实体碰撞，染缸不封堵返回。 |
| F1-04 | 半室外晾晒庭 | 晾晒、织物色彩、短探索 | 以 `DE-10/11/26` 组织遮阳和筛视线；保留至少 1.8m 可走环路。 |
| F1-05 | 后勤洗涤/储料门 | 供料与维护 | 可连至服务侧或回到前室，不能成为堆满货物的死角。 |

本原型以单层加半室外庭院为基线，不要求屋顶或夹层。若 P1 增设二层晾晒台，只能使用正式楼梯，必须配置中间平台、连续栏杆、最小头部净空和返回路线；绳梯、挂布横杆、晾架及维护梯都不得计为玩家竖向通路。

## 4. 玩家流线

```text
遮阳工坊街 / 小庭入口
  → 干区展示前室（F1-01）
  → 染料配液台（F1-02）
  → 湿作业间（F1-03）
  → 半室外晾晒庭（F1-04）
  → 后勤洗涤/储料门（F1-05）
  → 服务侧返回街道，或回穿前室离开
```

玩家可不触发交互而完成一圈探索；晾晒布、染缸、导水槽和货物必须保持干区、湿区及出口之间的连续行走带。

## 5. 外部接街、湿作业与 DE 约束

- 主入口接带遮阳的人行工坊街；湿区排水与后勤门朝庭院/服务侧，避免将湿作业和卸货压到主路。
- 可使用 `DE-04/10/11/13/19/20/21/26/28`。`DE-04` 转角避开门前，跨槽板 `DE-28` 仅在需要且不切断主路时使用。
- 布幔最低边距地不得破坏玩家头部净空，且不可遮住安全出口、主入口或导向标识。

## 6. P0 验收条件

- [ ] 两座 `BF-14` 均读得出展示、配液、湿作业与晾晒的生产顺序。
- [ ] 干区、湿区和半室外庭院均可实际进入，湿作业物不封堵主路或出口。
- [ ] 庭院保留连续可走环路；若增加上层晾晒台，正式楼梯、栏杆、头部净空和回程为必需项。
- [ ] 遮阳、布幔、导水槽和货物遵守净空，不遮入口、不占主路。
- [ ] 未写入最终城市世界坐标，也不绑定商人、三选一事件或 Boss。

## 7. 确认后进入 P1 的工作

输出共享原型及两座实例变体的湿区/庭院布局、排水与通行边界、可选上层取舍、交互锚点、固定 `DE` 坐标、布局 JSON 与设计图提示词。其后的 P2 白模必须以多色方块清楚区分墙体、干区可走面、湿区边界/水体、设备、庭院环路、楼梯及栏杆，并验证可探索回路。

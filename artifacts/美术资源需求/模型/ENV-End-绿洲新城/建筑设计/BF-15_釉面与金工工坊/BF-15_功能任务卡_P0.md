# BF-15 釉面与金工工坊｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-15`；实例配额：2；建议分区：工坊边缘或服务后街，主入口与外侧卸货口分向布置。

## 1. 建筑身份与层级限制

这是兼具釉面烧制与金工整备的高温、重物工坊。热源、重台和出货是功能叙事，不是用来制造城市地标的装饰。

- 外观保持中低层、厚实且安全；不采用高塔、大面积喷焰、巨型烟囱或高亮青绿立面。
- 炉体、坩埚、金属台与重物储位沿耐热服务侧组织；玩家只接触可安全观看/互动的外圈。
- 两座实例共享安全流线原型；P1 可做炉位与卸货侧镜像，但不得改变“人行—安全观察—作业—卸货”的基本次序。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 生产叙事 | 玩家能读出原料进场、热作业、冷却/检验、成品出货的连续关系。 |
| 可交互点 | 预留订单板、冷却架或釉面样片锚点，设在安全观察带，不能贴近炉口或货运车道。 |
| 探索 | 至少有街侧接待/样片区、受控作业观览带、冷却检验间与后侧卸货区。 |
| 安全边界 | 高温和重物区以可见围护、留白和组织方式表达；不以透明假墙或不可见碰撞替代。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 前部样片/接待区 | 进入、查看釉面与委托 | 具有清晰的安全观察起点，避免使玩家直接踏入热作业区。 |
| F1-02 | 热作业观览带 | 观察炉体、金工台、生产叙事 | 通过栏杆、低墙或格栅与炉体隔离，保留连续可走人行带。 |
| F1-03 | 冷却检验间 | 交互、成品检查、探索 | 位于热区之后或侧方，可让玩家近看安全状态下的器件。 |
| F1-04 | 重料/成品装卸庭 | 卸货、出货、维护 | 货物靠边或指定库位，确保人行出口不经过重物盲区。 |
| F1-05 | 可选上部排烟检视廊 | 丰富高温设施纵向层次 | 若采用，必须用正式楼梯连接；不可把炉旁维护梯当作上行路线。 |

若设置上部检视廊，必须与热源危险面隔开，以正式楼梯、落地平台和连续 1.1m 栏杆连接；楼梯下与梁下最小头部净空 2.4m，且可沿原路返回或通向另一处可走出口。炉旁直梯、起吊链和外露管道绝不是探索路线。

## 4. 玩家流线

```text
工坊街人行侧
  → 前部样片/接待区（F1-01）
  → 热作业观览带（F1-02）
  → 冷却检验间交互（F1-03）
  → 可选正式楼梯 → 上部检视廊（F1-05）→ 返回
  → 重料/成品装卸庭外缘（F1-04）
  → 服务侧出口或回到前部街侧
```

玩家始终沿安全观察与人行带移动；炉口、重料转运线、装卸门扇扫掠区和热作业核心不得成为必经通路。

## 5. 外部接街、货运与 DE 约束

- 主入口面向工坊街人行侧；卸货口和重料庭接货运支路/服务侧，两类流线不能在入口前交叉堆叠。
- 可使用 `DE-13/15/16/19/22/27/29/30`；`DE-22` 与主要人行通道净距至少 0.9m，`DE-30` 远离可走屋顶边。
- 炉体周边、交互锚点、楼梯落点、门扇范围保持安全留白；不得用货箱、罐体或装饰塞满外侧卸货净空。

## 6. P0 验收条件

- [ ] 两座 `BF-15` 都能读出高温/重物的生产与安全分区，而非普通机械工坊的重复品。
- [ ] 玩家有从前部进入、沿安全观览带探索、到冷却检验与装卸庭外缘、再返回的完整流线。
- [ ] 高温核心、重物转运、货运与玩家主路物理分开，且无不可见的假安全边界。
- [ ] 若有上部检视廊，正式楼梯、平台、栏杆、头部净空及返程已列为硬约束；维护梯不计入探索。
- [ ] 未写入最终城市世界坐标，也不绑定商人、三选一事件或 Boss。

## 7. 确认后进入 P1 的工作

输出共享原型及两座镜像/变体的热区安全边界、卸货留白、可选上廊、门窗/楼梯、交互锚点、固定 `DE` 坐标、布局 JSON 和设计图提示词。其后的 P2 白模必须用多色方块分辨承重结构、玩家安全人行带、热作业禁入区、重货区、楼梯与栏杆，并验证全程可走可返。

# BF-19 屋顶花园住宅｜P0 功能任务卡

> 阶段：P0 功能定义；本卡不锁定尺寸、平面、局部坐标、白模或效果图。  
> 建筑编号：`BF-19`；实例配额：6 座可进入实例；建议分区：E. 工坊与居住坡巷（邻接次级巷、微路径与可选屋顶连路预留）。

## 1. 建筑身份与层级限制

这是把节水绿化、储水和家庭停留面放到屋顶的住宅。其辨识来自可探索、可维护的屋顶花园，而不是堆高植被或把每座住宅做成强地标。

- 首层是完整家庭生活单元；屋顶花园是此类型的必备、实际可达第二层探索面，而非远景贴片。
- 屋顶仅使用低矮花床、耐旱植物、储水罐、遮阳或小平台等生活构件；不得用大型棕榈、风塔或过强发光把住宅升级为城市地标。
- 与邻屋的屋顶连通只能是有限、可选的微路径预留；不依赖邻屋存在，也不允许用无栏杆跳跃缝隙替代正规路径。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 屋顶探索 | 玩家可从室内抵达屋顶，走访绿化、储水和休憩三类信息，并获得对坡巷的短视线变化。 |
| 家庭生活 | 首层至少表现起居与私密/服务两类空间；屋顶是生活扩展，不替代真实室内。 |
| 轻叙事 | 每个实例至少 1 个与灌溉、照料、收集或家庭休憩相关的环境叙事/轻交互候选点。 |
| 事件边界 | 可作为外部屋顶平台的通用事件候选空间，但不绑定为本建筑永久专属的三选一事件。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能与可达要求 |
|---|---|---|
| F19-01 | 巷侧门厅 | 可辨认的家庭入口和由街巷到室内的过渡。 |
| F19-02 | 首层起居区 | 可停留、可阅读家庭日常，并与竖向路径相连。 |
| F19-03 | 私密/服务房 | 至少一间可进入的卧室、工作角或服务空间。 |
| F19-04 | 屋顶楼梯与到达平台 | 室内连续楼梯的终点；不得以梯子、跳台或装饰坡面代替。 |
| F19-05 | 屋顶花园 | 真正可走的环游面，至少组织花床、储水与小停留点三类信息。 |

## 4. 玩家流线与竖向规则

```text
居住次巷
  → 门厅（F19-01）
  → 首层起居与私密/服务房（F19-02 / F19-03）
  → 室内楼梯与到达平台（F19-04）
  → 屋顶花园环游（F19-05）
  → 原楼梯返回首层 → 居住次巷
```

- 屋顶为必达探索面，必须有从首层出发的连续住宅楼梯、足够转身的平台、连续栏杆和无阻塞回程；不可达屋面、只供眺望的露台门或隔着矮墙的绿化不得计入。
- 屋顶花床、水罐、座椅和遮阳构件须与步行环分离；边缘、楼梯开口和高差处在 P1 按《04》落实 1.1m 连续防护与安全碰撞。
- 可选跨屋连桥/连廊仅在两端均为已验证安全屋顶时启用；否则在本实例中封闭为维护边界，玩家仍经原楼梯返回。

## 5. 接巷与外部净空

- 入口接居住次巷；门前需要清晰入户净空，不预设最终地块、屋顶邻接对象或世界坐标。
- 屋顶可朝微路径或内庭形成观察面，但绿植不得遮蔽入口识别；DE-06/07/09/20/23/26 可作为后续候选且不侵占楼梯、门洞和环游面。
- 屋顶连通预留不改变街巷主流线，且不作为屋顶花园唯一进出或逃生路径。

## 6. 允许实例变体

- 可变：花园在屋顶的偏置、花床/水罐/休憩点组合、楼梯位置、是否预留一侧有限连通、首层私密房用途。
- 不可变：首层真实生活空间、室内上屋顶楼梯、可走屋顶环游、屋顶绿化与储水/停留功能，以及独立返回地面的路径。
- 6 座实例至少使用三种屋顶生活主题（种植、储水维护、家庭休憩）；不得复用同一花床轮廓与同一入口—楼梯关系。

## 7. P0 验收条件

- [ ] `BF-19` 的屋顶花园为真实可探索空间，首层也有完整可走室内，非只有外观与屋顶装饰。
- [ ] 楼梯、平台、栏杆、屋顶边缘和返回路径满足结构安全要求；不可达绿化或屋面未计入探索。
- [ ] 家具、花床、水罐、绿植和遮阳不侵占门洞、楼梯、屋顶环游面或栏杆安全带。
- [ ] 任何屋顶连通均为可选、已防护的连接，本实例不依赖邻屋仍可闭环返回街道。
- [ ] 6 座实例具备可见差异但都保持屋顶花园住宅身份。

## 8. 确认后进入 P1 的工作

输出首层/屋顶平面、屋顶荷载与可走区域边界、楼梯踏步和栏杆数值、花园与储水锚点、可选连通的启用条件、接巷净空、实例变体矩阵、布局 JSON 和设计图需求提示词；P2 白模须以多种颜色方块清楚区分可走首层、楼梯、屋顶步行环、花床/设备、栏杆与不可探索屋面。

# BF-04 旧物零件商店｜详细设计案

> P1 施工真源：本文件与 `BF-04_楼层布局.json` 完全一致。设计图提示词仅作视觉参考，不能修改结构。本轮不创建 `.unity`、白模、FBX、贴图或图片。

## 1. 身份、坐标与尺度

- 资产 `BF-04`（OldPartsShop），1 座可进入实例；商旅巷街边缘。唯一街道主门 D01 接商业街；D02 是东侧货运巷服务出口，不作为第二街道门面。
- 原点为首层完成面中心 `(0,0,0)`；Layout `+Z` 向上、正门朝 `-Y`；Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`。所有坐标均为局部坐标，不写最终世界坐标。
- 总包围盒为 X 宽 14m（`-7..7`）、Y 深 14m（`-7..7`）；单层主体墙高 4.8m、室内净高 4.2m、女儿墙顶 5.9m；外墙 0.30m、内墙 0.20m、屋面 0.30m。
- 结构是明确的 L 形：南翼 `13.4×5.4m`，东翼 `4.2×8.0m`，两翼在东南角相接；西北内侧由低边界墙围出无遮顶的干燥检视小院。小院不是背景、装饰井或屋顶路线。
- D01 门外净深 1.8m；D02 服务出口外侧净深 1.2m。除 D01、D02 外，所有洞口仅在建筑内部或小院与室内之间连通。

- F1 完成面 Z=0m、层高 4.8m、室内净高 4.2m；严格单层，禁止夹层、楼梯、屋顶路线、跳跃捷径和装饰假二层。

- 小院西、北两侧为 0.30m 高边界墙与排水边；南侧经 D03 接前店，东侧经 D05 接东翼。干燥检视地面必须连续可走，不能被箱堆、屋檐柱、固定台或红色排水边误占为通道。
- D04 提供前店直通东翼的室内短支路；D03→小院→D05 与 D04 共同形成围绕小院的实际可探索环路。

## 4. 流线、碰撞与验收

- 主探索环路：`D01 → F1_FrontRetail → D03 → F1_DryInspectionCourt → D05 → F1_Turnover → D04 → F1_FrontRetail → D01`。玩家也可由东翼经 D02 返回货运巷；D02 只作服务出口，不新增街道主门。
- 小院的 `P02` 四周、D03/D05、D01、D02、柜台外侧站位均不得受固定物、柱或门扇侵占；主通道不小于 1.8m，东翼服务支路不小于 1.2m。
- 结构、边界墙、`P01`～`P03` 与 `R01`～`R02` 使用简化实体碰撞；锚点、`E02` 与 `CB_Interaction` 无实体碰撞。小院上空无屋面、无梁下净空问题，室内最低净高为 4.2m。
- 用 1.80m 高、0.70m 直径角色代理走通 D01、所有锚点、小院环路、D02 与原路返回。
- 验收：本文件的包围盒、L 形翼、小院、区域、洞口、窗、锚点、固定物、禁区与 JSON 一致；不得加入 P0 外功能、世界坐标或系统数值。

# BF-04 旧物零件｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-04`；实例配额：1 座可进入实例；建议分区：商旅巷街边缘（邻接工坊方向或货运巷）。

## 1. 身份与层级限制

这是四座随机商人商店之一：一处处理旧物、替换零件与可回收器件的低调店面。它应让玩家读到「检索、翻找、修补」的功能，而非被误判为工坊、仓库或 Boss 前置建筑。

- 随机商人只可在 `BF-02`～`BF-05` 选择；无人值守时仍必须保留可走可看的旧件分类和拆检叙事。
- 可借邻近工坊/货运巷建立实用感，但不得承载加工生产，也不得与 `BF-13`～`BF-16` 的工坊、仓库功能混淆。
- 为弱地标单层商店；禁止高耸设备塔、危险工业烟囱、巨型门洞、强光机械核心与类似 BF-06 的压迫性入口。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 主要交互 | 商人锚点在前店检索柜台内，玩家在外侧交互。 |
| 服务表达 | 表达旧物鉴别、零件分类、替换件检索与回收交换；不在本阶段定义配方、修理系统或掉落。 |
| 可选探索 | 玩家可走入拆检台/分类架周边和后部周转间，读取零件流转关系。 |
| 安全边界 | 重件、工具与堆叠箱不得压缩主通道、柜台站位或任一返回出口。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 巷街门面 | 从商业街识别旧件店 | 入口、低调标识和少量分类旧件可见，不能把街道变成堆料场。 |
| 前店检索区 | 浏览、交易、分类阅读 | 柜台可见，分类架形成可绕行的探索边，而非迷宫。 |
| 拆检工作台区 | 旧物检查叙事 | 与交易区分开，可近看但不承担真实工坊生产。 |
| 后部周转间 | 货物暂存、可选探索 | 与前店有实际内门连接，并可到达后勤侧门。 |
| 后勤侧门 | 接货/离开 | 面向货运巷，形成可选短回路。 |

## 4. 玩家流线

```text
商旅巷街 → 巷街门面 → 前店检索区 → 柜台交互
                            └→ 拆检工作台区 → 后部周转间 → 后勤侧门 → 货运巷
```

- 主线可直达柜台；探索支线允许玩家先查看分类架和拆检台，再回到柜台或继续到后门。
- 至少一条返回路径经原前门，另有经后勤侧门到货运巷的可选返回；两者均不得被货箱、外摆或交互物阻断。
- 本类型为单层：禁止设置只能观赏、不可行走的夹层零件架；若后续确认多层，必须采用真实可走楼梯，标明楼梯可达楼层、回程路径，并禁止以攀爬货架、跳跃或传送替代楼梯。

## 5. 外部接街与净空

- 街侧正门接商旅巷街，后勤门接货运巷或朝工坊方向的次级巷；不锁定总图坐标。
- 门前只布置少量能说明分类用途的旧件，必须保留进店、转身和从主路读取入口的净空。
- 后勤装卸面与玩家返回面分开，避免堆料遮挡后门或压到公共通行区。

## 6. P0 验收条件

- [ ] `BF-04` 为 1 座可进入旧物零件商店，随机商人规则正确。
- [ ] 前店检索、柜台、拆检叙事、后部周转和两条返回路径完整。
- [ ] 无人商人时仍存在独立探索意义；未误做成工坊、仓库或战斗场地。
- [ ] 商业街入口、货运侧门和外摆/堆料净空职责明确。
- [ ] 未锁定坐标、尺寸、具体交易内容、三选一事件或 Boss 内容。

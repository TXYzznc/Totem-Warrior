## 0. 真源规则

1. 本文与 `BF-01_楼层布局.json` 共同构成尺寸和位置真源。
2. 设计图仅用于确认轮廓、材质、配色、气氛与视觉层级。

## 1. 建筑身份与功能

### 1.1 核心身份

晖纹纹身庭是绿洲新城唯一的固定纹身店，也是全图主要地标。建筑需要同时表达：

- 可亲近、明亮、仍在正常运作的未来生活设施。
- 虚构绿洲城市的拱廊、风塔、天井和水庭文化。
- 活性颜料只用于纹身功能、能源接口和少量状态提示。
- 远看靠双风塔与悬挂纹样环识别，近看靠工作台、颜料封存与纹样展廊识别。

### 1.2 游戏功能

- 固定纹身师交互。
- 纹身工作台与纹身展示。
- 三入口探索：正门、东西侧门、北侧后门。
- 首层与二层完整环路。
- 屋顶花园与后巷转移。
- 不绑定商人、三选一事件或 Boss 功能。

## 3. 建筑体块

建筑采用“首层闭合环院、二层 U 形三翼”的组合体块围绕中央水庭。首层由南部入口厅、东西两翼和北翼完整包围水庭；只有二层取消南部中央体块，形成西—北—东三翼 U 形。任何外观图或模型都不得把北翼删成直通水庭的大开口。

### 3.3 侧立面投影规则

- 左、右侧正交视图必须使用完全相同的比例、基线和建筑总长度。
- 首层可见轮廓按建筑总深度32m表现：南部入口厅、首层侧翼端部和连续地台共同形成完整首层基座。
- 二层侧翼长度为26m，范围为 `Y=-10～16m`；首层侧向轮廓范围为 `Y=-16～16m`。两层在北侧（背面）端点 `Y=16m` 对齐，首层只在南侧（正面）比二层向前突出6m。不得把二层居中放在首层上，也不得让首层在南北两端同时突出。
- 每个侧立面只显示一座近侧风塔。风塔投影中心位于上层外墙 `Y=1m` 与 `Y=11m` 两扇窗之间，即 `Y=6m`。

正面三重尖拱是“一门两窗/壁龛”的立面构图，不是三扇等规格入口：中央拱对应唯一的 D-01 主门，净宽4.8m、净高6.8m；左右两拱对应 W_F1_S_01 与 W_F1_S_02 的窗或浅壁龛，不得绘制成可通行的大门。

中央 D-01 使用独立抬高的尖拱门洞立面：外框宽8.0m、外框最高点 `Z=8.2m`、外凸深度1.2m，位于南墙 `Y=-16m`。它高于首层主体屋面 `Z=4.8m`，但低于二层主体/屋顶完成面 `Z=9.0m`。该门洞上方是入口厅的双高空间与承重立面，不增加南侧中央二层房间、楼板或屋顶路线；二层仍严格是西—北—东三翼 U 形。左右侧视图必须在正面端显示这段最高 `Z=8.2m` 的前门洞立面。

## 14. UV、贴图与 LOD

### 14.1 UV

- UV0：Trim Sheet 与可平铺表面，可有明确设计的平铺/镜像。
- UV1：唯一烘焙/光照 UV，不得重叠。
- 目标环境 Texel Density：256 px/m。
- 2K 贴图 UV 岛间距：不小于16 px。
- 硬边应与 UV 缝一致。

### 14.2 贴图

| 贴图集 | 分辨率 | 通道 |
|---|---:|---|
| 建筑共享 Trim Sheet | 2048² | D/N/ORM |
| BF-01 独特纹样与遮罩 | 2048² | D/N/ORM/E |
| 小型标识与纹样环 | 1024² | D/N/ORM/E |

所有贴图为2次幂。程序化 Noise、Color Ramp 或 Bump 必须烘焙后再进入导出材质。

### 14.3 LOD预算

不含可复用装饰和家具：

| LOD | 三角面预算 | 处理原则 |
|---|---:|---|
| LOD0 | ≤120,000 | 保留主轮廓、拱门、双塔与近景结构 |
| LOD1 | ≤60,000 | 移除小倒角和次级表面分段 |
| LOD2 | ≤30,000 | 简化拱廊内饰和栏杆细节 |
| LOD3 | ≤12,000 | 只保留首层闭合环院、二层U形三翼、双塔和悬环剪影 |

## 15. 碰撞与导航

- 墙体、楼板、楼梯、栏杆、水盆和大型固定家具使用简化碰撞。
- 装饰叶片、悬挂旗帜、水面和悬环不提供碰撞。
- 门洞碰撞不得侵入洞口。
- 主通道净宽≥3m；次级通道净宽≥1.8m。
- 角色参考：高1.8m、直径0.7m。
- 所有楼梯以连续坡面或简化阶梯碰撞实现，不逐级创建复杂碰撞网格。

## 16. Blender MCP 搭建顺序

1. 设置场景单位为 Metric，Unit Scale=1。
2. 创建1.8m角色尺度代理 `REF_Character_180cm`。
3. 按JSON建立首层、二层和屋顶占位矩形。
4. 先搭建墙体、楼板、门洞、窗洞和楼梯白盒。
5. 检查主入口、交互净空与三条出入路线。
6. 建立双风塔与悬环，检查120m剪影。
7. 替换为模块化正式网格。
8. 添加固定物件、锚点 Empty 与装饰实例。
9. 创建LOD和简化碰撞。
10. 检查法线、N-gon、非流形、UV和变换。
11. 保存源 `.blend`；导出前在副本中应用对象变换，源文件保留非破坏性修改器。

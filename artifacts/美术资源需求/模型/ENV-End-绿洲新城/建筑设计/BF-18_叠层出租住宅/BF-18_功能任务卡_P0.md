# BF-18 叠层出租住宅｜P0 功能任务卡

> 阶段：P0 功能定义；本卡不锁定尺寸、平面、局部坐标、白模或效果图。  
> 建筑编号：`BF-18`；实例配额：10 座可进入实例；建议分区：A. 入城拱廊的居住过渡段（与次级巷、错层门台相接；最终地块待总图确定）。

## 1. 建筑身份与层级限制

这是供多个小住户短租或长租的紧凑叠层住宅，以“上下住户入口错开、彼此不互相穿堂”为身份核心。它是日常人口密度的表达，不是商业旅馆或高层公寓地标。

- 至少有两个明确居住单元；下层和上层住户的入户节点必须错开，不能让通往上层的楼梯穿过下层住户的主要起居空间。
- 层数以首层加一层为主；可局部采用半层错台，但不做塔式连续加层、外置悬空楼梯秀场或夸张公共门厅。
- 上层入口、窗洞和小阳台保持居住尺度；无商店招牌、旅馆接待功能、随机商人或固定事件绑定。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 多户观察 | 玩家能读出至少两种住户的居住痕迹，且两者的入口、门牌或生活物有可读差异。 |
| 垂直探索 | 上层为实际探索目标之一；楼梯提供短暂的视线变化与分支，而不是仅供外观。 |
| 叙事点 | 每个实例至少在一个住户单元或共享平台设置 1 个环境叙事/轻交互候选点。 |
| 非商业边界 | 不放置交易柜台、店面橱窗或旅馆前台；三选一事件只可在外部公共候选空间发生。 |

## 3. 最小可探索室内

| 区域编号 | 区域 | 功能与可达要求 |
|---|---|---|
| F18-01 | 下层住户门前/前室 | 从巷道进入下层单元，不与上楼主踏步冲突。 |
| F18-02 | 下层起居单元 | 至少一处可走的起居/休息空间，含生活叙事信息。 |
| F18-03 | 独立楼梯与平台 | 从公共或半公共前室到上层的连续竖向路径；不得借道下层私室。 |
| F18-04 | 上层住户前室/小平台 | 错开下层门，作为上层住户到达点与安全转身点。 |
| F18-05 | 上层起居单元 | 实际可进入的上层居住空间，不可仅做门后封闭背景。 |
| F18-06 | 共用服务角 | 可为储水、洗衣、短晾晒或小型共享桌；不占楼梯和疏散路径。 |

## 4. 玩家流线与竖向规则

```text
坡巷/次级巷
  ├→ 下层前室（F18-01）→ 下层起居（F18-02）→ 原入口返回
  └→ 独立楼梯与平台（F18-03）→ 上层前室（F18-04）
       → 上层起居（F18-05）→ 楼梯返回 → 巷道
```

- 上层必须可从独立楼梯抵达并返回地面；不可把外立面窗后、封死阳台、不可操作梯子或仅用于采光的挑台算入上层探索。
- 楼梯起点与下层入户门错位，平台不得被门扇、家具体块或共用水罐占用；P1 必须按《04》闭合踏步、头部净空和住宅楼梯净宽。
- 上层屋顶如采用，只能在已有上层安全楼梯继续连通或另设安全楼梯时开放；开放屋顶需有连续栏杆和明确回程，不开放则作为非探索屋面并在 P1 标注。

## 5. 接巷与外部净空

- 对接错层居住坡巷或普通次级巷，建议用下层凹入门廊与上层侧向楼梯入口制造错开，但不写最终坐标、道路朝向或相邻实例编号。
- 巷侧至少保留清晰的下层入户与上层上楼辨识；楼梯落地、门前和转身位不得被 DE-20、晾晒物或花坛堵塞。
- 可设置小型共享门前停留处，但它不能吞并街巷主通行，也不承担三选一事件专属功能。

## 6. 允许实例变体

- 可变：楼梯在左/右侧或内嵌位置、上下层门的相对高差、住户数量为 2–3 户、共享服务角类型、窗洞与遮阳构成。
- 不可变：至少两个可读住户、上下入口错开、上层真实可达、下层不被上楼流线穿越。
- 10 座实例应轮换楼梯朝向、住户叙事与共享设施；不得整排复用同一外立面、同一门位和同一上楼路径。

## 7. P0 验收条件

- [ ] `BF-18` 被清晰识别为多户叠层出租住宅，而非旅馆、商铺或单户院宅。
- [ ] 下层和上层均具有可进入生活空间，且上楼不穿越下层主要入户/起居空间。
- [ ] 上层与任何开放屋顶均有符合安全要求的连续楼梯、平台、栏杆和返回地面的路径。
- [ ] 入口、平台、住宅主通道和楼梯无装饰、家具或门扇冲突。
- [ ] 10 座实例在叙事与立面/楼梯构成上有差异，同时保留叠层出租原型。

## 8. 确认后进入 P1 的工作

输出各单元边界、错层关系、楼梯与平台数值、可达屋顶声明、门窗/栏杆、住户叙事锚点、接巷净空、实例变体矩阵、布局 JSON 和设计图需求提示词；P2 以多种颜色方块区分下层、上层、公共楼梯、平台、可走屋顶与不可探索屋面，并验证住户流线互不冲突。

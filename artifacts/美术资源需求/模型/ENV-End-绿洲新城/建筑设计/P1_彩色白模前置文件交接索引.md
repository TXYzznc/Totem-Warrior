# 绿洲新城｜BF-03～BF-24 彩色白模前置文件交接索引

> 状态：已完成 P1 前置文件，待后续 Unity ProBuilder 白模执行使用。范围明确排除 BF-02，且本索引不代表已创建任何 `.unity` 场景或正式模型。

## 交接规则

1. 每个类型的 `详细设计案.md` 与 `楼层布局.json` 是尺寸、位置、洞口、楼梯和锚点真源；`设计图需求提示词.md` 只作视觉参考。
2. 真实 P2 白模必须遵循 [06_彩色白模制作合同](../06_彩色白模制作合同.md)，使用七类 `CB_*` 颜色和 Collection；必须采用 1.8m 高、0.7m 直径角色代理验收。
3. 所有坐标均为建筑本地坐标：首层完成面中心为原点、`+Z` 向上、正门朝 `-Y`、Unity 映射为 `Unity(X,Y,Z)=Layout(X,Z,Y)`。未指定城市世界坐标。
4. 任何尺寸、房间、洞口或楼梯变更必须同步修改该建筑的详细设计案与 JSON；不得用提示词或效果图反向覆盖真源。

四家店均严格单层，仅有一处街道主入口 `D01` 与一处服务/后勤出口 `D02`。差异来自体量、入口构图、半室外阈值与可探索流线；不得以塔楼、二层、假楼梯或巨型标识取代这些差异。

## 实例化边界

- 同一类型的多个实例可在不改变内部真源的前提下调整立面饰件、庭院/花坛组合、货物摆放、店招、楼梯左右镜像（仅在详细案允许时）及环境叙事。
- 不得取消规定的街道入口、主通路、可探索房间、正式楼梯、栏杆、交互净空或返回路线。
- BF-19 的邻屋顶连接只是默认封闭的地图落位预留，不属于本体探索路线；最终总图确认后才能开启。

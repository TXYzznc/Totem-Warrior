# BF-06 Boss 专属建筑｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不设计具体 Boss、战斗机制、敌人、奖励或数值，也不锁定尺寸、平面、白模、效果图或城市世界坐标。
>
> 建筑编号：`BF-06`；实例配额：1 座可完整进入实例；建议分区：边缘特殊区（与主城保持可读联系，以高差、门洞或风沙设施完成氛围转场）。

## 1. 身份与层级限制

`BF-06` 是唯一的 Boss 专属建筑，也是城市的强地标之一；它必须是可完整探索和可运行的内部建筑，绝不能是封闭立面、远景道具或只留战斗入口的壳体。

- Boss 只能绑定 `BF-06`；随机商人、纹身师与三选一事件均不得移入本建筑。
- 强地标性来自完整可读的入口、前厅与主空间关系，不等同于堆叠特效、无意义高度或不可到达的塔体。
- 本卡仅规定空间承载战斗前、主空间和撤离的条件；不得预设具体 Boss 战、攻击模式、谜题、刷怪、奖励或剧情结局。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 入口与转场 | 从边缘特殊区进入，完成主城日常氛围到特殊区的可读转场。 |
| 战斗前厅 | 为准备、读取环境、校准方向和进入主空间提供安全缓冲；不是战斗主空间的一部分。 |
| 主空间 | 预留给后续 Boss 玩法的完整可进入空间；P0 不定义任何战斗内容。 |
| 后勤/撤离 | 与入口及主空间形成独立、可理解的后勤与撤离组织，避免把返回流线压在战斗入口上。 |
| 返回 | 玩家不论是否触发后续战斗内容，均可经可用路径返回室外。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 外部抵达台/门前缓冲 | 读入口、完成氛围转场 | 保持主城方向可读，不把最终地块坐标写死。 |
| 入口门厅 | 进建筑、方向确认 | 入口不能直接把玩家丢入未来战斗核心；应有可停步、可转身的过渡。 |
| 战斗前厅 | 准备、环境叙事、进入主空间 | 与主空间有明确边界，且可从前厅识别返回方向。 |
| Boss 主空间 | 未来战斗承载 | 整体可进入、可绕行、可返回；本 P0 不布置 Boss、武器或战斗机制。 |
| 后勤/撤离通道 | 结构叙事、离开 | 与主入口流线分离，不得仅以封闭门或坠落捷径表示。 |
| 室外返回出口 | 回到边缘特殊区 | 必须是真实可达出口，接回外部可通行面。 |

## 4. 玩家流线与楼层规则

```text
主城可读连接 → 外部抵达台 → 入口门厅 → 战斗前厅 → Boss 主空间
                                          └→ 后勤/撤离通道 → 室外返回出口 → 边缘特殊区
```

- 入口、战斗前厅、主空间、后勤/撤离路线必须功能分区清晰；主空间后不得把唯一返回强制穿过不可控的入口拥堵点。
- 至少提供一条从主空间经撤离通道回到室外的连续返回路径；可另保留经前厅原路离开的路径。两条路径在 P1 中需验证不被门扇、摆件或碰撞阻塞。
- 本建筑允许后续发展为多层，但 P0 不锁定层数。只要采用多层，所有层间连接必须是实际可走楼梯（公共流线按全局公共楼梯规范），每层均能回到入口或撤离出口；禁止以跳台、单向坠落、攀爬、不可用装饰梯、传送或战斗触发动画替代楼梯及返回路径。

## 5. 外部接街与净空

- 建议位于边缘特殊区，和主城通过可读的主游逛连接、转折高差、门洞或风沙设施关联；本卡不得编造最终世界坐标或精确高差。
- 门前须保留抵达、停步、转身、读取入口与安全返回的连续空间；禁止以大规模障碍、坠落或纯装饰封住建筑出入口。
- 后勤/撤离出口应接回可通行外部空间，与正门抵达缓冲区避免相互挤压；不将出口伪装成不可返还的剧情门。

## 6. P0 验收条件

- [ ] 明确 `BF-06` 是唯一 Boss 专属、1 座完整可进入建筑；未指定任何具体 Boss 战内容。
- [ ] 入口、前厅、主空间、后勤/撤离与室外返回出口均已定义，且入口/主空间/撤离流线分离。
- [ ] 主空间至少有一条连续、可实现的撤离返回路径；多层时必须以真实楼梯满足全层返回。
- [ ] 未把建筑做成封闭立面、战斗房间壳体或只可单向进入的死路。
- [ ] 不挪用随机商人、纹身师或三选一事件功能，未编造最终总图坐标。

## 7. 确认后进入 P1 的输出

输出功能分区平面、层数方案与全部真实楼梯/返回路径、入口/前厅/主空间/撤离出口坐标、碰撞和净空、布局 JSON、设计图需求提示词及结构验收项；后续白模以多色方块明确结构、前厅、主空间、后勤、楼梯和撤离路径，但不加入具体 Boss 战内容。

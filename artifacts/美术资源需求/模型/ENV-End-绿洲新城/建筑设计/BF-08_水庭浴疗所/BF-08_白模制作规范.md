# BF-08 水庭浴疗所｜白模制作规范

> 后续 P2 必须遵守全局《06_彩色白模制作合同》。仅作 P1 前置，不创建 Unity 场景、ProBuilder 对象或截图。

## Collection 与命名
```text
BLD_BF08_ROOT
├── GEO_Structure / GEO_Walkable / GEO_Function / GEO_Vertical
├── GEO_Entrances / GEO_InteractionPreview / GEO_RestrictedPreview
├── COL_Collision / COL_Anchors
```
根对象为首层完成面中心；Layout +Z、正门 -Y，Unity 映射 `Unity(X,Y,Z)=Layout(X,Z,Y)`，对象命名 `CB_<语义>_<对象ID>`。

# BF-08 水庭浴疗所｜P0 功能任务卡

> 阶段：P0（功能定义，待确认）；本卡不锁定尺寸、平面、白模、效果图、水循环技术或城市世界坐标。
>
> 建筑编号：`BF-08`；实例配额：1 座可进入实例；建议分区：水庭公共区（接公共步行面与浅水庭/导水环境）。

## 1. 身份与层级限制

水庭浴疗所是恢复与日常服务建筑，以干区、湿区围绕小水庭的连续探索建立功能。它应呈现明亮、安静、可亲近的水庭公共性，而不是医疗堡垒、封闭澡堂背景或高科技设施地标。

- 必须明确干区与湿区的功能及通行边界；不能把水面、浴池或蒸汽做成看得见但不可接近的舞台。
- 青绿色活性颜料只作为低强度功能提示，不覆盖主立面；整体依旧以暖白石材、浅砂、遮阳与水庭为主。
- 本 P0 采用单层环庭组织，不设必须上楼的功能；禁止以水池落差、跳台或传送伪造楼层/捷径。

## 2. 玩法功能

| 项目 | P0 规则 |
|---|---|
| 服务承载 | 预留恢复/生活服务交互，不在 P0 定义恢复数值、状态效果或 NPC。 |
| 干湿分区 | 进入、接待、更衣/准备属于干区；浴疗、水庭边、清洗/休憩属于湿区或湿区边缘。 |
| 环庭探索 | 玩家可沿安全步行面绕小水庭完成浏览，并能从任一主要区段返回入口。 |
| 安全可读 | 水边、湿区门槛、桥/步道与服务点需在 P1 明确碰撞、栏护和不可侵占净空。 |

## 3. 最小可探索空间

| 区域 | 必须承载的功能 | P0 空间要求 |
|---|---|---|
| 水庭入口门廊 | 从公共区抵达、读服务入口 | 不遮挡公共步行面，能看到接待/导向。 |
| 干区接待与准备区 | 服务交互、转换、方向确认 | 接待不占用进门与环庭主通路。 |
| 小水庭与环庭步道 | 环境核心、可选探索 | 水体四周至少形成连续、可实际步行的探索段，不把水庭封成远景。 |
| 湿区浴疗边 | 恢复服务与环境叙事 | 与干区有清楚转换，玩家可到达服务点而不穿过不可走水面。 |
| 安静休憩角 | 停留、观察水庭 | 连接环庭步道，不能成为堵住回路的尽头。 |
| 维护侧门/导水服务边 | 维护叙事与第二离开 | 可接服务面或公共边缘，保持与玩家主入口可区分。 |

## 4. 玩家流线

```text
水庭公共步行面 → 入口门廊 → 干区接待/准备区 → 湿区浴疗边
                                            ↓                 ↓
                                       环庭步道 ← 小水庭 → 安静休憩角
                                            └→ 维护侧门/服务边 → 外部服务面
```

- 玩家先在干区明确服务方向，随后可选择进入湿区、沿环庭步道探索或在休憩角停留；任何选择都能回到入口。
- 返回路径至少包括经干区与正门回公共步行面；维护侧门可作为第二离开路径，但不得迫使玩家穿越水体、湿滑不可走面或封闭服务区。
- 本建筑为单层环庭：禁止以无护栏高差、可跳跃水池、不可攀爬装饰梯或传送取代正规通行；若 P1 确认增设二层/屋顶平台，必须增加实际可走楼梯、每层回到正门或侧门的连续路径，并禁止把楼梯口放在湿区危险边缘。

## 5. 外部接街与净空

- 正门接水庭公共区的步行面，维护侧门接导水/服务边；不指定最终城市坐标或水体边界。
- 入口外留出从桥、步道或公共区辨认服务入口和安全停步的空间，不让座椅、绿植、导水槽或装饰堵住门洞。
- 水边、桥/步道接口与维护门周边均须在 P1 落为可通行或明确阻挡的边界，不能以视觉水面替代碰撞设计。

## 6. P0 验收条件

- [ ] `BF-08` 为 1 座可进入水庭浴疗所，干区、湿区、小水庭和环庭探索职责明确。
- [ ] 玩家可从入口到达服务点、绕水庭探索，并经正门或服务侧门返回外部。
- [ ] 水体不被当作可走捷径或背景，后续可落地安全碰撞与通行边界。
- [ ] 本 P0 单层方案没有伪楼层；若后续加层，楼梯与返回规范已明确。
- [ ] 未锁定数值、技术设施、城市坐标、三选一事件或 Boss 内容。

# BF-16 商旅仓库｜P0 功能任务卡

> 阶段：P0 功能定义；尚未锁定尺寸、平面、白模、世界坐标或效果图。  
> 建筑编号：`BF-16`；实例配额：2；建议分区：商旅街后侧、驿运支路或市集边缘的货运侧，两座实例共享仓储原型。

## 1. 建筑身份与层级限制

这是商旅货物暂存、分拣与转运的可进入仓库。高货架和夹层服务于可探索的货运逻辑，绝不能将建筑做成封死的箱子堆或压过城市商街。

- 保持低到中层仓储体量；不采用堡垒式门楼、高塔或高亮招牌。
- 箱笼、货捆和移动货物是分区内容而非墙；至少一条从入口贯通至深处/后门的人行路线始终可读。
- 两座实例均保留前部登记、主仓分拣、后部装卸和可选夹层的功能骨架；P1 可做货品与开口方向变体。

## 2. 玩法功能

| 项目 | 规则 |
|---|---|
| 城市叙事 | 读出旅货从登记、分拣、暂存到后门转运的顺序。 |
| 可交互点 | 预留货签登记台或分拣清单锚点，锚点前与侧方均有回身净空。 |
| 探索 | 至少探索登记前室、主仓人行带、货架间支路、后部装卸口；高货架/夹层不得只有外观。 |
| 事件边界 | 不绑定三选一事件、随机商人或 Boss；`DE-32` 仅可作为物流说明点或独立候选点。 |

## 3. 最小可探索室内与竖向结构

| 区域编号 | 区域 | 功能 | 空间要点 |
|---|---|---|---|
| F1-01 | 登记前室 | 进入、货签交互、方向提示 | 从入口可读出人行主带与后部货运方向。 |
| F1-02 | 主仓人行带 | 贯通行走、看见分拣过程 | 宽度按后续规范锁定；不得被 `DE-22` 或可移动箱笼堵断。 |
| F1-03 | 货架间探索支路 | 近看货物、环境叙事 | 支路两端至少一端接回主仓人行带，避免形成无回头空间的死角。 |
| F1-04 | 后部装卸门廊 | 货运出入、返回出口 | 货物靠装卸边，人与货车/推车动线分离。 |
| F2-01 | 可走夹层分拣廊 | 俯看仓储、提供第二层探索 | 必须用正式楼梯抵达，不能把货架顶、吊装梁或维护梯当作楼层。 |

本原型建议采用可走夹层或高货架旁的二层分拣廊，以满足仓库纵向探索。F2 必须有正式楼梯、转向/会车平台、连续 1.1m 栏杆和 2.4m 最小头部净空；从 F2 至 F1 的原路回程必须不受货物摆放影响。维护梯与吊装设施不得计入探索路线。

## 4. 玩家流线

```text
商旅人行街 / 市集侧入口
  → 登记前室（F1-01）
  → 主仓人行带（F1-02）
  → 货架间探索支路（F1-03）
  → 正式楼梯 → 夹层分拣廊（F2-01）
  → 原楼梯返回主仓
  → 后部装卸门廊（F1-04）
  → 服务货运巷 / 回到前门
```

货物可形成支路选择但不得制造无法辨认的迷宫；夹层、后部装卸口与前部入口之间至少保留一条明确且持续可用的人行返程。

## 5. 外部接街、货运与 DE 约束

- 入口接商旅人行侧，装卸门接后侧货运支路；装卸开门、停靠和货物等待区不得占主街。
- 可使用 `DE-10/13/19/22/25/27/29`；`DE-25` 若在临街出现只能作小型点缀，前方仍留至少 1.8m 通行带。
- `DE-22` 靠墙、货位或装卸边摆放，与主要人行通道净距至少 0.9m；不在楼梯起落点堆货。

## 6. P0 验收条件

- [ ] 两座 `BF-16` 都有登记、主仓人行、货架支路、后部装卸和可走夹层的可探索功能。
- [ ] 至少一条完整人行路径贯通入口、深处和出口；货物、门扇与货运不封堵该路线。
- [ ] 夹层只能由正式楼梯抵达，具备平台、栏杆、头部净空和稳定回程；维护梯/货架不计探索。
- [ ] 人行入口与后勤货运分向组织，主路和楼梯落点没有箱笼堆占。
- [ ] 未写入最终城市世界坐标，也不绑定商人、三选一事件或 Boss。

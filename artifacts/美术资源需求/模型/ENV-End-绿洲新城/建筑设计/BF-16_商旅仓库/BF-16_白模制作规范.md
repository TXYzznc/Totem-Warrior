# BF-16 商旅仓库｜白模制作规范

> P2 交接，引用 `../../06_彩色白模制作合同.md`；夹层与 ST01 是强制真实可达结构。

## 颜色、命名与层级

`CB_Structure #A9B0B7` 为仓壳、货架边界、楼板/栏杆；`CB_Walkable #D4B56A` 覆盖登记、主带、支路、装卸门廊和夹层；`CB_Function #4F93D1` 为登记台、货架/货位；`CB_Vertical #9569C9` 为 ST01 与中台；`CB_Entrance #5FBF76` 为 D01-D04；`CB_Interaction #42C6C6` 为登记/分拣锚点无碰撞；`CB_Restricted #D95C5C` 为货运/吊装禁区。

使用 `BLD_BF16_ROOT` 与九个 Collection：`GEO_Structure/GEO_Walkable/GEO_Function/GEO_Vertical/GEO_Entrances/GEO_InteractionPreview/GEO_RestrictedPreview/COL_Collision/COL_Anchors`；对象如 `CB_Vertical_ST_F1_F2_01`、`CB_Walkable_F2_SortingGallery`、`CB_Restricted_Loading`。局部 Scale=1、Rotation=0。

## BF 特化验收

- 角色走 `D01→登记→主带→货架支路→ST01→夹层→ST01→装卸→D02`；箱货距主带 ≥0.9m，支路 ≥1.2m，不得踩货架。
- ST01 为 20 级×0.1725m=3.45m、踏面 0.30m、净宽 1.8m、平台 1.8×1.8m、头净高 2.4m、栏杆 1.1m；夹层边缘连续栏杆并有碰撞。
- 墙/货架/栏杆/梯有碰撞，锚点/吊物无碰撞；核验四门、二窗、一梯、两锚点和两实例镜像。

## Blender 使用优先级

1. 尺寸、标高、开洞、楼梯、交通与物件位置：以楼层布局 JSON 和详细设计案为准。
2. 结构关系与可达性：以 Unity 白模、室内剖切、楼梯/局部核验截图和结构决策记录为准。
3. 材质、构件分缝、风格化装饰与氛围：以五视角效果图为参考。
4. 效果图若与白模或 JSON 冲突，必须服从 JSON 与白模；不得根据单张效果图自行增生门窗、楼层、楼梯或附楼。

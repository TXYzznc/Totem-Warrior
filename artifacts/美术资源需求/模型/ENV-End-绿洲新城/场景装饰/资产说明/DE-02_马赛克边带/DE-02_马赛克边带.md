# DE-02｜马赛克边带

## 1. 资产定位

这是绿洲新城可复用的“马赛克边带”环境装饰模块，默认尺度为 **0.3×2×0.02m**。资产必须可独立实例化，不绑定特定建筑或街区坐标。

## 2. 设计与建模要求

- 体现绿洲新城的异域绿洲、克制未来设施和活性颜料科技语言。
- 可在材质磨损、边缘形态、颜色分区和局部附件上做变体，但不改变默认占地、连接接口和通行要求。
- 明确接地、支撑、连接和拆分关系，不出现无法解释的悬空结构。
- 建议拆分为主体、功能/连接件、装饰件和碰撞件。

## 3. 场景使用

推荐位置：门槛、墙脚、水边、广场边缘。

作为引导，不大面积铺满 组合时优先与相同功能或同一空间层级的 DE 资产搭配，必须服从门洞、楼梯、交互净空、主通道和镜头规则。

## 4. 六视图生成要求

生成 6 张独立纯色背景图：front 正面、rear 背面、left 左面、right 右面、top 正交俯视、axon 轴测。每张图只显示本资产，不添加角色、街道、建筑、场景地面、文字或水印。视图必须展示完整轮廓、厚度、接地和连接部位；俯视图重点显示占地与拼接边界，轴测图重点显示体块与结构关系。

## 5. 建模检查清单

- [ ] 六视图为同一版本、同一尺度和同一造型。
- [ ] 正面方向与局部坐标已固定。
- [ ] 默认占地与上级装饰目录一致。
- [ ] 可碰撞实体与无碰撞区域已区分。
- [ ] 没有把场景地面、墙体或其他 DE 类型烘焙进资产。
- [ ] 适合制作 prefab，并可通过变体参数复用。

## 6. 变体设计

本资产需要补齐模块化路径节点。所有变体保持带宽、厚度、纹样尺度和端点网格一致。

- **变体_1｜直线节奏款**：连续直线段，调整内部几何纹样节奏，适合长距离重复铺设。
- **变体_2｜九十度转角款**：同规格边带形成清晰 90° 转角，内外角收边完整，可与原型直线段无缝连接。
- 转角只用于路径转折；禁止通过缩放直线模块伪造转角。

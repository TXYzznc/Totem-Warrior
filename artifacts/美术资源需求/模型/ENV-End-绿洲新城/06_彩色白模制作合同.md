# 绿洲新城｜彩色白模制作合同

> 适用范围：BF-03～BF-24 后续的 Unity ProBuilder 白模制作。本文是 P2 执行合同，不是实际白模场景；本变更不创建 `.unity`、ProBuilder 对象或截图。

## 1. 输入与真源

1. 每个建筑只可依据其已确认的 P0、详细设计案和布局 JSON 搭建；效果图/提示词不具有尺寸修改权。
2. Blender 布局使用公制、`1 unit = 1m`、`+Z` 向上、正门朝 `-Y`；导入 Unity 时遵循 `Unity(X,Y,Z)=Layout(X,Z,Y)`。
3. 所有白模必须使用 1.8m 高、0.7m 直径的角色代理复核入口、房间、楼梯和回程。

## 2. 强制颜色语义

| 标识 | 语义 | 白模颜色 | 用途与限制 |
|---|---|---|---|
| `CB_Structure` | 承重外壳、墙、楼板、女儿墙 | 中性灰 `#A9B0B7` | 仅表示结构边界；不替代可走地面。 |
| `CB_Walkable` | 可走地面、走廊、平台 | 砂黄 `#D4B56A` | 必须连续覆盖所有可探索路径。 |
| `CB_Function` | 房间功能体块、固定大型工作区 | 蓝 `#4F93D1` | 用于阅读空间职责；不得封死通路。 |
| `CB_Vertical` | 可走楼梯、坡道、楼梯平台、屋顶出入口 | 紫 `#9569C9` | 多层/半地下建筑的每段正式垂直交通必须使用。 |
| `CB_Entrance` | 街道门、室内门、出口和门洞净空 | 绿 `#5FBF76` | 用绿色框/体块表达可通行洞口；不得被结构碰撞侵占。 |
| `CB_Interaction` | NPC/交互锚点、玩家站位、交互净空 | 青 `#42C6C6` | 可用半透明体块；不得加入实心阻挡碰撞。 |
| `CB_Restricted` | 危险区、维护禁区、水面、不可占用净空 | 红 `#D95C5C` | 必须与可走地面明显区分；不把危险/水面伪装为可走区域。 |

颜色仅用于白模结构阅读，正式美术阶段必须回归《01_地图与美术风格规范》的材质与配色规则。

## 3. 结构、探索与碰撞

- 每个建筑须存在街道入口、至少一个真实室内探索区域、可回到街道的路径；后勤出口仅在详细案指定时可作为第二返回路径。
- 多层、屋顶或半地下空间须提供连续 `CB_Vertical` 楼梯/坡道和平台；装饰梯、井梯、爬梯、传送或跳跃落差不得计入探索路径。
- 楼梯需使用连续坡面或简化阶梯碰撞；门洞、主通道、楼梯平台和交互净空不得被家具、装饰或结构代理占用。
- `CB_Interaction`、水面和悬挂装饰不应产生实体碰撞；墙、楼板、栏杆、水盆边沿和固定大型工作台须在后续创建简化碰撞。

## 4. 命名与层级

```text
BLD_<BF编号>_ROOT
├─ GEO_Structure
├─ GEO_Walkable
├─ GEO_Function
├─ GEO_Vertical
├─ GEO_Entrances
├─ GEO_InteractionPreview
├─ GEO_RestrictedPreview
├─ COL_Collision
└─ COL_Anchors
```

- 每个色彩类别的对象名以相应 `CB_` 前缀开始，例如 `CB_Vertical_ST_F1_F2_01`。
- 源对象使用局部原点、Scale=`1,1,1`、Rotation=`0,0,0`；P1 布局 JSON 是尺寸/位置真源。
- 白模验收截图至少包含正、背、左、右、轴测五视图和一张室内/剖切视图；截图属于后续 P2，不属于本次交付。

## 5. P2 最低验收

- [ ] 审查者不读效果图即可从颜色辨识结构、可走面、功能区、楼梯、入口、交互净空和禁区。
- [ ] 角色代理可通过所有规定的门洞、楼梯、走廊和可探索房间，并能按规定返回街道。
- [ ] 所有垂直空间都通过正式楼梯/坡道连通；不存在只用于外观的不可达“假楼层”。
- [ ] 红色禁区未被误作为玩家通道；青色交互区无永久碰撞物。
- [ ] 白模的房间、洞口、楼层和锚点与该建筑 P1 真源一致。

# 绿洲新城｜尺度、生产流程与验收规范

## 1. 统一尺度

| 项目 | 规范 |
|---|---:|
| 标准角色身高 | 1.80m |
| 角色肩宽参考 | 0.55m |
| 角色活动直径参考 | 0.70m |
| 世界单位 | Unity/Blender 均按 1 单位 = 1m。 |
| 建筑原点 | 各建筑首层完成面中心为局部原点；详细设计案必须写明正门朝向与坐标轴。 |

## 2. 通用建筑模块

| 项目 | 常规值 | 使用说明 |
|---|---:|---|
| 首层层高 | 4.8m | 公共建筑/商店/住宅首层的默认值；地标可另行提高并在详细案说明。 |
| 首层室内净高 | 4.2m | 包含梁、灯具、吊挂物后的最低可用净高应单独核验。 |
| 标准上层层高 | 4.2m | 二层及以上默认结构层高。 |
| 标准上层室内净高 | 3.6m | 居住、档案、展示、办公等上层空间适用。 |
| 外墙厚度 | 0.30m | 外立面、保温/装饰和碰撞模型需要在详细案中统一。 |
| 内墙厚度 | 0.20m | 房间分隔墙默认值。 |
| 楼板/屋面厚度 | 0.30m | 含结构与面层的默认控制值。 |
| 常规模块步进 | 0.6m | 门窗、柱距、家具和 Trim 可按 0.6m 或其倍数组织。 |

## 3. 楼梯、门、窗与通道

| 构件 | 标准规格 | 验收要求 |
|---|---|---|
| 公共楼梯净宽 | 1.8m | 双向通行；栏杆内侧净宽不得缩水。 |
| 住宅/次要楼梯净宽 | ≥1.2m | 不能成为唯一高流量入口。 |
| 每级踏步进深 | 0.30m | 同一跑内必须一致。 |
| 单级高度 | 0.17–0.175m | 同一跑内误差为 0；总级数与层高在详细案中闭合。 |
| 中间平台 | 宽度不小于楼梯净宽，建议 1.8×4.0m | 转向、开门与人物会车不冲突。 |
| 最低头部净空 | 2.4m | 楼梯下、梁下、拱下均要核验。 |
| 栏杆高度 | 1.1m | 屋顶、二层内廊、桥和水边高差均适用。 |
| 主公共入口 | 建议净宽 2.2m、净高 2.8m | 地标主门可例外，必须有独立尺寸表。 |
| 内部门 | 建议净宽 1.4m、净高 2.5m | 门扇开启不得侵占主通道。 |
| 标准外窗 | 1.5×1.6m，窗台 0.8m | 转角/墙端净距不少于 0.6m。 |
| 宽景窗 | 2.4×1.6m，窗台 0.8m | 仅用于需要展示/采光的首层或公共房间。 |
| 高侧窗 | 1.8×0.8m，窗台 2.2–2.4m | 用于背街、设备、隐私房间；不替代疏散门。 |
| 主通道 | ≥1.8m | 商店、公共建筑、Boss 前厅和主探索环路。 |
| 次通道 | ≥1.2m | 住宅、后勤、支路；不得同时承担主要战斗/会车。 |

## 4. 详细设计案与提示词必须分离

### 4.1 详细设计案：施工真源

每栋建筑都必须包含：

- 每层长×宽、面积、层高、净高、墙/楼板厚度；
- 房间、门、窗、楼梯、固定家具的编号、尺寸、坐标、朝向；
- 玩家入口、交互锚点、碰撞、通行和维护净空；
- 资产/装饰编号与摆放规则；
- Blender/Unity 的坐标约定和验收清单。

### 4.2 设计图需求提示词：视觉参考

每栋建筑另建同名提示词文件，用来生成正、背、左、右、轴测和必要室内视图。提示词必须写清：

- 风格锚点、材质、配色、建筑身份与禁止项；
- 与详细设计案一致的层数、体块、门窗数量和关键位置；
- 正交视图统一比例/基线、轴测观察角度和画面留白；
- “效果参考而非尺寸真源”的说明。

不能把 AI 图中的偶然透视、附加窗洞、临时家具或错误结构直接作为开发依据。

## 5. 建筑生产流程

1. 锁定功能、实例数量和建筑编号。
2. 写详细设计案，先完成可走通的平面和高度关系。
3. 输出布局 JSON / Unity 白模；先校验正交立面与轴测体块是否一致。
4. 再依据提示词生成效果图；出现结构矛盾时，回到详细设计案/白模修正，而不是让效果图决定结构。
5. 完成 Blender 正式模型、碰撞、LOD、材质与 Unity 导入验证。

## 6. 最低验收清单

### 6.1 布局与功能

- [ ] 实例已被计入 67 座可进入建筑配额，且拥有真正可用入口。
- [ ] 门、楼梯、走廊和交互区无碰撞/家具/装饰侵占。
- [ ] 随机商人仅使用 BF-02～BF-05；纹身师仅使用 BF-01；Boss 使用 BF-06。
- [ ] 三选一事件未被绑定为某一建筑的永久专属功能。

### 6.2 尺寸与结构

- [ ] 每层层高、净高、长宽面积、门窗和楼梯均有数值，不依赖效果图猜测。
- [ ] 楼梯总高度 = 踏步数 × 单级高度；平台、栏杆和头部净空满足规范。
- [ ] 正/背/左/右正交图共享比例和基线；侧立面长度与平面投影一致。
- [ ] 楼层退台、塔楼、女儿墙、门洞等高度关系与白模/JSON 一致。

### 6.3 美术与可读性

- [ ] 暖白石材为主，青绿活性颜料仅作为功能性点缀。
- [ ] 商店的识别强度低于 BF-01 和 BF-06；城市没有无理由的重复地标。
- [ ] 每条主街具有导向、遮阳、绿化、水体或生活叙事中的至少一种有效内容。
- [ ] 装饰遵守 `DE` 编号、禁区与组合规则，未把道路、入口和关键视线堵死。

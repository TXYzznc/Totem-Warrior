# 后续地图地貌设计（待确认）

## 已知范围与共同规则

正式地图模板目前有三张：`AI_RUINS`、`ALIEN_HIVE`、`VIRUS_SWAMP`。本文件只定义后续美术生产与 PCG 选择所需的地貌合同；在用户确认前，不修改正式 `PCGMapGenerator`、`TotemMapService` 或既有地貌 catalog。

- 每个地貌固定 8 张独立的 256×256 全不透明图块变体。
- 每个**允许出现**的地貌交界固定 6 张透明环境装饰；装饰不是过渡拼图，不负责遮住完整边界。
- 未列出的地貌对在后续 PCG 中禁止相邻，因此不生产无效的装饰资源。
- 图块一律由绘图模型绘制；程序只选图、摆放和渲染，不生成纹理、岸线或融合边。
- 已确认的 `grass`、`water` 及 `grass|water` 六张装饰被保留，作为病毒沼泽的草甸与暗水资源，不重复生产。

## 地图 1：AI_RUINS（AI 遗迹）

视觉关键词：冷灰蓝石材、氧化金属、低饱和蓝青冷却液、少量阴湿苔痕；保留暗黑手绘像素风，不做科幻 UI、发光网格或高频机械细节。

| 地貌 ID | 角色 | 行走 | 视觉内容 |
|---|---|---:|---|
| `ruin_floor` | 主地表 | 是 | 破碎的深灰蓝混凝土/石板块面，细裂纹与磨损边缘。 |
| `service_metal` | 次地表、路线复用 | 是 | 暗枪灰氧化金属板，局部铆钉和凹槽，但不形成规则大网格。 |
| `reclaimed_growth` | 自然侵入区 | 是 | 石缝苔藓、压低的耐阴草与湿斑；不出现完整草坪。 |
| `coolant_water` | 危险水域 | 否 | 深蓝青冷却液、缓慢涟漪与少量黯淡反光；不画岸线。 |

允许相邻对：`ruin_floor|service_metal`、`ruin_floor|reclaimed_growth`、`ruin_floor|coolant_water`、`service_metal|coolant_water`、`reclaimed_growth|coolant_water`。

装饰方向：碎石与断缆、金属锈片、苔藓丛、漏液管口、积水边漂浮碎屑；均为局部物件，不能画成整条金属/水岸拼图。

## 地图 2：ALIEN_HIVE（异形巢穴）

视觉关键词：暗褐几丁质、病紫半透明膜、焦黑树脂、低面积荧黄酸液；材质可读但保持克制，避免拟真脏器与血腥写实。

| 地貌 ID | 角色 | 行走 | 视觉内容 |
|---|---|---:|---|
| `hive_chitin` | 主地表 | 是 | 低饱和褐金、暗橄榄的几丁质块面与短节纹。 |
| `hive_membrane` | 柔性覆盖层 | 是 | 暗紫褐半透明膜与压痕，不要镜面湿滑高光。 |
| `resin_crust` | 硬化巢体 | 是 | 焦黑/琥珀树脂硬壳，断裂的块面与少量包裹纹。 |
| `acid_pool` | 危险液体 | 否 | 暗绿黄酸液、迟缓气泡和稀疏荧光点；不画岸线。 |

允许相邻对：`hive_chitin|hive_membrane`、`hive_chitin|resin_crust`、`hive_chitin|acid_pool`、`hive_membrane|acid_pool`、`resin_crust|acid_pool`。

装饰方向：卵囊残壳、短骨刺、树脂滴柱、小簇菌丝、酸液边气泡；不要用大面积肉膜把两个图块“融合”起来。

## 地图 3：VIRUS_SWAMP（病毒沼泽）

视觉关键词：暗青绿、腐褐泥炭、低饱和紫黑污染与克制黄绿孢光；这是当前草地—水域试制的扩展主题。

| 地貌 ID | 角色 | 行走 | 视觉内容 |
|---|---|---:|---|
| `grass`（已有） | 主草甸 | 是 | 已确认的暗绿草地。 |
| `mud` | 湿软次地表 | 是 | 腐褐泥炭、浅脚印洼陷与湿润块面；不画成河岸。 |
| `water`（已有） | 暗水域 | 否 | 已确认的青蓝绿水面。 |
| `corruption` | 病毒污染地 | 是 | 紫黑菌苔、枯萎草根和零星低亮孢点；不出现强烈荧光大色块。 |

允许相邻对：`grass|water`（已有）、`grass|mud`、`grass|corruption`、`mud|water`、`mud|corruption`、`corruption|water`。

装饰方向：枯芦苇、腐木、泥泡、菌簇、污染根须、漂叶；仍然只在边界附近稀疏摆放。

## 生产规模与顺序

确认后新增：

| 类别 | 数量 | 画布 |
|---|---:|---|
| 新地貌 | 10 种 × 8 变体 = 80 张 | 10 张 4×2 单地貌源画布 |
| 新交界对 | 15 对 × 6 装饰 = 90 张 | 15 张 3×2 装饰源画布 |
| 已复用试制资源 | `grass`、`water`、`grass|water` | 不重复生成 |

生产顺序建议：先完整制作 `VIRUS_SWAMP` 的 `mud`、`corruption` 与 5 对装饰，复用已确认草地—水域的视觉基线；再制作 `AI_RUINS`，最后制作 `ALIEN_HIVE`。每个主题完成后先进入独立预览，再开始下一个主题，避免一次性引入 170 张未经目测的资源。

## ADDED Requirements

### Requirement: 元素状态使用弱、标准、强三层
同元素施加 MUST 将目标提升一层并刷新该元素衰减计时；强层再次施加只刷新计时。每经过 3 秒 MUST 消耗一层，弱层被消耗后元素消失；每层 MUST 保存来源并按 FIFO 顺序消费。

#### Scenario: 连续施加同元素
- **WHEN** 火元素在衰减前连续施加三次
- **THEN** 状态依次成为弱、标准、强
- **AND** 每次施加都将下一次衰减时间重置为 3 秒

### Requirement: 异元素施加触发反应并消耗层级
目标已有元素时施加不同元素 MUST 触发对应反应；新施加元素被消耗，已有元素降低一层，已有弱层在反应后消失。第一阶段反应 MUST 为终止节点且不得生成新的事件。

#### Scenario: 弱火受到冰元素
- **WHEN** 带弱火的目标被冰元素命中
- **THEN** 触发火冰反应
- **AND** 火与本次冰均从目标状态中消失

### Requirement: 火冰雷元素具有独立特性
火元素灼烧 MUST 每 0.5 秒结算一次并按弱/标准/强使用 1/1.25/1.5 倍层级系数；冰元素 MUST 分别造成 12%/20%/28% 减速；雷元素在目标受到有效直接伤害时 MUST 每 0.5 秒至多触发一次放电，优先命中最近的同阵营次要目标，无次要目标时 50% 伤害回到自身。

#### Scenario: 雷目标附近没有同阵营单位
- **WHEN** 带雷元素目标受到有效直接伤害且放电间隔已满足
- **THEN** 放电对该目标自身造成正常放电值的 50%

### Requirement: 三种元素反应使用冻结的第一阶段规则
火冰“热冲击” MUST 造成 0.6 倍枪械身体命中伤害；火雷“过载” MUST 对中心造成 0.35 倍、3 米内其他目标造成 0.25 倍并产生轻击退；冰雷“停滞” MUST 使目标 2 秒内直接伤害降低 20%。反应组合与施加顺序无关。

#### Scenario: 先冰后火与先火后冰
- **WHEN** 两个相同目标分别以相反顺序形成火冰反应
- **THEN** 两次均结算热冲击 0.6 倍身体命中伤害

### Requirement: 反应归因同时保留触发者和辅助来源
反应导致击杀时最终击杀 MUST 归触发不同元素的参赛者；反应伤害成果 MUST 同时给触发者和被消费已有元素层的来源记录相同数值，并显示“间接造成 X 点元素伤害”，实际目标生命只能扣减一次。

#### Scenario: 两名队友共同触发反应击杀
- **WHEN** A 施加已有元素、B 施加异元素并由反应击杀目标
- **THEN** 淘汰归 B
- **AND** A 与 B 的成果各增加相同的间接元素伤害值

### Requirement: 同时触发效果按优先级队列依次结算
一次行为产生的所有合法效果 MUST 先收集再排序：主动技能臂 100、闪避 90、移动 80、头部弱点 70、枪械臂 60、躯干 50；相同优先级 MUST 用 match seed 派生的确定性随机顺序。玩家第一阶段没有主动技能效果，但 100 优先级槽保留。

#### Scenario: 同一命中触发头部和枪械臂
- **WHEN** 有效直接伤害同时满足头部弱点与枪械臂条件
- **THEN** 头部事件先于枪械臂事件结算
- **AND** 枪械臂只在本次伤害实际生效时进入队列

### Requirement: 结算间延迟只影响表现
队列事件之间可配置短暂演出延迟，但模拟结果、随机序、合法性和统计 MUST 与延迟为 0 时一致；系统不得设置全局反应冷却。

#### Scenario: 对比快速与正常演出模式
- **WHEN** 相同 seed 和输入分别以 0 延迟与默认延迟运行
- **THEN** 最终生命、状态、击杀、统计和队列顺序完全一致

## chroma_key 使用情况

- 仅在**中间步骤**用于初步剥离 mockup 绿幕外圈（`tools/chroma_key_tool/chroma_key.py --threshold 80 --soft-edge 30 --despill 0.5`）
- **最终 10 张 sprite 中没有一张需要保留 chroma_key 输出** —— 因为：
  - 面板背景改成程序化生成（避免 mockup 里 UI 元素残留）
  - 小组件全部从面板**内部**裁出，源像素已经是 `#1A1C2E` 主色底，不带绿幕污染
  - SliderHandle 程序化生成，无原图来源

## 与 layout 状态清单的差异（MVP 决策）

`prefab-layout.md §状态清单` 原本要求 10+ 张状态变体图（CloseButton normal/hover/pressed 3 张、Slider 3×2=6 张、Radio 2×3=6 张、Button 3×2=6 张、KeyBindButton disabled 3 张）。

**用户 MVP 决策**：只拆 default 态，运行时靠 Selectable ColorTint 切态。故本次拆分只交付 10 张 default sprite，非 30+ 张。

## 阶段 5 (client-unity) 交接备忘

1. **PanelBg** 是纯净底图，UI 内容全部靠 Prefab 层级独立节点拼装（不重复渲染）
2. **SliderFill** 是 200×12 单色金色带 —— **建议用 Image.Type = Sliced（9-slice）** 或 **Tiled**，避免 Unity Slider 内部 Fill Area 拉伸时失真；Border 建议 4/4/4/4
3. **SliderTrack** 175×12，同样 **Sliced 9-slice**，Border 8/8/0/0（左右圆角）
4. **KeyBindButton_Disabled / CancelButton / SaveButton** 底图含中文字（源 mockup 特性），Prefab 层级里应额外覆盖 TMP_Text 节点，字号按 layout（KeyBind 16，Cancel/Save 18），Alignment = MiddleCenter；底图设 Image.Type = Sliced 拉伸到 layout 目标尺寸（200×44 / 160×52 / 200×52）
5. **RadioCircle_Selected** 是"圆圈+内点"整合图，若要动态切显/隐内点，改用 layout 里的 `RadioCircle_Normal` + 独立 `RadioDot`（14×14 金色圆）方案，此时可用 `RadioCircle_Normal.png` 作外圈，动态生成或另外提供 `RadioDot.png` 作内点；MVP 简化直接把整合图作为 selected 态即可
6. **SliderHandle 32×32** 已带描边和高光，Image.Type = Simple，Preserve Aspect = true
7. **CloseIcon_X** 48×48（含白色 X，无独立 button 底），Prefab 里 CloseButton 底可以留纯色透明 Image + 上叠 CloseIcon_X

# 3D PvPvE 美术垂直切片

## Why

现有 2.5D 原型已验证刺青构筑的基础玩法，但无法承载可进入建筑、空间对抗和身体刺青的 3D 可读性。需要先制作独立的美术垂直切片，验证明亮卡通化美术是否能与 PvPvE 撤离构筑玩法统一。

## What changes

- 以 FPS 为主、可切越肩第三人称的视觉方向制作离线切片。
- 建立一名局部功能性机械改造人类角色、六处纹身 UV 区和统一美术语言。
- 制作一栋可进入的未来生活街区建筑战斗单元及统一灯光。
- 制作可操作的纹身工作台 UI 原型。
- 不在本变更中实现 20 人联机、完整经济或正式地图。

## Success criteria

一段 60 秒可玩体验可连续展示街区移动、进入建筑、NPC 遭遇、工作台纹身和第三人称刺青展示，且角色、建筑、UI、灯光与 VFX 具备一致的明亮活性颜料风格。

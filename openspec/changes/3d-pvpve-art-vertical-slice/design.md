# 设计基线

## 全局美术

- 明亮、卡通化的活性颜料世界。
- 角色为局部功能性机械改造人类；机械部件只框住而不遮挡六处刺青区。
- 第一版仅一套中性基础身体、统一骨骼与固定刺青 UV 区。
- UI 为全局 PC 键鼠纹身工作台，不依赖具体地图主题。

## 地图切片

- 地图主题：遭受活性颜料泄漏的未来生活街区。
- 建筑须提供外部接近、至少两条进入路线、室内视线切断、转移路线、另一出口和一个资源或 PVE 节点。
- 地编以越肩第三人称为基准，第一人称为可切换沉浸视角。

## 非目标

- 不为低配性能提前压缩美术效果，但资产需保持模块化、可 LOD、可烘焙灯光和可复用材质。
- 不迁移现有 2.5D 正式地图，也不实现真实多人网络。

# WPN-FP-001 民用模块化巡防步枪设计说明

> 仅用于设计交接。在完整设计包获批前，不得制作模型、贴图、材质或 Prefab。

## 1. 身份定义

| 字段 | 约定 |
|---|---|
| 资源 ID | `WPN-FP-001` |
| 暂定名称 | 民用模块化巡防步枪 |
| 建议逻辑 key | `weapon.rifle.patrol.v1` |
| 玩法角色 | 第一阶段唯一枪械；枪械行为由玩法数据负责 |
| 世界观来源 | 由市政周界安全与维护平台改装而来，用于受控巡防 |
| 识别目标 | 15 米距离下明确是步枪；近看又明确不是现实产品 |

武器应当像清洁的民用基础设施部门配发设备：容易维护、操作安全、视觉平静，并由可替换的方盒式密封模块构成。它不是突击步枪复刻品，不得借用现实厂商可识别的机匣、枪托、弹匣或瞄具结构。造型必须优先考虑制作成本，以少量方盒、梯形和楔形体块组合出识别度，而不是依赖高面数连续曲面。

## 2. 轮廓

### 2.1 主要体块

1. **方盒式上部脊线**：由两到三个切角长方体从后部外壳连续衔接到护木，形成主要水平识别线。
2. **一体化折面桥架**：从上部脊线中切出低矮提把 / 瞄具桥，并保留面积较大的矩形负空间开口。
3. **受保护的维护核心**：深色内结构只通过梯形侧面开口和半透明弹匣 / 状态窗露出。

### 2.2 比例

| 尺寸 | 目标值 |
|---|---:|
| 总长 | 0.78 米 |
| 含握把总高 | 0.22 米 |
| 主体最大宽度 | 0.075 米 |
| 机匣前方可见枪管长度 | 0.34 米 |
| 枪托 / 后部外壳长度 | 0.21 米 |
| 护木长度 | 0.25 米 |

使用中等长度枪管和紧凑后部外壳。上轮廓由连续方盒与切角构成；下轮廓由握把与略微前倾的半透明弹匣 / 状态模块打断。瞄具桥内部必须保留醒目的矩形大开口，使其在远距离仍然可辨。

### 2.3 各视角要求

- **侧面**：长条封闭脊线、一个前向楔形、一个向下握把体块，以及唯一明亮嵌件——半透明检查窗。
- **顶部**：狭窄的中央维护通道，两侧有保护肩部；不得使用密集附件导轨。
- **正面**：切角方形护木包围低分段枪管核心；真正的圆形只保留在必要的枪口孔洞。可用不对称维护锁扣增加辨识度，但不得改变瞄准线。
- **第一人称**：瞄具桥、上部肩线与状态窗可见；枪管和护木不得遮挡准星或屏幕下方中央的目标区域。
- **第三人称**：机匣、枪管和枪托保持三个可读体块；细小锁扣和贴花可以在远处消失。

## 3. 功能部件拆分

| 网格 / 节点 | 用途 | 是否必须 |
|---|---|---|
| `WPN_FP_001_Root` | 原点与全局缩放根节点 | 是 |
| `Body` | 封闭式上部与后部外壳 | 是 |
| `BarrelCore` | 工作金属枪管 | 是 |
| `Handguard` | 切角方盒式前部防护外壳 | 是 |
| `GripMain` | 主手接触握把 | 是 |
| `MagazineStatus` | 带检查窗的可替换下部模块 | 是 |
| `SightBridge` | 一体化瞄具 / 提把桥 | 是 |

以下锚点全部必须是缩放安全的空节点，局部 +Z 朝前、+Y 朝上：

| 锚点 | 放置位置 |

| `Socket_GripMain` | 主手握把中心 |

武器 Prefab 中不得包含敌人专属目标锚点。命中与反应特效只绑定到玩法提供的通用目标数据。

## 4. 材质分区

| 分区 | 面积占比 | 基础颜色 | 表面属性 |
|---|---:|---|---|
| A——民用外壳 | 55–65% | 暖白 / 浅灰蓝 | 喷涂合金，粗糙度约 0.65 |
| B——结构聚合物 | 20–25% | 深石板灰 | 注塑质感，粗糙度约 0.75 |
| C——工作金属 | 8–12% | 低饱和钢色 | 拉丝，粗糙度约 0.45 |
| D——检查窗 | 3–6% | 烟熏青灰 | 克制的着色半透明 |
| E——元素通道 | 待机时小于 4% | 事件发生时使用元素色 | 遮罩自发光 |

强调标记只表达安全与维护信息，例如模块编号、操作方向和维护对齐线。禁止使用军衔、击杀标记、旗帜、现实口径、仿真序列号和随机微缩文字。

元素身份只通过 `ElementChannel` 的短暂流动表达，随后淡化为低亮度记忆线。火使用上升楔形分段；冰使用内嵌方板 / 菱形板；雷使用错位分叉缺口。三种元素共用同一套基础几何，不为元素更换枪身造型。

## 5. 贴图与 Shader 合同

| 项目 | 目标 |
|---|---|
| 材质槽 | 最多 2 个：不透明主体 + 检查窗 / 自发光模块 |
| 主贴图组 | 2048² BaseColor、Normal、合并 Mask；金属度/粗糙度/AO 通道按项目规范 |
| 可选细节 | 仅在已有、授权清晰且可复用时使用共享平铺微法线 |
| 自发光 | 一个遮罩通道；强度由 VFX / 表现事件驱动，不包含玩法逻辑 |
| 透明 | 尽量使用不透明或抖动方案，避免大面积 Alpha 混合 |

所有部件保持一致纹素密度。贴花必须在 1080p 第一人称距离下有明确用途。烘焙笼伪影、渐变偏斜、法线接缝与检查窗周围的 Mip 渗色均属于退回问题。

## 6. 建模预算

| 版本 | 三角面目标 | 用途 |
|---|---:|---|
| `LOD0` | 18,000–24,000 | 第一人称与近距离查看；以方盒和折面控制成本 |
| `LOD1` | 8,000–12,000 | 普通第三人称距离 |
| `LOD2` | 3,000–5,000 | 远距离第三人称 / 低画质 |
| 可选阴影代理 | 800–1,500 | 仅在性能分析证明有价值时制作 |

必须手工制作 LOD。到 LOD2 仍需保留瞄具桥开口、上部脊线、枪管与护木分离，以及检查窗轮廓。首先合并维护锁扣、接缝倒角和细小贴花。

交付 FBX 不得包含非流形结构、N 边面、重叠薄片、意外内部壳体或零面积 UV。只有在 Unity 2022.3 导入结果验证通过后才允许使用加权法线。导出前应用变换，单位为米，Unity 导入缩放为 1。

### 6.1 几何成本约束

- 主体先用不超过 12 个基础方盒 / 梯形体完成可读轮廓，再增加功能细节。
- 非轮廓边使用硬边与法线处理，不为“更圆滑”无条件增加支撑线。
- 可见倒角默认 1 段，第一人称近景主轮廓最多 2 段；细小维护件不做倒角或用贴图表达。
- 枪管外露部分建议使用 8–12 边低分段柱体；被护木遮挡的内部部分继续降段或省略不可见面。
- 同类螺丝、锁扣和装饰块共用网格；左右重复部件尽量镜像或实例化。
- 每次增加几何细节必须说明它改善了第一人称轮廓、第三人称识别或功能读法中的哪一项，否则不制作。

## 7. 第一 / 第三人称验证

- 待机、瞄准、开火与换弹姿势下均不得遮挡准星。
- 支持的 FOV 范围内，第一人称枪身不得穿过近裁剪面。
- 主手与支撑手锚点不得造成手腕反转；精确动画偏移由动画交接负责。
- 枪口 VFX 必须向前发射，不得与护木相交。
- 15 米处仍须识别为步枪，不能误读为冲锋枪、工具枪或现实枪械复刻。
- 缩小到 32 px 背包图标时，一体化桥架与封闭脊线仍可识别。
- 关闭元素自发光后，武器仍应是完整、成立的设计。

## 8. 生产包结构

设计通过后，预期生产交付如下：

```text
art/production/weapon/WPN-FP-001/
├─ source/                         # 源文件
├─ model/WPN_FP_001_LOD0.fbx
├─ model/WPN_FP_001_LOD1.fbx
├─ model/WPN_FP_001_LOD2.fbx
├─ textures/                       # 贴图
├─ materials/                      # 材质
├─ preview/                        # 预览与验收图
└─ provenance.md                   # 来源与授权记录
```

Unity 装配阶段再创建带 LODGroup、Renderer / 材质分配及必要锚点的 Prefab。资源必须使用主变更定义的资源目录 / `TotemAssetService` 流程，不得直接通过 Resources 加载。

## 9. 退回清单

- 可识别为某个现实步枪平台的复刻；
- 以黑色战术风、迷彩或大量外露导轨为主体；
- 依赖高分段圆柱、连续曲面或无功能圆角堆叠识别度；
- 没有经过性能证据支持却使用两个以上材质槽；
- 第一人称瞄准线或第三人称轮廓不可读；
- 颜料发光永久压过中性枪身；
- 缺少 LOD、变换未应用、拓扑非流形或授权 / 来源未记录；
- 在美术 Prefab 中嵌入玩法代码或伤害逻辑。

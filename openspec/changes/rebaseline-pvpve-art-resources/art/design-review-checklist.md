# 设计审核清单

本门槛通过之前，不得开始生成图片、3D 建模、Unity 材质制作或 Prefab 装配。

## 美术方向

- [ ] “清透机能”能够被理解为明亮的民用近未来，而不是战术军事或霓虹赛博朋克。
- [ ] “颜料失序”保持局部化，并且只由事件驱动。
- [ ] 方盒、矩形、切角和低分段折面是主要造型语言；圆形仅用于有功能理由的局部。
- [ ] 造型没有通过高分段曲面、无功能倒角或额外材质堆高制作成本。
- [ ] 色彩、形状、动作与禁止偏移规则均已确认。
- [ ] 敌人外观完全不属于本变更。

## UI

- [ ] 13 组必要窗体 / 覆盖层均已包含。
- [ ] 菜单 → 对局 → 构筑 → 战斗 → 结算 → 菜单的返回链正确。
- [ ] 构筑倒计时结束时的关闭顺序已经确认。
- [ ] 手柄焦点、键鼠一致性、模态框焦点恢复与回退状态均有明确定义。
- [ ] 720p、1080p、4K、掌机、安全区与中文扩展规则均已确认。
- [ ] 对手纹身信息只显示公开描述，不泄露精确隐藏数值。

## 步枪

- [ ] 民用模块化巡防步枪的轮廓已经确认。
- [ ] 一体化瞄具桥、封闭脊线与检查窗作为身份特征已经确认。
- [ ] 材质分区与克制的元素通道已经确认。
- [ ] LOD、贴图、材质预算与通用锚点已经确认。
- [ ] 方盒式轮廓与 1–2 段倒角满足第一 / 第三人称可读性，不需要额外曲面堆面数。

## VFX

- [ ] 火 / 冰 / 雷的弱、标准、强形状语言在没有颜色时仍可区分。
- [ ] 热冲击、过载与停滞的分镜符合玩法含义。
- [ ] P01 / P02 与队列提示只镜像已经结算的顺序，不进行玩法判断。
- [ ] 性能预算、对象池、减少动态效果和锚点缺失回退方案均已确认。
- [ ] 主要特效由方片、条带、棱片和断裂方框组成，圆环 / 球壳没有成为主要语言。
- [ ] `Assets/Game/Scene/ArtResourceTest.unity` 的独立调试、压力测试和晋级流程已经确认。

## 5. 拆分与生产规则

- 每张画布只生成一个逻辑资源族；不得把 UI 组件、步枪转面图和 VFX 帧混在同一张源图中。
- 原始输出保存在 `art/raw/<类别>/`；不得覆盖已有候选。
- UI 组件必须拆成透明图层，并尽可能重建为九宫格、矢量或文字组件。
- 步枪图片仅作为人工 3D 制作参考；图像生成不会自动提供拓扑、UV、碰撞、LOD 或锚点。
- VFX 图板只作为时序与形状参考；实际实现必须使用兼容 Unity 2022.3 的粒子 / Shader，并遵守 `vfx/first-playable-vfx-design.md` 的预算。
- 任何擅自增加敌人、新玩法界面、隐藏数值、玩法规则、品牌、可读假文字或授权风险的结果都必须退回。

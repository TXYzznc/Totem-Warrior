# 首轮可玩版离线美术生产包

本目录用于在 Unity 编辑器被占用期间，提前完成可独立制作和静态校验的美术源文件。当前文件尚未写入 `Assets/`，不会触发导入、刷新、编译或场景修改。

## 已完成内容

- UI：3 套九宫格面板、4 种按钮状态、18 枚功能图标、图标图集、准星、弱点命中确认、危险边框。
- 背景：一张以绿洲新城现有资源为参考的主菜单背景候选。
- VFX：通用噪声、色带、抖动和形状图集；程序化形状 Shader、程序化拖尾 Shader、共享 HLSL；6 套材质参数配方。
- UI Shader：方形切角焦点框与扫描高光，不依赖逐帧动画贴图。
- 工具：可重复生成位图的脚本和不启动 Unity 的离线验收脚本。

## 风格与成本约束

- 主形体使用方盒、切角、折线、楔形、分段条和低面数碎片。
- 圆形只用于准星中心点、局部脉冲等功能性小元素，不作为主轮廓。
- UI 只在色彩上与绿洲新城的暖砂、青绿环境协调，不复制场景纹样、釉面、拱券或建筑装饰。
- VFX 与场景风格隔离，不引用绿洲新城的色板、材质或纹样。
- VFX 优先由 Shader 参数、ParticleSystem 曲线和少量共享灰度纹理组合，避免为每种效果制作独立序列帧。
- 敌人相关模型、贴图、图标和特效均不在本生产包范围内。

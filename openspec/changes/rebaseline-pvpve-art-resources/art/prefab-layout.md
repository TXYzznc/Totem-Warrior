# 第一阶段 UI Prefab 布局规范

> 本文件是第一阶段 UGUI 结构的唯一真源。效果图生成与 Unity 装配必须遵循本文。  
> Unity 目标版本：2022.3.62f3；使用 UGUI；手柄优先，并保证键鼠操作一致。  
> 本布局通过审核前，不得制作 Prefab 或位图资源。

## 1. 全局 Canvas 合同

| 属性 | 值 |
|---|---|
| 参考分辨率 | 1920×1080 |
| Canvas Scaler | `Scale With Screen Size`；Match 0.5 |
| 渲染模式 | 默认 `Screen Space Overlay`；既有 GF_X 窗体宿主必须使用 Camera 时服从宿主 |
| 安全区 | `SafeArea` 全拉伸；先应用设备边距，再按参考分辨率保留横向 96 px、纵向 54 px 设计边距 |
| 最小点击区域 | 48×48；标准按钮 320×72 |
| 导航 | 显式设置手柄导航关系；鼠标悬停不得抢走当前手柄焦点 |
| 输入图标 | 由 `TotemInputService` / 当前 `ITotemInputProvider` 提供绑定动作；禁止写死按键 |
| 模态框行为 | 模态框限制焦点范围、记住打开者，并在关闭后恢复原焦点 |
| 层级顺序 | HUD 100；瞬时反馈 200；覆盖层 300；模态框 400；开发工具 500 |

所有窗体根节点都使用 `CanvasGroup`、既有 GF_X UI 系统要求的窗体桥接组件，以及一个 `SafeArea` 子节点。装饰用 `Image` 必须设置 `raycastTarget=false`。滚动内容使用 `RectMask2D`；只有确实需要柔边裁剪时才使用 `Mask`。

### 1.1 RectTransform 记法

每行依次为：`节点 | anchors 最小值→最大值 | pivot | anchoredPosition | sizeDelta | 布局/行为`。

以下共用组件都是精确的 Prefab 子树。界面实例化某个共用组件时，将继承其全部子节点和字段，只允许使用本文明确记录的覆盖值。

## 2. 页面与返回关系

```text
主菜单 MainMenu
├─ 本地对局确认 LocalMatchConfirm ─→ 开局构筑 OpeningBuild ─→ 战斗 HUD ─→ 第一阶段结算 FirstPlayableResult ─→ 主菜单
├─ 纹身与元素档案 TattooElementArchive ─→ 主菜单
├─ 玩法帮助 GameplayHelp ─→ 主菜单
├─ 设置 Settings ─→ 主菜单
├─ 制作人员 Credits ─→ 主菜单
└─ 退出确认 ExitConfirmDialog ─→ 主菜单 / 退出应用

战斗 HUD CombatHUD
├─ 回合构筑覆盖层 RoundBuildOverlay
│  ├─ 六人情报 SixPlayerIntel
│  └─ 颜料请求 PigmentRequestDialog
├─ 倒地 / 淘汰覆盖层 DownedOverlay / EliminationOverlay
├─ 观战覆盖层 SpectatorOverlay
└─ 第一阶段结算 FirstPlayableResult
```

构筑倒计时结束时按以下顺序关闭：`PigmentRequestDialog` → `SixPlayerIntel` 与其他构筑子覆盖层 → `RoundBuildOverlay` → 恢复 `CombatHUD` → 恢复玩法模拟。关闭过程必须支持重复调用且结果一致。

## 9. 退出确认——`UI-FP-EXIT-001`

实例化 `C_ModalShell`，标题和正文改为退出确认。左侧 `Cancel`（取消）是初始焦点；右侧 `Exit`（退出）是破坏性操作，必须使用明显的危险描边。返回动作等同取消。关闭后焦点回到 `MainMenu/Exit`。

## 17. 状态矩阵

所有交互组件都实现：`Normal`（普通）、`Focused`（焦点）、`Pressed`（按下）、`Disabled`（禁用）；需要异步数据时增加 `Loading`（加载），可能校验失败时增加 `Error`（错误）。各界面还要支持：

| 界面 | 必要特殊状态 |
|---|---|
| 主菜单 | 开发控制隐藏 / 显示 |
| 对局确认 | 普通 / 开发快速数值 / 启动中 / 启动失败 |
| 档案 / 帮助 / 制作人员 | 加载 / 有内容 / 空内容 / 本地化溢出 |
| 设置 | 未修改 / 有未应用修改 / 已应用 / 无效选项回退 |
| HUD | 普通 / 计时警告 / 构筑时隐藏 / 倒地 / 淘汰 / 观战 |
| 构筑 | 开局 60 秒 / 后续 45 秒 / 颜料不足 / 替换 / 移除 / 到时关闭 |
| 情报 | 已冻结且有内容 / 公开数据隐藏 / 不可用 |
| 请求 | 编辑 / 接收者确认 / 数量过期被拒 / 到时关闭 |
| 结算 | 显现 / 可交互 / 统计缺失回退 |

## 18. 分辨率与本地化验证

| 目标 | 规则 |
|---|---|
| 1280×720 | 档案改为两列；列表可滚动；关键字体不得小于参考等效 16 px |
| 1920×1080 | 标准构图 |
| 3840×2160 | 由 Scaler 缩放；位图背景需要足够源尺寸；九宫格 UI 保持清晰 |
| 16:10 掌机 | 应用安全区；侧边导航允许变窄；HUD 中央保持干净 |
| 超宽屏 | 关键 UI 保持在居中的 16:9 安全框内；背景允许向外延伸 |
| 中文扩展 | 允许源字符串 1.4 倍宽度；按钮在省略号出现前最多增高到 96 |

验收必须覆盖键鼠和手柄完整遍历，不能出现焦点死路、焦点不可见、点击穿透背景或返回后焦点丢失。至少执行 200 次焦点切换与反复模态框开关，不能因为重建静态美术布局产生明显分配峰值。

## ADDED Requirements

### Requirement: 首张地图场景与相关 3D 继续使用
绿洲新城场景、已完成建筑和场景装饰 MUST 作为当前地图基线保留；本 change 只记录兼容问题，不重新规划地图或批量重做模型。

#### Scenario: 美术 change 初始化
- **WHEN** 建立生产清单
- **THEN** 已确认场景资源被归入 retained 清单
- **AND** 不生成重复的替代资源任务

### Requirement: 角色相关 3D 继续使用并验证纹身可读性
当前角色身体、服装、统一骨骼和局部机械组件方向 MUST 保留；只需验证六部位纹身区域、第一/第三人称使用和 Unity 导入兼容性。

#### Scenario: 角色兼容检查
- **WHEN** 角色装备六部位测试纹身
- **THEN** 指定部位在目标视角下可读
- **AND** 不因新 UI 需求重做角色造型

### Requirement: 八图案视觉库和六部位贴花遮罩继续使用
S01 几何黑工八图案板、现有确认纹身资源及六部位贴花/遮罩 MUST 保留；P01～P08 仅为临时编号，第一阶段只对 P01/P02 建立功能交付。

#### Scenario: 检查 P03～P08
- **WHEN** 盘点后六个图案尚未进入第一阶段实现
- **THEN** 其视觉资源仍保留为后续储备
- **AND** 不为其制作第一阶段 UI 状态和 VFX

### Requirement: retained 状态不掩盖缺失的正式资产
“继续使用”只表示方向和既有资产不因玩法重构作废；若条目仍缺 FBX、PBR、Prefab 或导入验收，MUST 保持真实的待制作/待验收状态。

#### Scenario: 角色只有概念图
- **WHEN** 某角色条目尚无正式 FBX
- **THEN** 说明记录“方向继续使用”
- **AND** 状态不得错误标为已完成-符合

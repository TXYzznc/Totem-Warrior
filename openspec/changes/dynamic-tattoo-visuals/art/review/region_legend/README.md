# ActorCommonM02 六部位固定纹身区域图例

对应 Unity 场景：`Assets/Game/Scene/ActorCommonM02TattooRegionLegend.unity`。

这张图例使用标准正面 Idle 立绘。彩色覆盖层由与 TattooMap 相同的“逐像素皮肤检测 + 部位四边形锚点”规则生成，因而展示的是**实际允许绘制的范围**，不是概念示意图。

| PartId | 颜色 | 固定皮肤区域 | 本轮原则 |
| --- | --- | --- | --- |
| 1 | 珊瑚红 | 脸颊 / 太阳穴的小块裸露皮肤 | 头部被头发、转向或遮挡时不显示 |
| 2 | 金黄 | 背心开口内的裸露胸腹 | 不覆盖背心、绑带、腰带 |
| 3 | 绿色 | 左上臂外侧 | 不覆盖护腕、衣物或被躯干遮住的部分 |
| 4 | 蓝色 | 右上臂外侧 | 不覆盖护腕、衣物或被躯干遮住的部分 |
| 5 | 紫色 | 左大腿外侧 | 不覆盖短裤、膝部以外区域 |
| 6 | 青色 | 右大腿外侧 | 不覆盖短裤、膝部以外区域 |

## 映射规则

- 每一帧的 TattooMap 只在该帧可见、批准的裸露皮肤像素写入遮罩；衣物、透明像素和遮挡部位的遮罩保持为零。
- `offset` 和 `scale` 仅改变该部位区域内部的图案采样坐标；Shader 仍以 TattooMap 遮罩作为最终裁剪，图案不能移动到区域外。
- 翻滚等大幅动作允许某个部位本帧完全缺失。这表示该部位被遮挡或没有可靠裸露皮肤，而不是把纹身投射到相邻肢体或衣物上。
- 当前只有 `roll_right` 的 8 帧进入运行时映射验证；本图例是后续 Idle、Walk、Hit、Dash 等逐帧映射的人体区域基准，不额外扩大当前验证范围。

# AI 帧动画制作工作流

> 状态：active  
> 适用范围：角色待机、呼吸、睡眠、行走、施法等 2D 循环帧动画  
> 核心方法：关键帧先行、双端参考插值、循环末段单独验收、自适应补帧

## 1. 目标

本流程用于借助生成式 AI 制作角色帧动画，并解决以下常见问题：

- 相邻帧动作重复或跳变；
- 角色五官、服装、鹿角、头发等特征漂移；
- AI 生成的“过渡帧”并未处于两个动作之间；
- 末帧回到首帧时产生明显跳帧；
- 抠图后出现绿边、孔洞或半透明脏边；
- 切片后角色主体在播放时上下抖动；
- 为了固定帧数而牺牲动画质量。

最重要的原则是：

> AI 负责画出指定时间点，人负责定义时间点、运动逻辑、稳定锚点和验收标准。

不要让 AI 在一次生成中同时完成动作设计、过渡设计、角色一致性和 Sprite Sheet 排版。

## 2. 推荐生产链路

```text
角色母版
→ 动作节奏设计
→ 生成关键帧
→ 验证关键帧
→ 使用相邻关键帧生成过渡帧
→ 单独检查末帧到首帧
→ 按运动距离自适应补帧
→ 统一抠图和边缘清理
→ 按稳定锚点对齐
→ 切片与命名
→ GIF / Unity 循环验证
→ 只返工不合格区段
```

## 3. 阶段一：建立角色母版

先准备一张清晰、完整、已经通过审美验收的角色参考图。母版负责约束“角色是谁”，至少应锁定：

- 体型、面部、肤色与角色比例；
- 发型、鹿角或其他高辨识度结构；
- 服装结构、纹样与配色；
- 线条、排线、阴影和材质表现；
- 摄像机角度、透视与角色朝向；
- 光照方向与整体色调。

后续每一次生成都应继续传入角色母版。动作参考图只约束姿势，不能代替角色母版。

## 4. 阶段二：设计关键帧

### 4.1 先写动作节奏，不直接生成整套帧

以循环睡眠呼吸为例，可以先定义四个关键状态：

| 关键帧 | 动作状态 | 视觉变化 |
|---|---|---|
| K1 | 呼吸中位 | 头部自然下垂，胸腔处于中位 |
| K3 | 吸气阶段 | 胸腔微抬，头部略微抬起 |
| K5 | 吸气最高点 | 身体达到最高位置，发丝和披风略展开 |
| K7 | 呼气最低点 | 身体放松下沉，头部和肩部回落 |

关键帧必须满足：

- 每一帧的外轮廓都有可见区别；
- 姿势变化符合动作方向，不出现逆向运动；
- 身体重心与接触点稳定；
- K7 能够合理回到 K1；
- 不依赖过渡帧修复关键姿势本身的错误。

### 4.2 只生成关键帧并先验收

第一轮只生产关键帧，不生产过渡帧。逐张检查：

- 角色身份和画风是否一致；
- 面部、手指、鹿角和衣物结构是否正确；
- 镜头、透视和角色缩放是否一致；
- 动作轮廓是否确实不同；
- 重心是否连续；
- 服装、头发和附属结构有没有无原因换形。

如果关键帧按顺序播放时逻辑不成立，应先重做关键帧。增加过渡帧无法修复错误的动作设计。

## 5. 阶段三：生成过渡帧

### 5.1 必须提供两端参考图

生成某一张过渡帧时，至少提供：

1. 角色母版；
2. 起点关键帧；
3. 终点关键帧；
4. 明确的时间位置 `t`。

例如，生成 K1 与 K3 之间的 T2：

```text
使用角色母版保持角色身份和画风。
参考动作图 A（K1）和动作图 B（K3），生成二者之间唯一的中间动作，时间位置 t=0.5。
保持服装、鹿角结构、镜头、透视、角色比例和身体接触点不变。
头部、肩部、胸腔、手臂、头发和披风的位置必须处于 A 与 B 之间。
不得直接复制任一端点，不得创造第三种无关动作，不得增加或删除肢体和装饰。
纯绿色 #00FF00 背景，无文字、无边框、无投影。
```

当一个区段需要两张过渡帧时，分别指定：

```text
T8：K7 → K1，t=0.33，姿态更接近 K7。
T9：K7 → K1，t=0.67，姿态更接近 K1。
```

“生成一个过渡动作”不是充分指令。没有双端参考和时间位置时，AI 很可能只生成另一个独立姿势。

### 5.2 帧数由动作距离决定

不要为了满足预设的 8 帧而限制动画。动作距离较大的区段应分配更多过渡帧，动作距离较小的区段可以减少帧数。

本次睡眠动画最终使用的序列为：

```text
K1 → T2 → K3 → T4 → K5 → T6 → K7 → T8 → T9 → K1
```

原本 K7 到 K1 只有一张过渡帧，身体、头部、鹿角和衣摆仍然产生明显跳动。将该区段拆成两张过渡帧后，循环衔接显著改善。

## 6. 阶段四：循环和时间设计

### 6.1 末帧到首帧必须作为独立区段验收

循环动画不能只检查画布中的相邻图片，还必须检查：

```text
最后一帧 → 第一帧
```

重点观察：

- 头部运动弧线是否突然折断；
- 胸腔是否突然抬升或下沉；
- 鹿角是否因头部旋转而跳动；
- 发丝和披风是否突然换形；
- 身体接触点是否发生位移。

如果这个区段跨度更大，应优先增加过渡帧，而不是重新生成整套动画。

### 6.2 使用帧时长表现停顿

相邻图片应尽量存在有效变化。需要在吸气最高点或呼气最低点停顿时，不必复制同一张图片，可以调整播放时长：

| 帧类型 | 建议时长 |
|---|---:|
| 普通过渡帧 | 80–100 ms |
| 呼吸极值关键帧 | 120–180 ms |
| 循环衔接帧 | 根据预览结果微调 |

这样既能表现动作停顿，也不会浪费图像帧。

## 7. 阶段五：抠图

### 7.1 背景规范

生产阶段可使用角色本身不存在的纯绿色，例如 `#00FF00`。要求：

- 背景颜色完全一致；
- 无渐变、阴影、地面投影和环境光晕；
- 角色不得接触画布边缘；
- 鹿角、发丝和披风周围保留足够空间。

### 7.2 推荐抠图方法

不要直接删除画面中所有接近绿色的像素。推荐流程：

1. 从画布四周识别与边缘连通的绿色背景；
2. 仅移除连通背景区域；
3. 将抗锯齿边缘转换为半透明 Alpha；
4. 对绿色溢色执行去色处理；
5. 检查鹿角分叉、发丝、指缝和衣物镂空；
6. 输出 RGBA PNG；
7. 验证四角 Alpha 均为 0。

直接使用全局颜色阈值容易误删角色内部颜色，并在浅色皮肤、白发和衣物周围留下绿边。

## 8. 阶段六：对齐与切片

### 8.1 不要按外接矩形中心对齐

鹿角、头发和披风会随动作改变外接矩形。如果逐帧按照外接矩形居中，身体主体会在播放时抖动。

应根据动作类型选择稳定锚点：

| 姿态 | 推荐锚点 |
|---|---|
| 坐姿 | 臀部与地面或坐垫的接触点 |
| 站姿 | 双脚基线或主支撑脚 |
| 横躺 | 躯干重心与床面的接触线 |
| 悬浮 | 骨盆中心或设计时定义的角色原点 |

### 8.2 对齐流程

1. 所有帧使用相同画布尺寸；
2. 将稳定锚点移动到相同像素坐标；
3. 保持统一缩放，不逐帧自动适配大小；
4. 预留所有附属结构的最大运动范围；
5. 检查角色主体，而不是鹿角尖端是否稳定；
6. 再输出单帧 PNG 和 Sprite Sheet；
7. Unity 中为所有 Sprite 使用相同的归一化 Pivot。

建议按播放顺序命名：

```text
character_action_direction_00.png
character_action_direction_01.png
character_action_direction_02.png
...
```

## 9. 阶段七：最终验收

至少执行三种检查：

### 9.1 逐帧检查

- 是否有肢体、手指或装饰缺失；
- 是否出现局部结构跳变；
- 相邻帧是否存在有效差异；
- 是否有被画布裁切的内容。

### 9.2 洋葱皮检查

将相邻帧半透明叠加，观察：

- 头部、肩部和胸腔的运动弧线；
- 稳定锚点是否漂移；
- 附属结构是否沿合理方向运动；
- 是否出现突然缩放或旋转。

### 9.3 循环播放检查

分别使用慢速、目标速度和较快速度播放：

- 慢速用于发现结构变形和跳帧；
- 目标速度用于判断节奏和自然度；
- 快速播放用于暴露重心抖动。

GIF 适合作为快速验收格式。正式导入 Unity 时，应优先使用透明 PNG 序列或 Sprite Sheet。

## 10. 常见失败模式与处理方式

| 失败模式 | 根本原因 | 推荐处理 |
|---|---|---|
| 一次生成的 8 帧顺序混乱 | AI 将任务理解为八个相似插画 | 拆成关键帧和过渡帧两阶段生产 |
| 多帧动作几乎相同 | 没有给每个时间点定义独立姿态 | 明确每个关键帧的身体状态和轮廓差异 |
| 过渡帧不是中间状态 | 缺少起点、终点或时间参数 | 同时引用两端关键帧并指定 `t` |
| 循环末段跳变 | 只检查了表内相邻帧 | 单独验证最后一帧到第一帧 |
| 补一帧仍不平滑 | 区段的动作距离过大 | 使用 `t=0.33` 和 `t=0.67` 两张过渡帧 |
| 播放时主体上下抖动 | 按动态外接矩形居中 | 改用身体接触点或骨盆作为固定锚点 |
| 抠图后出现绿边 | 直接按颜色阈值删除背景 | 使用边缘连通背景、半透明 Alpha 和去溢色 |
| 动画极值没有停顿感 | 依赖重复图片控制节奏 | 为关键帧配置更长的播放时长 |
| 某一帧错误导致整套返工 | 将所有帧作为一个生成任务 | 保留已通过帧，只局部重做失败区段 |

## 11. 交付验收清单

### 美术一致性

- [ ] 角色脸部、体型、发型和服装一致；
- [ ] 鹿角、武器或饰品结构一致；
- [ ] 线条、配色、阴影和光照一致；
- [ ] 没有额外肢体、文字、边框或背景杂物。

### 动作连续性

- [ ] 每个关键帧职责明确；
- [ ] 每对相邻帧都有区别且变化方向正确；
- [ ] 没有动作反向、瞬移或突然换形；
- [ ] 最后一帧能够自然过渡到第一帧；
- [ ] 必要时已为跨度较大的区段增加过渡帧。

### 技术质量

- [ ] 所有帧画布尺寸一致；
- [ ] 所有帧缩放和镜头一致；
- [ ] 固定锚点坐标一致；
- [ ] 背景完全透明且边缘无绿色溢色；
- [ ] 角色和附属结构没有被裁切；
- [ ] 文件按播放顺序命名；
- [ ] Sprite Sheet 网格、Pivot 和帧率已经记录。

### 播放验收

- [ ] 慢速播放无结构跳变；
- [ ] 正常速度下节奏自然；
- [ ] 快速播放时主体不抖动；
- [ ] GIF 和 Unity 内的播放顺序一致；
- [ ] 循环播放至少持续观察 10 次，没有明显接缝。

## 12. 最终结论

AI 帧动画的质量主要由工作流决定，而不是由单次提示词长度决定。稳定且可复用的生产方式是：

1. 用角色母版锁定身份；
2. 由人先设计少量关键帧；
3. 关键帧通过后，再用相邻两端作为参考生成过渡帧；
4. 将末帧到首帧视为独立动画区段；
5. 根据动作距离动态决定过渡帧数量；
6. 使用固定身体锚点完成抠图、对齐和切片；
7. 通过逐帧、洋葱皮和循环播放进行分层验收；
8. 只返工失败区段，不重新生成已经通过的内容。

该方法将不可控的一次性出图，转化为可以逐段验证、局部返工和稳定交付的动画生产流程。

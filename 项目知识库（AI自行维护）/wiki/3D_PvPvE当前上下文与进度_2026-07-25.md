## 1. 一句话定位

这是一个以**刺青构筑**为核心的 3D PvPvE 大逃杀肉鸽：玩家在同一局、同一张地图中同时遭遇 NPC 与其他玩家，通过局内纹身、颜料、武器和资源塑造构筑，在撤离、继续搜刮和战斗风险之间做决策。

项目当前处于“**已有 2.5D/PCG 原型基础，正在验证 3D 美术垂直切片**”的阶段，而非完成 3D 重构的阶段。

## 2. 已确认的产品与玩法背景

### 2.1 模式与单局节奏

- PvP 与 PvE 同时在同一局、同一场景中发生；不是拆分的 PvP 模式与 PvE 模式。
- 初始设计基准为 20 名玩家，未来可扩至 50 名，但当前设计不为 50 人规模过早复杂化。
- 目标局时长：平均整局约 20 分钟；单名玩家平均停留 10–15 分钟；所有人撤离或死亡的最长时间不超过 30 分钟。
- 约 28 分钟需要触发促使结局发生的事件，例如毒圈、终极 Boss 或高价值目标。
- 剩余玩家达到 40% 时开启撤离阶段；玩家可选择不撤离。更晚撤离可以通过阶段补给等方式产生更高风险、更高潜在收益。
- 撤离最低时间门槛暂定为 8 分钟。
- 撤离为公开读条：离开范围停止读条，期间正常承受伤害，死亡则中止撤离并走死亡掉落流程。

### 2.2 局内、死亡与局外获得

- 局前仅带：一把自选基础武器、一罐自选颜色的颜料；最终战斗流派由局内随机资源和选择形成。
- 玩家死亡后会生成一个可被其他玩家开启的死亡箱；逻辑与地图宝箱一致，但内容是该玩家身上的可掉落物品。
- 是否可掉落是独立于“是否全局”的物品属性。
- 非全局资源会在死亡后清空；全局资源须成功存活至结算才能带走。
- 长期目标不是单纯数值碾压，而是收集个性化刺青/外观、熟练掌握战斗流派，并形成“自己最强的一套刺青外观与构筑”。

### 2.3 PvP / PvE 数值边界

- PvP 与 PvE 伤害系统应是两个独立子系统，避免在同一公式中堆叠大量例外。
- 永久成长可对 NPC（Enemy）侧产生更直接的影响；对 PvP 的影响必须可控。
- 不要求永久效果对 PvP 完全没有影响，但要限制其幅度，并避免永久成长直接成为 PvP 胜负决定因素。

### 2.4 纹身构筑与熟练度

- 可纹身部位为六处：头部、躯干正面、左臂、右臂、左腿、右腿；每个部位同时仅保留一个刺青，重新纹身会直接覆盖原刺青。
- 每次纹身选择：一个部位、一种图案、一个颜料。
- 纹身工作台在 UI 或快捷键中打开。工作台打开期间玩家无法控制角色，解除鼠标锁定；纹身完成后不会自动关闭，必须由玩家关闭后才恢复控制。
- 纹身读条期间禁止移动；受伤不会自动打断；玩家可主动用快捷键（暂定 X）打断。
- 成功：消耗颜料和一次性图案次数，并提升该图案熟练度。失败：不消耗一次性图案次数，但损耗一定比例材料。
- 图案可分为永久可用和有限次数；永久图案不显示“无限/永久”文案，有限次数图案显示剩余次数。
- 熟练度是死亡后保留的长期进度。阶段收益可包含永久可用、加快纹身、小幅降低材料消耗和少量效果强化；具体数值尚未冻结。
- 角色 3D 身体模型须能同步显示当前六部位刺青。

## 3. 3D 视觉与角色的已确认边界

### 3.1 视角与空间

- 以 FPS 为主，可切换越肩第三人称；视角切换当前视为视觉偏好，不先行做复杂平衡约束。
- 地编和空间体验以第三人称越肩视角为准，以规避视角切换时的遮挡、穿帮和交互漏洞。

### 3.2 角色共同设定

- 角色是接受**局部功能性机械改造**的人类，而非半机械人或重甲战士。
- 角色外观需要完整服装与鞋，不能以裸露身体来解决刺青展示问题。
- 六个刺青部位应通过合成皮革、弹性布等“刺青载体面板”可读地显示；刺青不是随意贴在所有衣物上的装饰。
- 当前男性角色概念以 23–28 岁、敏捷运动型、局部机械接口、轻机能服装为探索约束。

### 3.3 地图与角色必须分层

**“生活化未来街区”是首张地图/环境的内容概念，不是游戏世界观的全部，也不应约束角色的通用设计。**

因此：

- 角色、NPC、武器和 UI 应以“局部改造人类 + 刺青构筑载体 + 明亮可读的风格语言”为共同基础。
- 建筑、街道、室内、生活化道具和对应光照才属于“未来街区”环境层。
- 以后生成角色稿时应使用中性纯色背景，避免由地图气质替角色做决定。

## 4. 当前技术与原型状态

### 4.1 运行时 / PCG

项目使用 Unity 2022.3.62f3 与 GF_X runtime。7 月中旬完成 PCG 架构调整：

- 地图生成已从旧布局管线迁移为 `PCGWorldPlan + PCGWorldPlanner + Profiles`。
- `PCGWorldPlan` 是一次地图生成的只读逻辑产物；渲染、事件和未来能力系统应消费该计划，不从 Tilemap 或实例化对象反推规则。
- 世界格子区分当前运行能力与未来能力；当前运行时能力固定为视觉，碰撞、遮挡、危险、交互等能力由配置预留。
- `WorldGenerationProfiles.json` 当前定义三套测试主题：`ai_ruins`、`alien_hive`、`virus_swamp`，每套含地形、特征操作、玩家出生点、Boss、商人、纹身师、宝箱、资源和事件锚点规则。
- 已有 PCG 测试场景、地图预览、玩家预览面板，以及刺青视觉展示相关调试内容。

## 7. 垂直切片的正式目标与实际完成度

OpenSpec 变更：[`openspec/changes/3d-pvpve-art-vertical-slice/`](../../../openspec/changes/3d-pvpve-art-vertical-slice/)

目标是一个约 60 秒可连续展示以下内容的切片：街区移动、进入建筑、NPC 遭遇、工作台纹身、第三人称刺青展示，并且角色、建筑、UI、灯光、VFX 具备统一的明亮活性颜料风格。

当前结论：

- **已完成/接近完成**：设计共识、GDD、资源台账、概念探索、模块化环境规格、纹身图案探索、已有 PCG 原型基础。
- **尚未完成**：OpenSpec 任务列表中的设计冻结、白盒、角色模型、工作台流程接入、统一渲染实现、60 秒验收脚本。该变更的 `tasks.md` 当前仍以未勾选项为主。

## 8. 当前关键风险与待决策

1. **美术方向尚未正式收口**：A/B/C、五种大风格与厚涂 NPR v3 并存。需要明确厚涂 NPR 是否成为主风格，并把其他方案降级为历史探索或子风格参考。
2. **角色与地图层级不可混淆**：未来街区只能影响环境资产；不能反过来规定角色、NPC、UI 的世界观与造型。
3. **PCG 测试主题与首张环境切片未对接**：当前 Profile 是遗迹/虫巢/沼泽，首张美术切片是生活化未来街区。需决定复用、改造或新增街区 Profile。
4. **概念完成度不能等同于生产完成度**：当前大部分“已完成”是设计稿或 brief；没有 FBX、Prefab、Shader/VFX、动画和验收场景就不能宣称垂直切片完成。
5. **验证证据不足**：历史提交含 PCG 截图和诊断报告，但当前尚无“新版 3D 垂直切片”自动化或人工验收记录。

## 9. 建议的下一步顺序

1. 冻结主美术方向：确认厚涂 NPR 是否作为主风格，并选定一个男性外观母版。
2. 建立一份正式 Art Bible：角色、刺青、武器、NPC、UI、环境各自的继承关系与禁止项；把“地图主题”与“角色世界观”分层写清。
3. 将首张“生活化未来街区”拆成 PCG 可消费的主题 Profile 或明确其不走 PCG 的原因。
4. 先制作最小可验证组合：一名基础角色、一个可进入建筑战斗单元、纹身工作台 UI、统一灯光/后处理。
5. 在 Unity 中完成 60 秒切片后，才扩展到 20 人网络、完整经济、更多地图和批量资产生产。

# 想法库

本目录用于保存已经提出、具有潜在价值，但明确不进入当前第一版范围的设计想法。

想法库中的条目不是当前需求、实现承诺或排期任务。只有经过后续讨论并正式进入 OpenSpec / GDD 后，才可以转为开发范围。

## 状态约定

- `parked`：暂存，第一版不考虑。
- `reviewing`：重新进入讨论，但尚未纳入版本。
- `promoted`：已迁移到正式设计或 OpenSpec；原条目保留去向链接。
- `rejected`：讨论后明确不采用，保留否决原因。
